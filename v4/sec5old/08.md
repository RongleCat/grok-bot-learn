## 容易踩的坑

### 凭证安全与权限认知
- **别在聊天框贴密钥或密码**。网页端人工键入，CLI Token 存 `~/.env`，脚本走环境变量。
- **同账号 Bot 共享 `/workspace` 与权限**，无数据隔离。敏感资产靠外部私有仓库权限与人工审批隔离。

### 协作规范与依赖管理
- **Bot 间协作必须落地文件**。会话不互通，Bot A 必须将结果存成 Markdown 或 JSON。
- **全局依赖不持久**。用 `apt install` 与 `npm install -g` 装的工具，遇计算机更新或点了 Recover、Reset 都会清空，需备恢复脚本。
- `node_modules` 与 `.venv` 不备份，**恢复脚本须含 `npm install` 或 `pip install -r requirements.txt`**。

### 运维操作与网络配置
- 界面显示 `Reconnecting` **先等或重启客户端，别点 Reset**。直接 Reset 会重建机器并丢掉改动。
- **别私加 crontab**。定时任务须统一列清单，交由 Git 仓库维护。
- 开「通过当前计算机路由流量」后**长连接不自动切**。IP 没变就把请求进程停掉重跑。
