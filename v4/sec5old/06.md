## 重建、更新与终止：云电脑的生命周期

云电脑因镜像升级、平台维护或故障排查随时可能重构。**弄清不同操作的数据保留边界，才能防止资产丢失。** 细则参考 [Grok Bot 计算机](https://cursor.com/cn/help/grok-bot/computer-recovery) 与 [管理 Grok Bot 电脑](https://cursor.com/cn/docs/grok-bot/computers)。

### 云电脑状态操作对比

| 操作类型 | 触发与影响 | 保留内容 | 清除内容 |
| --- | --- | --- | --- |
| 软件更新 | 设置里点击，安全点暂停并恢复 | 全部保留 | 无 |
| 计算机更新 | 设置里点击，切到新镜像 | 持久磁盘与文件、Bot 及登录态 | 自装软件、`node_modules` 与 Python 虚拟环境 |
| Recover | 重连或卡住时可选，中断当前工作 | 尽量打快照，保留已存文件与登录态 | 自装软件；若连不上机器，最近更改会丢失 |
| Reset | 设置里重置，作为最后手段，中断工作 | 基于最近保存数据建新机，保留已存文件与登录态 | 自装软件；若连不上机器，最近更改会丢失 |
| 重建 VMs | 管理员触发，切到新机 | 持久磁盘与文件、Bot 及登录态 | 自装软件（环境设置脚本会自动重跑） |
| 终止 VMs | 管理员触发或**闲置 30 天自动终止**，机器关机 | 持久磁盘保留，下次发消息开新机仍在 | 自装软件与未保存任务进度 |

### 遇到连接异常的处理顺序

看到 `Reconnecting` 或 `Couldn't Reach Grok Bot's Computer`，**先别急着点 Reset**，按下面顺序排查。

1. 先点 Retry 等待。重连时机器人、文件和登录态完好，频繁点 Reset 反而破坏现场。
2. 彻底退出客户端。macOS 不能只点红叉关窗口，**必须通过 `Cmd+Q` 彻底退出**后重开。
3. 检查可用更新。进设置中的「计算机」，若提示等待备份或智能体未暂停，等 Bot 空闲后再更新。
4. 尝试 Recover。长时间连不上且弹出恢复提示，**优先选 Recover**，它在重置前会尽量保存数据。
5. 最后的手段 Reset。前几步全失效，且确认没有未保存的紧急代码时，再执行 Reset。
