## 选型对照：Grok Bot 与主流常驻 Agent 横向对比

选常驻 Agent 看图省心还是折腾。**开箱整机**免运维但卡额度，组装机自由但**环境报错得自己修**。

| 产品 | 底座与门槛 | 特点与适用场景 |
| - | - | - |
| Grok Bot | 共享 Linux 云电脑。2026-10-12 起执行 The X Subscription（Premium $30、Super $100、Ultra $200/月），**Plus 档不含 Bot**；客户端 v0.70.2 配独立邮箱与连接卡片 | 7×24 小时常驻，支持例程与技能，跨 Bot 异步交接文件并调 X 检索。适合免运维协同与巡检对账 |
| OpenAI dots | 个人常驻云电脑，ChatGPT Pro 档包含 | 基于 GPT-6 Astra（2026-09-30 发布），常驻后台连 4000 多个插件，主打日常伴随与轻量代办 |
| Manus Cue | 独立云电脑，处于早期体验阶段 | 2026-09-29 铁柱上手体验；原生配独立邮箱、电话与钱包跑腿采购，自主权极高但伴随操作风险 |
| Meta Muse | Meta 托管云端代理 | 诺鸭船长评测偏家庭生态，深度绑定 Meta 社交网络与硬件，适合家庭日常辅助 |
| Hermes | 本地或私服自建 | 自由换开源模型无额度限制，适合本地敏感数据流水线，**需自己动手配环境排错** |
