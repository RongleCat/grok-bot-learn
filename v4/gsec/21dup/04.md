## 21.4 百万撤离方案：跨账号与跨平台迁移实战

[《Grok Bot 百万撤离：一套完善的 Agent 系统备份方案》](https://jcng5q8n0f3z.feishu.cn/wiki/W0TCwnTmbiIJ9KkF4S4cV6ifnCh)

### 迁至新 Grok 账号

1. 新账号添加记忆管家模板。
2. 在 `/workspace` 配置 Git 凭据并拉取备份仓库。
3. 唤醒记忆管家，解析根目录 `RESTORE.md`。
4. 管家按 `bots/agent-spec.md` 读名称、头像描述与 Description 填入配置，把 `MEMORY.md` 注入初始上下文。
5. 执行 `vm-services/restore/restore-all.sh` 恢复虚拟机系统依赖与服务。

**基础设定与记忆还原度约 80%（作者自述，未核）。** 本地非结构化文件、编译缓存和对话历史无法恢复，依赖 Cookie 或 OAuth 的登录态必须人工重新扫码配置。

### 迁至本地开源系统

- **Hermes 体系**：把各 Bot 的 `MEMORY.md` 放入记忆工作区，`agent-spec.md` 里的 Description 贴入 System Prompt。
- **OpenClaw 体系**：**把备份库中的 `bots/` 目录直接挂载到 OpenClaw 知识目录下。**
