## 高耗操作清单：坚决避开的六大陷阱

参考出处：[《4.1 额度与成本：省额度清单》](https://jcng5q8n0f3z.feishu.cn/wiki/KFbzwPhAliezlBkkvIuc1Abgn4h)、[《Grok Bot 额度超长续航保姆级新手指南（直接发给 Bot！）》](https://jcng5q8n0f3z.feishu.cn/wiki/OPMJw2EgtiWMiJkcrzFc6gJ8nlf)。

| 高耗操作 | 费额度原因 | 避坑做法 |
| :--- | :--- | :--- |
| 多 Bot 群聊 | 互相唤醒导致 token 翻倍空转 | 单主导 Bot 配 Subagents 派活，或人工单聊 |
| 对话直接喂图与视频 | 历史帧常驻，每轮全量重读买单 | 终端命令行处理，Bot 只接百字内结构化文本 |
| 全天高频轮询 | 15 分钟一次每周 672 次，多在确认无变动 | 收紧到工作时间，或改用系统脚本加 Webhook |
| 一条会话用到底 | 数十轮后单轮重读数十万 token | 单任务单会话，定期总结并 Duplicate 重置 |
| 无保护重试死循环 | 报错后连续自我尝试数十次 | **提示词强制设 2 次重试上限**，失败立刻阻断问人工 |
| 盲目开按量付费 | 死循环可能一夜产生高额账单 | **平时关闭按需付费**，开启必须设严格低额月度上限 |
