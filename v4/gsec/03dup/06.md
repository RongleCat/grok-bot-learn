## 认识共享底座与创建第一个 Bot

### 共享底座的核心特性

每位付费用户独享一台 Linux 虚拟机（早期测试约为 8 核 16GB 内存，以官方实际分配为准），配有终端、浏览器与持久化磁盘。

- **所有 Bot 共享同一台机器与登录态**：共用 `/workspace` 目录，分设 Bot 只是切分岗位上下文，无法作为安全隔离。
- **跨 Bot 协作必须依赖文件落盘**：Bot 间看不到彼此聊天记录，Bot A 须将产物写入 `/workspace` 具体文件，Bot B 读文件接力工作。
- 遇到密码、人机验证码或支付认证时，展开右侧实时画面可随时接管控制，不用在输入框输入敏感凭证。

### 创建与设置 Bot

首次登录系统会自动生成默认的 Grok Bot。

1. 新建：点侧栏 + 按钮（快捷键 Cmd+N）选 Create new Bot，或在输入框输名字后点击创建对应 Bot。
2. 重命名与标签：右键侧栏 Bot 选“重命名机器人”，或在聊天顶部直接改；下方可填职务标签（Label，手机端为 Title (optional)）。
3. 换头像：点顶部详情头像，可挑内置图形、输入提示词生成（Generate），或上传 25 MB 以内的本地图片（Upload）。
4. 设职责：**个人 Bot 已取消独立的设置页与 Description 框**，规则直接发在首条消息并要求它记住，会自动存入专属记忆区；团队 Bot 仍可在“关于”栏编辑描述。
