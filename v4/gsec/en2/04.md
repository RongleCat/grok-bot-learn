Mori 在云电脑 `/workspace/devdesk` 跑状态机修 GitHub 缺陷，由 Chief 调度四个专职角色推进。
1. Triage 复现故障并提供失败用例。
2. Builder 调 Cursor 云端 Agent 独立分支写补丁。
3. Reviewer 独立复核，交由 Release 发布。

- 验收：**补丁交付必须包含复现用例的前后对比执行日志**。
- 熔断：**同一测试报错两次立即停机呼叫人工**，防止死循环空耗额度。
