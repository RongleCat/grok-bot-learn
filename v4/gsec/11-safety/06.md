## 网络策略与边界收拢

### 核心权限
**连接器策略与网络策略完全独立**。后台禁用插件管不住 Bot 调自带浏览器访问公网。**网络控制（Network Controls）仅限企业版**，Teams 方案默认全通且无配置面板，需在 Cursor 仪表盘进 Grok Bot > Network > Grok Bot Network Access 配置。

### 访问模式
| 模式 | 生效规则 | 适用场景 |
| :--- | :--- | :--- |
| **Allow All Network Access** | 允许访问所有公网目标（默认状态） | 探索性研发、无敏感数据业务 |
| **Defaults + Team Allowlist** | 放行系统基础域名加团队自定义列表 | 绝大多数企业生产环境 |
| **Team Allowlist Only** | 仅放行自定义列表与维持虚拟机底线 | 严苛的合规审计环境 |

支持网页域名与原始 TCP 的 IP 范围及端口，条目数量没有上限。正在运行的计算机约一分钟内自动同步，休眠机下次唤醒时应用。目录群组策略优先于团队策略，开启全局锁定（Lock）则全员生效。

### 避坑与私网
- 共享静态出口 IP 为全体客户共用，**绝不能用来标识具体团队**。内网需要放行时向账户团队索取最新 IP 段。
- 网关放行 `api2.cursor.sh` 却解密嵌套域名会导致机器卡在 Setting up computer，**须在所有 profile 中将 `*.cursorvm.com` 与 `*.*.cursorvm.com` 加白并跳过证书解密**。参见[配置 TLS 检查代理](https://cursor.com/cn/docs/grok-bot/proxies)。
- 访问内网资源可开启桌面端流量转发（Allow Local Egress Routing），或用团队环境设置脚本（Team Setup Scripts）在初始化时统一安装 VPN 客户端。参见[连接到私有网络](https://cursor.com/cn/docs/grok-bot/private-networks)。

### 做到什么程度算好
- **明确封锁非必要外网请求**
- 阻断未经允许的文件外发传输
- 内网网关正确放行嵌套域名，无虚拟机连接挂死现象
