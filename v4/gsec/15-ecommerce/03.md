## 案例 3：工具情报员（按用途筛选的软件分析简报）

Miles Ma 做的「工具情报员」Bot，专门抓取开源仓库与文档，生成支持分类筛选的网页卡片简报。

### 工具限制与推荐任务

| 工具 | 门槛与依赖 | 主要限制 | 推荐任务 |
| :--- | :--- | :--- | :--- |
| **PowerToys** | Windows 安装包直接运行 | 仅限 Windows，部分实验功能偶发不稳定 | 快捷键提取文字或置顶窗口 |
| **MarkItDown** | 依赖 Python 或命令行 | 复杂图文版面识别率有限 | 批量转 Word 与 PDF 为 Markdown |
| **changedetection.io** | 需 Docker 或服务器环境 | 需运维基础，受反爬限制 | 监控电商价格标签变动 |

### 操作步骤

1. 在 Grok Bot 侧栏新建 Bot，命名为「工具情报员」。
2. 确定调研受众与目标工具清单。
3. 进入对话界面发送提示词。

```text
帮内容工作室整理 PowerToys、MarkItDown 和 changedetection.io，查官方仓库和文档。每个工具写清能帮忙做什么、上手需要什么、主要限制，再给一个具体使用例子。做成能按用途筛选的网页简报，附来源链接。
```

4. Bot 抓取仓库说明与依赖，**编写包含筛选脚本的 HTML 简报**存入工作区。

### 验收标准与避坑

- 每张卡片**包含 6 项核心要素**，覆盖工具定位、上手依赖，以及主要限制、实操任务与官网链接。
- 网页顶部设置分类按钮，能平滑筛选卡片。
- 限制说明务必客观，明确指出 changedetection.io 需 Docker 或服务器，不夸大为零门槛。
- 这属于案头筛选，**Bot 不跑全流程实测**，主要用来快速排除不符合门槛的候选软件。
