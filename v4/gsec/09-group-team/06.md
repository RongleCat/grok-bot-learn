## 用量影响与额度控制：The X Subscription 下的多 Bot 治理

2026-10-12 起 Grok Bot 纳入 The X Subscription，**统一按周共享额度**。

| 档位 | 价格 |
| :--- | :--- |
| Premium | $30/月 |
| Super | $100/月 |
| Ultra | $200/月 |

### 规则与防烧策略

1. **回复与握手消息都计费**。私聊团队 Bot 扣自己额度，群聊扣发起方的，周初耗尽整周停摆。
2. 群聊 Bot 压在 3 个以内，**坚决用 1+N 串行替代自由群聊**。
3. 清洗等轻任务用基础模型，核心推导才用顶级推理模型。
4. 没跑稳前**别设半小时或每小时的定时例程**，防夜间重试上百次耗尽额度。

### 验收标准

- **周额度平稳消耗**，没有夜间死循环。
- 模型分层分明，费用分摊到具体提问者。
