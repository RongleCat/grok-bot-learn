**不用公网 IP 和自备服务器**，靠飞书长连接与官方 Python SDK 扫码免配后台，把 3 个 Bot 接进飞书。每个 Bot 设独立门铃触发器，由应用管家维护账本。

- **严格限制仅在艾特自身或全员时转发**，避免群内闲聊引发模型空转。
- **关键确认节点直接推送交互卡片**，点选按钮即可放行，省去两端界面来回切换的麻烦。
