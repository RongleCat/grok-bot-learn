### 自动化管道与协同配置

配上 Webhook，Grok Bot 就是 **7×24 小时自动化节点**。

1. Bot 端建例行任务，触发选“当 Webhook 被触发时”，保存后获取接口地址与 Bearer 密钥。
2. 手机用快捷指令配“获取 URL 内容”，以 POST 发送 JSON 文字或链接。
3. 微信无分享面板就读剪贴板；大附件或多图存临时网盘换公网链接，Bot 云端下载解压。
4. 飞书走长连接，免公网 IP 和自建服务器，配门铃触发器定向派活。

**验收标准**：
- 手机即发即走不用等。
- Bot 云端异步抓取、抽帧转录、落库并给收录回执。
- 群聊仅被精准艾特或全员时响应。

发提示词可**自动生成接收端点**：

```text
帮我创建一个 Webhook 触发的例行任务。快捷指令会用 POST 请求发来一个 JSON，里面包含一个字段 info。info 可能是我输入的文字，也可能是一个文件下载链接，比如微信聊天记录压缩包、截图、录音。收到后：如果是链接就先下载文件再读取，压缩包先解压；然后整理出要点，收录进知识库，最后给我一份回执，写清楚收录了什么、存在哪里。
```
