## 典型实战案例拆解

### 金尘马的情报总监（个人调研岗位）

金尘马（@jinchenma_ai）搭建了一个追踪前沿动态的数字员工。

1. 在 Edit Profile 的 Description 中写明长期岗位规则，定性为情报调研员。
2. 用五要素（结果、来源、限制、格式与确认点）派单，检索 X 平台长文并区分视频帖，标明曝光数据，无一手数据严禁编造。
3. 首次交付纠偏格式后，发指令要求 Bot 把流程**沉淀为 Skill**「AI 教程情报搜集」。
4. 换第二组输入测通后配置 Routine，定在每个工作日早上 8:10 自动执行并汇报。
5. 新建「内容总监」负责选题评审，初稿保存到 `/workspace/grokbot-demo/` 供读取。

**岗位说明沉淀长期规则，临时需求走消息**，多 Bot 协作通过 `/workspace` 落盘解耦。实操细节见[《万字长文｜Grok Bot 从入门到精通｜金尘马》](https://jcng5q8n0f3z.feishu.cn/wiki/MIKpwiUXpiE9mWkyG8ccFM6Znee)。

### 金尘马的电商运营团队（多角色分工流水线）

金尘马（@jinchenma_ai）把单兵模式升级成了 4 个 Bot 的协同流水线。

1. **单点起步**：建「店铺经营值班员」读商品表、库存表和订单表发晨报。**卡死只读红线，严禁改价、改库存、发信或退款**。
2. **细化拆岗**：拆出「内容增长专员」（分析流量与选题）、「商品与库存分析员」（盯缺货与周转）和「订单与售后异常助理」（查履约并草拟回复）。
3. **协同流转**：原值班员升级为「电商运营主管」，各岗位将数据保存至 `/workspace/ecommerce-ops/日期/` 目录。
4. **业务联动**：库存分析员发现爆款仅剩 3 天库存，内容专员暂停推广，售后助理备好延期话术，主管汇总决策清单。

不要一上来就搭建庞大团队，**涉及资金、库存与外部发信的操作全部锁定人工审批**。

### 铁柱的开源仓库管理员 Bot（自动化运维巡检）

铁柱AGI（@cgnot996）搭建常驻 Bot 自动维护 awesome-grok-bot 知识库。

1. **配置巡检**：定期扫描 X 平台公开推文、官方更新日志与技术社群动态。
2. **分类提交**：把新玩法、教程、官方文档和线下活动结构化分类并自动收录。
3. **实际效果**：作者公开宣发前已自动收录相关资料；2026 年 8 月突破 130+ Star（作者自述，未核），并获得官方人员的申请表单邀请。

常驻 Agent 很适合承担**长效资料检索与文档归档**，能把人从重复的信息搜集里解脱出来。
