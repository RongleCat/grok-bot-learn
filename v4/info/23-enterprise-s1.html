日常配置：仪表盘的四步

1

划分权限与基础开关

  • Manage Group Access 勾选试点
  • 本地执行设为 Never allow
  • Auto-add 选 All team 或指定群组
2

配置审批锁与规则

  • 开启 Enforce Auto-review 模式
  • 高危操作设为 Ask first
  • 冲突时强制以 Ask first 为准
3

设置网络与密钥

  • 网络选团队允许列表或加默认值
  • 可关闭默认开启的 sudo
  • Team Secrets 最多 100 条
4

配置群组级策略

  • 只能放宽、不能更严
  • 网络按最严执行
  • 权限按最宽生效

两版权限

团队版
  • 全员默认开启
  • 共享静态出口 IP
  • 基础审计与团队规则
企业版
  • 按组授权与 SCIM 2.0
  • sudo 和网络白名单
  • 操作录制与 OpenTelemetry 导出

做到什么程度算好

  • 明确区分试点群组与未授权群组
  • 团队规则与 Auto-review 规则已锁定
  • 高危操作百分之百触发审批拦截
