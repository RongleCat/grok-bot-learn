私有网络接入

Grok Bot 跑在云端，访问内网必须打通私网。

两种接入方式

桌面端路由

适合临时调试。流量走本机网卡，管理员可在后台一键禁用。

Team Setup 安装客户端

常态化访问且仅限企业版。由 IT 统一维护脚本。

网络控制

仅团队允许列表时，必须把网络工具的控制面加入允许列表。

常态化访问：由脚本接入内网

方案一

接入 Tailscale 组网

添加 Tailscale 认证密钥 TS_AUTHKEY，绑定专属 ACL 标签，严格限制访问权限。

方案二

接入 Cloudflare Tunnel

私有 HTTP 服务由 Cloudflare Access 鉴权；私有 TCP 服务打开本地转发端口。

Team Setup 脚本如何运行

Bot Computers
开机时运行

以 sudo 普通用户身份在 Debian Linux 虚拟机中跑。

每天约周期刷新一次

超时上限 30 分钟。

check 验证

退出码为 0 就跳过安装；执行失败不阻塞电脑启动，会在下次周期刷新时重试。

做到什么程度算好

✓

新建或重建的 Bot 电脑启动完成后，自动出现在管理控制台设备列表中，状态为在线。

✓

check 脚本能在后续每日轮巡刷新中稳定返回 0，不会重复执行安装逻辑。

✓

敏感 Token 完全由 Team Secrets 注入，清单文本和执行日志中没有任何明文凭据。
