例程：设置、查看与测试

1

设置例程

在聊天框发指令直接创建。

手机端点击 Add routine，补齐指令发送即可创建。

时区检查路径：
Settings → Bot → Timezone。

2

查看与管理

桌面端进入 Details，在例程列表能看运行时间或 Paused。

点击具体例程可查：Instruction、When to run 与 Webhook。

开关可随时 Pause 或 Resume；手机端状态与桌面端双向实时同步。

3

测试例程

在桌面端详情页点击底部的 Test 按钮即可手动触发。

按钮状态变为 Running…，执行反馈直接打在聊天窗口中。

测试执行的是真实操作。

涉及删改先用沙箱数据测试。

规格与限制

50 个每个 Bot 最多创建
20 次系统保留最近运行记录
5 分钟定时例程最短触发间隔
不可逆删除例程，后续执行会永久终止

计划调度

Auto-detect

自动跟随当前电脑时区

手动指定时区

手动下拉选择对应时区

新建定时例程不会立刻首跑，必须等待下一个计划时间点。周末若需连续巡检，指令中必须明确强调“包括周末在内每天运行”。
