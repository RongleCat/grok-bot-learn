省额度四步工作流

01

锁定计费与
安全底线

Settings > Usage & Billing
核对套餐、用量与倒计时；
卡住点 Stop 强制结束。

调试时关 Additional Usage / On-demand

send、post、buy、transfer、delete、permissions
设为 Ask first 人工批准

02

规范会话与
交互

单任务单会话，做完立即归档。

日志长文存进 /workspace/，
只回结论和路径，严禁贴回。

X 搜索限每分 30 次、
每天 1000 次（不扣周额度）

提取核心事实，以 3 到 5 条要点输出

会话臃肿时用 Duplicate 重置

03

能力路由与
分流

主 Bot 只负责拆解、派发与汇总，不写长代码或转大文件。

写代码走 Cursor 云端 Agent
（走 Cursor 额度不扣周额度）

或在虚拟机无头跑 Grok Build CLI / Codex CLI。

截图与音视频由云电脑命令行处理，或用免费模型转文字再喂给 Bot。

04

定时任务
改造

Details > Routines 里，
暂停或删除过去一周天天报「没有变化」的例程

换 Linux 脚本低成本轮询，
有变动再发 Webhook 唤醒 Bot。

保留例程写入静默指令

「检查后若无变化，直接结束任务，严禁输出任何文字」。
