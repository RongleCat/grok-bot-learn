批准机制与 Auto Review

Bot 执行受控操作会弹卡

提供三个选项（iPhone 端一致）

Allow once
Always allow
Deny

底层的 Auto Review 会预审 shell 命令与插件调用，也管控计算机使用、自动化写入及 Agent 委派。

写入记忆和大部分配置更改不经评审，不能替代逐项批准。

怎么做

1

企业版在 Cursor 仪表盘开启 Enforce Auto-review 模式锁定，群组设 Don't enforce for this group 除外。

2

个人在客户端进入 设置 > General > Auto-review > Custom Rules

规则冲突以 Ask first 为准

Ask first：强制拦截弹卡
Allow automatically：无风险时自动放行

send, post, buy, transfer, delete,
permissions, production, terms

验收标准

高危动作 100% 弹出确认卡片
日常低危读写不被误拦截
冲突时执行最严拦截方案
规则须绑定具体行为

如“发外部邮件前先询问”

严禁宽泛规则

“允许所有 shell 脚本”
