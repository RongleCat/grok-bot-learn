移交屏幕，不交密码

登录授权是一个高频场景

不要把网站账号、密码或 API Token 发进聊天框

这种做法有极大的安全隐患，会把凭据暴露给模型的推理上下文与外部传输链路。

Bot 与你使用同一个浏览器环境处理服务登录的铁律是「移交屏幕，不交密码」。

浏览器接管标准步骤

1

触发暂停

打开目标登录页；遇到输入密码、扫码或双重验证（2FA）时主动暂停，交出控制权。

2

接管输入

在客户端点击全屏或通过实时画面接管鼠标与键盘。

3

人工登录

由你本人在云端浏览器内直接敲入账号密码，或者使用手机扫描屏幕上的二维码完成二次验证。

4

移交执行

登录成功并进入操作页面后，通知 Bot 恢复运行。

↓
恢复运行Bot 会直接复用浏览器当前已有的会话 Cookie，自始至终接触不到你的明文密码。
