适合与不适合的任务类型

任务过滤标准

任务该不该交给 Grok Bot，直接看三条过滤标准

01能在网页端、终端或通过 API 完整跑通
02中间文件或最终报告能由人工直接核验
03高危敏感动作能停下来等人工弹窗批准

适合的任务

适合流程固定、高频重复且需跨工具调用的活

情报巡检定期访问固定官网、Changelog 或社媒出摘要表
线索清洗CRM 捞目标账户，结合公开信息起草外联信供审核
财务对账每周核对发票，标记缺票并催收
缺陷复现读 Issue 在预发布环境模拟复现，提取日志与截图
经营晨报每天汇总库存、订单与流量指标，揪出异常点

不适合的任务

别硬塞不匹配的活，容易白耗每周额度甚至失控

即时问答查报错、翻短文用普通网页模型几秒搞定，不用云电脑
本地写码断点调试与 Git 冲突放本地 Codex CLI 或 Claude Code
生活琐事管日历、买日用品缺乏企业级数据源，硬搬很别扭
无增量轮询每 5 分钟无条件刷新会空耗推理额度
高危操作群发邮件、对外发帖、扣款支付或删库，必须留人工闸门

人工闸门：高危敏感动作能停下来等人工弹窗批准。
