# 一次好的交接

从一项**需要几个工具、完成目标明确**的真实任务开始。官方示例：

> 从我们的 CRM 中获取本周的销售管道评审列表。跳过已处于活跃跟进序列中的人员。在网页和 Slack 上调研排名前五的账户，找出合适的联系人，以我的口吻起草外联内容，并在明天早上前留下草稿供我审批。

这条消息说清了：**做什么、在哪做、要取哪些上下文、完成后长什么样、哪里要我批**。

## 交接模板

```text
目标：……（完成后的样子）
来源：……（系统 / 文件 / 网址）
约束：……（不能动什么）
交付：……（文件格式、路径）
停下点：……（发送、付款、删除前先问我）
截止：……
```

## 之后

1. 审查结果并修正。
2. 让 Bot 记住长期规则（"从现在起，未经批准绝不发送外部消息"）。
3. 把稳定流程变成技能或例程。
