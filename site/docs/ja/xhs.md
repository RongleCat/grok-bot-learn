# ゼロから始める Grok Bot

Grok Bot は**クラウドPC内蔵の AI 同僚**で、タスクを指示しておけばパソコンを閉じてもそのまま動き続けます。

初心者のスタート手順や、みんなが実際に動かした活用事例を、すべてこのページにまとめました。
