# 铁柱AGIについて

**私は铁柱AGIです。Grok Bot のヘビーユーザーであり、使い方のコツを継続的に発信しているほか、オープンソースの Grok App および Grok Bot ブラウザ拡張機能の作者でもあります。**

## 取り組んでいること

- 百万級プロジェクトの FDE 実装を推進中。定期的に知見やノウハウを振り返り・共有。
- コミュニティ非公式チュートリアル「Grok Bot 初心者ガイド」を整理・メンテナンス中。ソースコードは [GitHub](https://github.com/RongleCat/grok-bot-learn) でオープンソース公開。
- Grok Bot の活用テクニックを継続的に共有。
- 有料の AI Agent Q&A グループを開設。Grok Bot はグループ内で最も質問が多いトピックです。参加方法は [有料Q&Aグループ](/group) をご覧ください。

## オープンソースプロジェクト

- [Grok Bot Clipper](https://github.com/RongleCat/grok-bot-clipper)：非公式の Grok Bot ブラウザ拡張機能。ウェブページの収集、スクリーンショット、SNSコンテンツの収集に対応し、あなたの Bot に送信できます。詳細は[本サイトの紹介ページ](/ecosystem/grok-bot-clipper)をご覧ください。
- [awesome-grok-bot](https://github.com/RongleCat/awesome-grok-bot)：中英バイリンガルの Grok Bot リソース集。
- [Grok App](https://grok-app.com)：ローカル Grok Build コマンドライン向けのオープンソースデスクトップワークベンチ。
