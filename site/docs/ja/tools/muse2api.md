# muse2api

<ToolMeta id="muse2api" />

コミュニティによるオープンソースの muse.ai リバースラッパープロジェクトであり、**クラウドPC** 上で OpenAI 互換インターフェースを経由してWeb版の無料枠を直接呼び出し、対話、画像生成、動画生成を行うのに適しています。

結論として、本ツールはクラウドPC上で互換インターフェースを介して対話、画像生成、動画生成を行う目的にのみ使用されます。

## Bot に送信するプロンプト

以下の内容をすべてコピーして Grok Bot に送信してください。クラウドPC上で自動的にインストールおよび検証が行われ、ログインやAPIキーの設定が必要な場合は一時停止してあなたの操作を待ちます。

<div class="tool-prompt">

````text
帮我在你的云电脑上部署 muse2api（https://github.com/czg86389-hub/muse2api），以后调用多模态接口进行对话、生图和生视频用它。需要填密钥时请提醒我自己填。
````

</div>

## 自身で行う作業

- muse.ai のアカウントを用意し、クラウドPCのブラウザでログインを完了する。
- 案内に従って通信キーやログイン状態データを自身で入力する。
