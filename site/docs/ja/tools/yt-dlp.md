# yt-dlp

<ToolMeta id="yt-dlp" />

yt-dlp は数千以上のサイトに対応したコマンドライン動画・音声ダウンロードツールで、Bot に**動画の一括ダウンロードや音声の抽出**を行わせ、その後の文字起こし処理などに活用するのに適しています。

## Bot に送信するプロンプト

以下の内容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われます。ログインやキーの設定が必要な場合は一時停止して操作待ちとなります。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 yt-dlp（https://github.com/yt-dlp/yt-dlp），以后批量下载音视频和提取音频用它。
````

</div>

## 自身で行う作業

- ダウンロード対象となるメディアのリンクを準備する。
- ログインが必要なサイトの場合は、対応する Cookie ファイルをエクスポートして用意しておく。
