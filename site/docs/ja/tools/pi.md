# Pi Coding Agent

<ToolMeta id="pi" />

極めてシンプルかつ高度に拡張可能なターミナルコーディング Agent で、**拡張機能、スキル、プロンプトテンプレートによる独自の開発ワークフローの高度なカスタマイズ**に適しています。
拡張機能、スキル、プロンプトテンプレートを活用して独自の開発フローをカスタマイズしたいギークな開発者に最適です。

結論として：本ツールは、拡張機能、スキル、プロンプトテンプレートを通じて、極めてシンプルで拡張性の高い独自のターミナルコーディング Agent ワークフローを高度にカスタマイズするためにのみ使用されます。
