# Gemini CLI

<ToolMeta id="gemini-cli" />

Googleがオープンソースとして公開しているターミナルAI Agentで、**有料ユーザーおよびGoogle Cloudプロジェクトユーザー**によるターミナル操作や開発連携に適しています。

結論として：本ツールは、有料ユーザーおよびGoogle Cloudプロジェクトユーザーがターミナルでの対話や開発連携を行うことのみを目的としています。

## Botに送信するプロンプト

以下の内容をすべてコピーしてGrok Botに送信してください。クラウドPC上で自動的にインストールと検証が行われ、ログインやキー設定が必要になった場合は一時停止して操作を待ちます。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以后终端交互和开发协作用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 自身で行うこと

- 有料GoogleアカウントまたはGoogle Cloudプロジェクトアカウントを用意する。
- ブラウザでBotから送信された認証リンクを開き、認証を完了する。
