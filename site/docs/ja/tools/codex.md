# Codex CLI

<ToolMeta id="codex" />

OpenAI 公式ターミナルコーディング Agent。**コード修正、スクリプト実行、画像生成・画像確認**に適しており、ChatGPT のサブスクリプション利用枠を直接使用できます。
コード修正、スクリプト実行、画像生成・画像確認を行いたい ChatGPT サブスクリプションユーザーに最適です。


## Bot に送信するプロンプト

以下の内容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われ、ログインやキー設定が必要な場合は一時停止して操作を待ちます。

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Codex CLI（https://developers.openai.com/codex/cli），用我的 ChatGPT 账号登录，以后写代码、跑脚本和生图用它。需要我授权时把链接发给我。
````

</div>

## ご自身で行う作業

- ChatGPT アカウントを用意し、デバイスコードログイン権限が有効になっていることを確認します。
- ブラウザで Bot から送信されたデバイスコードのリンクを開き、確認を完了します。
