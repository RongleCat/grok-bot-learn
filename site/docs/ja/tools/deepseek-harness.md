# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

DeepSeek 公式がオープンソースで提供する**「すべてがプラグイン」アーキテクチャの Agent** で、デスクトップおよび Web UI をサポートしています。現在は開発者プレビュー段階にあり、**コード作成**、**調査・分析**、**日常業務**、**定期タスクの拡張**に適しています。

## Bot に送信するプロンプト

以下の内容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われます。ログインやキーの設定が必要な場面では一時停止し、あなたの操作を待ちます。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以后日常办公、调研、写代码和跑定时任务用它。需要配置 DeepSeek API Key 时请停下来提醒我自己填。
````

</div>

## ご自身で行う作業

- DeepSeek API Key を用意する
- Bot のインストール完了後、設定画面で各自 API Key を入力する
