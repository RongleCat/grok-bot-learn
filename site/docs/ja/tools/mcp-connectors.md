# MCP コネクタ

<ToolMeta id="mcp-connectors" />

MCP コネクタは外部サービスとモデル間の通信チャネルを開通させ、Bot が**外部ツールやクラウドデータを直接呼び出して**複雑な連携を行うのに適しています。

結論として：本ツールは、Bot が外部ツールやクラウドデータを直接呼び出して複雑な連携を行う目的のみに使用されます。

## Bot に送信するプロンプト

以下の内容を丸ごとコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われ、ログインやキー設定が必要な場合は一時停止して操作を待機します。

<div class="tool-prompt">

````text
帮我在你的云电脑上接入 MCP 连接器（https://docs.x.ai/grok/connectors），以后调用外部工具和同步云端数据用它。需要第三方授权时把链接发给我，需要填密钥时请提醒我自己填。
````

</div>

## ご自身で行う作業

- ブラウザでコネクタの管理ページにアクセスし、接続対象のアカウントを準備する。
- 指示に従って対象サービスのアドレスや認証キーを自分で入力する。
