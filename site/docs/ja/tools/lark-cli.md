# 飛書 CLI（lark-cli）

<ToolMeta id="lark-cli" />

飛書公式のコマンドラインツール。Bot が個人アカウントとして **クラウドPC** 上で飛書ドキュメント、Base（多次元テーブル）、クラウドドライブ、ナレッジベースを操作するのに適しています。
Bot が個人アカウントとしてクラウドPC内で飛書ドキュメント、Base、クラウドドライブ、ナレッジベースを操作します。
Bot が個人アカウントとしてクラウドPC上で飛書ドキュメント、Base、ドライブの資産を管理することを希望するユーザーに適しています。


## Bot に送信するプロンプト

下記の内容をそのままコピーして Grok Bot に送信してください。クラウドPC上で自動的にインストールと検証が行われます。ログインやキー設定が必要になった場合は一時停止し、あなたの操作を待ちます。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置飞书 CLI（https://github.com/larksuite/cli），以后操作飞书云文档、多维表格和云盘用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## ユーザー自身で行う作業

- 飛書の個人アカウントを用意する。
- 認証リンクを開き、ターミナルに表示されたデバイスコードを入力して承認を完了する。
