# 固定出口プロキシ（SSHトンネル）

<ToolMeta id="egress-proxy" />

固定出口プロキシは、SSH の動的ポートフォワーディングを利用してローカル SOCKS5 プロキシを構築するもので、Bot が**地域制限のあるサービスにアクセスする**際に安定した送信元 IP を維持するのに適しています。

## Bot に送信するプロンプト

以下の内容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われ、ログインや秘密鍵の設定が必要な場合は一時停止して操作を促します。

<div class="tool-prompt">

````text
帮我在你的云电脑上配置基于 SSH 隧道的固定出口代理（https://man.openbsd.org/ssh），以后访问受地域限制的服务用它。需要填服务器地址和私钥时请提醒我自己填。
````

</div>

## 自身で行う必要があること

- SSH 秘密鍵でのログインに対応した海外サーバーを 1 台用意する。
- 指示に従い、ログイン秘密鍵と接続情報を自身で機密ファイルに書き込む。
