# Cursor CLI

<ToolMeta id="cursor-cli" />

Cursor 公式のコマンドライン Agent。**クラウド PC 上で小規模なコード変更を実行する** のに適しており、Bot の利用枠を全体的な意思決定のために残しておくことができます。

## Bot に送信するプロンプト

以下の内容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われ、ログインやキー設定が必要な場合は一時停止して操作を待ちます。

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 自身で行う必要があること

- Cursor アカウントまたは関連する認証情報を用意する。
- ブラウザで Bot から送られた認証リンクを開き、ログインを完了する。
