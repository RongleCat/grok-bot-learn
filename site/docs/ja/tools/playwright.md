# Playwright

<ToolMeta id="playwright" />

Playwright は Microsoft がオープンソースで公開している自動化ライブラリです。Bot に **ウェブページの大量スクリーンショット撮影やレンダリング・スクレイピング** を実行させるのに適しており、手動でブラウザ操作の利用枠を消費する必要がありません。

## Bot に送信するプロンプト

以下の内容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われます。ログインや API キーの設定が必要な場合は、一時停止してあなたの操作を待ちます。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Playwright（https://playwright.dev/python/docs/intro），以后网页渲染、截图和抓取任务用它。
````

</div>

## 自分で対応が必要なこと

- クラウド PC に Python 実行環境が備わっていることを確認する。
