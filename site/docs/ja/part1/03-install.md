# 第 3 章 インストール・ログインと最初の Bot

**サブスクリプションに Bot の利用権限が含まれていることを確認してください**。含まれていない場合、入口（メニュー）が表示されません。ログインがループする場合はプライバシー設定を確認してください。制約のない「万能アシスタント」を作って週間クォータを無駄に消費しないようにしましょう。

1. デスクトップ版とモバイル版をインストールし、ログインエラーを解消する
2. **専用 Bot を作成し、6行の契約（指示規約）を入力する**
3. 最初のファイル保存タスクを発行し、チェックリストに沿って検収する


![インストール・ログインと最初の Bot](/info/03-install.png)

## サブスクリプションプランの確認と利用条件

ダウンロードする前にアカウント資格を確認してください。**Grok Bot は有効なサブスクリプションと紐付いていなければ使用できません**。

| プラン名 | 価格 | Grok Bot の有無 | クォータ説明 |
| :--- | :--- | :--- | :--- |
| The X Plus | $8 / 月 | なし | 通常モデルの対話のみ、Bot 権限なし |
| The X Premium | $30 / 月（年払い $300） | あり | 4x クォータ、個人の入門に最適な最低ライン |
| The X Super | $100 / 月（年払い $1000） | あり | 15x クォータ |
| The X Ultra | $200 / 月（年払い $2000） | あり | 50x クォータ |
| Cursor Pro / Pro+ / Ultra | 公式サイトの価格を参照 | あり | プランに応じて週間クォータを提供 |
| Cursor Teams (セルフサービス席) | 公式サイトの価格を参照 | あり | メンバー間でチームクォータを共有 |

- **月額 8 ドルの Plus プランには Bot の利用権限が含まれていません**。購入しても利用できません。
- **X 連携クォータと Cursor サブスクリプションのクォータは合算されません**。システム決済では、週ごとの使用量が多い方が自動的に適用されます。

プランの基盤メカニズムについては、コミュニティ記事[『1.1 Grok Bot 是什么：一页看懂』](https://jcng5q8n0f3z.feishu.cn/wiki/I04Gw3wEaisftUkBikxcg43rnpc)および[『万文长｜Grok Bot 从零入门第一次上』](https://jcng5q8n0f3z.feishu.cn/wiki/Zs1JwANRgiOvJ4klrADcMxJ9nzg)を参照してください。

## デスクトップ版のダウンロードとインストール

![デスクトップ版のダウンロードとインストール](/info/03-install-s2.png)

macOS は Apple silicon（M シリーズ）および Intel をサポートし、Windows と Linux は x64 および Arm64 をサポートしています（Windows ではハードウェアアクセラレーションの有効化を推奨）。

1. `cursor.com/dashboard/bot` にログインするか、直接 `x.ai/bot` にアクセスしてインストーラーをダウンロードします。**会社の端末で権限がない場合は、管理者に問い合わせてください**。
2. macOS ではダウンロードしたアプリケーションを `Applications` フォルダにドラッグし、Windows と Linux ではインストールウィザードを実行します。
3. **クライアントを起動してログイン画面が表示されれば完了です**。具体的な手順はドキュメント [Grok Bot 快速入门](https://cursor.com/cn/docs/grok-bot/get-started) を参照してください。

## アカウントログインとプライバシーモードの設定

1. クライアントを起動して **ログイン** をクリックし、ブラウザで直接 Cursor アカウントを用いて認証します。エンタープライズ SSO は自動的に適用されます。Grok Business シートの場合は、**Sign in with Grok** を選択してログインしてください。
2. 認証完了後にクライアントの「設定」を開き、アカウントのメールアドレスとプランステータスが表示されていれば成功です。

**旧版のプライバシーモード（Privacy Mode (Legacy)）は現行の Privacy Mode に切り替えないと続行できません**。個人ユーザーはポップアップで確認をクリックするだけです。チームメンバーの場合は、管理者に Team Settings で更新してもらう必要があります。

詳細な手順は公式ドキュメント [入职](https://cursor.com/cn/help/grok-bot/onboarding) および [登录 Grok Bot](https://cursor.com/cn/help/grok-bot/sign-in) を参照してください。

## よくあるログイン問題とトラブルシューティング

やみくもに再インストールしても意味はありません。多くはキャッシュやセッション更新の問題です。

1. クライアントを最新バージョンにアップデートして再ログインする。
2. `cursor.com` と `x.ai` の Cookie を削除するか、シークレットモードを使用する。
3. `x.ai/bot` にログインし、Web 版でセッションが確立できるか確認する。
4. サブスクリプションを変更した直後は **30〜60 分ほど待機** し、更新後にエラーが解消されるのを確認する。

SMS/電話番号の認証に連続して失敗するとリスク管理機能によりロックされ、自動復旧しません。トラブルシューティングを行っても解決しない場合や OAuth エラーが発生する場合は、**サポートページからチケットを起票** し、メールアドレス、スクリーンショット、バージョン、手順を明記してください。

詳細は [登录 Grok Bot](https://cursor.com/cn/help/grok-bot/sign-in) を参照してください。

## iOS モバイル版のインストールと双端連携

### インストールとログイン
1. システム要件は **iOS 18 またはそれ以降** です。
2. App Store で Grok Bot を検索してインストールし、同じ Cursor アカウントでログインすると自動同期されます。**追加の支払いは不要です**。

### デバイス間の役割分担
- モバイル版は日常のモニタリングに適しており、リアルタイム画面の確認、認証コード入力時の制御引き継ぎ（Take over）、承認（Allow / Deny）、Routine の開始・停止に対応しています。
- **高度な操作はデスクトップ版に戻る必要があります**：最長 10 分間の画面録画ティーチング（Teach a task）、Routine のテスト実行（Test run）、クラウド PC のメンテナンス（Update / Recover）。

### 通知管理
- **個別の Bot をミュート**：チャット画面上部の名前をタップして **Notifications** をオフにします（デスクトップ版からメッセージを送信してもオフにできます）。
- **一括オフ**：端末の「設定」で Grok Bot の通知権限をオフにします。

詳細は [移动端 Grok Bot](https://cursor.com/cn/help/grok-bot/mobile) を参照してください。

## 共有基盤の仕組みを理解し、最初の Bot を作成する

![共有基盤の仕組みを理解し、最初の Bot を作成する](/info/03-install-s6.png)

有料ユーザーにはそれぞれ常駐型のクラウド仮想マシンが 1 台提供され、独立した Linux、ブラウザ、ターミナル、永続ディスクが備わっています（初期テスト環境の構成は約 8 コア・16GB メモリですが、公式未確認のため実際のスペックに準じます）。

このマシンには、操作に直接影響する 3 つの物理的境界があります：
- **すべての Bot が同一マシンを共有**：`/workspace` および一連のブラウザログインセッションを共用します。Bot を分けるのは担当業務を切り分けるためだけであり、セキュリティ上の分離はありません。
- **Bot 間連携にはファイルのディスク保存が必須**：チャット履歴は相互に共有されないため、Bot A が成果物を `/workspace` のファイルに書き込み、それを Bot B が読み込んで引き継ぐ必要があります。
- **常時モニタリングとリアルタイムの制御引き継ぎに対応**：画面右側にクラウド PC の画面を展開でき、パスワード入力、キャプチャ認証（CAPTCHA）、決済認証が発生した場合はいつでも操作を引き継げます。認証情報を入力欄に直接書き込まないでください。

初回ログイン時にはデフォルトの **Grok Bot** が自動生成されます。手動での新規作成と設定手順は以下のとおりです：

1. **新規作成**：サイドバー上部の **+**（または Cmd+N）をクリックし、**创建新 Bot**（Create new Bot）を選択します。入力欄にあらかじめ名前を入力してそのまま作成をクリックすることも可能です。
2. **名前の変更とラベル**：右クリックして **重命名机器人** を選択するか、上部の名前をクリックしてパネルを展開し編集します。下部で役職ラベル（Label、モバイル版では Title (optional)）を設定できます。
3. **アバターの変更**：上部の名前をクリックして詳細画面を開き、アバターをクリックします。プリセットの幾何学図形の選択、プロンプト入力による生成、または 25 MB 以下のローカル画像のアップロードが可能です（モバイル版では写真ライブラリからの選択、生成、削除が選択可能）。
4. **役割・責務の設定**：**個人向け Bot では個別の設定ページが廃止されたため、長期的なルールは最初のメッセージで直接説明し、それを記憶するよう指示します**。チーム向け Bot では詳細の「About」欄に固定の説明文エリアが引き続き用意されています。

- [更改 Bot 的名称、头像和职责](https://cursor.com/cn/help/grok-bot/edit-bot)
- [《万字长文｜Grok Bot 从入门到精通｜金尘马》](https://jcng5q8n0f3z.feishu.cn/wiki/MIKpwiUXpiE9mWkyG8ccFM6Znee)

## 役割・責務の記述：標準6行契約

### 契約の構造とテンプレート

初心者は曖昧な肩書きを与えるのを避け、**6 つの重要制約を最初のメッセージに直接記述**して、長期ルールとして記憶させましょう。

1. Own（担当領域・責任）：長期的に責任を持つ具体的な指標を明確にし、汎用アシスタントにしない。
2. Sources（情報源）：公式サイトや指定リンクのみを参照するよう限定し、不明な情報源の使用を禁止する。
3. Output（納品フォーマット）：保存パス、命名規則、要約の文字数を規定する。
4. Approval（承認基準・レッドライン）：メール送信、フォーム送信、ファイル削除などの高リスクな操作は、必ず手動のポップアップ承認を待つ。
5. Failure（例外処理・フォールバック）：Web ページのリンク切れやデータ欠損が発生した場合は明確に明記し、憶測による補完を厳禁とする。
6. Never（絶対禁止事項）：元ファイルの変更禁止、記憶に基づく概括の禁止、支払いボタンのクリック禁止。

Bot に名前を付けたら、テンプレートの項目を置き換えてそのまま送信します。

::: details 契約の構造とテンプレート
```text
请牢记你的长期工作职责，在今后的工作中始终遵循以下要求：

Own: 负责监控目标清单的每周功能与定价变动，输出结构化对比材料。
Sources: 仅限使用目标官方网站的定价页、Changelog 页面以及我通过附件提供的官方说明文档。
Output: 提炼核心动态，附带核对日期与原始出处链接，长文本与数据表格必须保存至 /workspace/research/ 下的 Markdown 文件中，对话框中只发简要完成汇报。
Approval: 涉及发送任何邮件、对外发帖、提交表单、删除文件或进行任何费用支付前，必须停下来等待我的人工批准。
Failure: 若目标页面无法访问或内容缺失，在报告中明确标注为“未取得一手数据”，严禁推测或编造任何功能与价格。
Never: 严禁修改我上传的任何源文件，在源系统可访问时严禁依赖自身训练记忆进行主观概括。

今后的工作中请记住这些要求。
```
:::

### 実践事例

- 金尘马は [《万字长文｜Grok Bot 从入门到精通｜金尘马》](https://jcng5q8n0f3z.feishu.cn/wiki/MIKpwiUXpiE9mWkyG8ccFM6Znee) において、**長期的な責務と単発の要望を厳格に分けています**。

  長期ルールで情報源と納品形式を管理し、その都度のメッセージでは具体的な調査テーマのみを発行します。一次データが不足している場合は直接説明させ、数値の推測は厳禁としています。
- Today は [《万文长｜Grok Bot 从零入门第一次上》](https://jcng5q8n0f3z.feishu.cn/wiki/Zs1JwANRgiOvJ4klrADcMxJ9nzg) において安全境界を設定し、**読み取り専用の操作と外部に影響を及ぼす操作を分離しています**。

  1 回につき 1 つの競合製品のみを調査し、公開されている情報源のリンクを添え、事実と推測を明確に区別します。ログインや決済に関わる操作は一律で停止し、確認を待ちます。

進化ルールの詳細は [《1.1 Grok Bot 是什么：一页看懂》](https://jcng5q8n0f3z.feishu.cn/wiki/I04Gw3wEaisftUkBikxcg43rnpc) を参照してください。

## 最初の実タスクの発行

![最初の実タスクの発行](/info/03-install-s8.png)

**まずは小さなタスクから始めましょう**。タスクを書く際は 5 つの要素を押さえます：目標と入力を明確に伝える、厳格な読み取り専用（元ファイルの変更、登録、支払いの禁止）、ディスク保存仕様の策定、制御引き継ぎポイントの明示。

添付ファイルの要約には次を送信します：
```text
用五个要点总结这份文档。
在单独的部分列出每个日期、决策和未解决的问题，并为每项注明对应章节出处。
不要更改源文件。
```

競合の価格調査とディスク保存には次を送信します：
::: details 最初の実タスクの発行
```text
【目标】
调研 3 款主流代码编辑器（Cursor、VS Code、Zed）在 2026 年的最新公开定价方案与核心 AI 功能，产出一份选型对比参考材料。

【材料】
1. 仅限使用上述三款产品官方网站的定价页、功能介绍页与官方文档；第三方博客仅作为辅助索引，必须找到官方页面核实。
2. 记录每一项数据的原始官方 URL 与数据核对日期。

【边界】
1. 纯只读检索，严禁注册任何账号，严禁开启任何试用，严禁输入任何支付信息。
2. 遇到需要登录才能查看的页面，直接跳过并记录在未核实清单中。
3. 严禁改动 /workspace 下已有的其他项目文件。

【交付规格】
1. 在 /workspace/editor-research/ 目录下生成对比报告文件 comparison.md。
2. 报告内包含一张 Markdown 数据表格，表头列定义为：产品名称、方案档位、月付价格、年付价格、核心功能特征、官网来源链接、核对日期。
3. 表格下方附带一份 400 字以内的中文总结，指出各产品主要差异，并单独开辟一节列出“未核实或存在矛盾的信息”。
4. 对话框中仅需回复已完成落盘的简短提示及文件绝对路径。

【暂停确认节点】
1. 遇到必须登录、验证码拦截或点击付费的操作时，立刻停下并提示我接管。
2. 官网信息前后出现明显矛盾且无法核实时，停下说明情况由我判断。
```
:::

ログイン、2FA、またはスライダー認証が発生した場合：
1. **Take over をクリックして手動で対応**し、完了したら I'm done をクリックして続行、スキップする場合は Skip をクリックします。
2. 実行完了後、**`/workspace/editor-research/comparison.md` が完全に保存されていることを確認**します。

仕様・ガイドラインは [使用 Grok Bot](https://cursor.com/cn/docs/grok-bot/get-started) および [入职](https://cursor.com/cn/help/grok-bot/onboarding) を参照してください。

## 陥りやすい落とし穴

1. 8 ドルの Plus プランには Bot がありません。**月額 30 ドルの Premium プランを選択する必要があります**。
2. すべての Bot がクラウド PC とクォータを共有します。まずは 1 つの Bot を確実に動作させ、十数個も作って競合させないようにしましょう。
3. チャット欄にパスワードや API Key を送信してはいけません。Take over による制御引き継ぎで入力するか、セキュリティカードに入力してください。
4. 長文テキストはコンテキストの汚染を防ぐため、**すべて `/workspace` 配下の Markdown ファイルに保存**してください。
5. ログインエラーが発生しても再インストールせず、`cursor.com` と `x.ai` の Cookie を削除するか、30〜60 分待機してください。
6. **異なる Bot 間でも仮想マシンとブラウザセッションが共有される**ため、権限を分離することはできません。
7. Teach a task、Test run、システムの復元はデスクトップ版限定の機能であり、iOS 版にはありません。

## 完了後の検収方法

1. Usage & Billing を開き、有料プランが有効で利用量が正常であることを確認する。
2. デスクトップ版の右側画面が正常に立ち上がり、Reconnecting エラーが出ないことを確認する。
3. iPhone（iOS 18+）で同一の Cursor アカウントにログインし、再購入を促す表示が出ないことを確認する。
4. 6行契約を送信し、Bot が長期ルールを記憶したことを明確に返答することを確認する。
5. クラウド PC の `/workspace` に指示どおりターゲットファイルが生成されていることを確認する。
6. ログインなどの操作に遭遇した際、Bot が自発的に一時停止し **Action needed** カードを表示することを確認する。
7. 意図的に無効なリンクを渡し、レポートに **未取得一手数据** と明確に記載され、捏造がないことを確認する。
