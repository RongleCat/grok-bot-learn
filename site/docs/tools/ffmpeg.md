# FFmpeg

<ToolMeta id="ffmpeg" />

FFmpeg 是多媒体底层处理的核心工具，适合让 Bot 完成 **音视频转码、压缩、截帧与音频提取**。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 FFmpeg（https://ffmpeg.org/download.html），以后处理音视频转码、剪辑、压缩和截帧用它。
````

</div>
