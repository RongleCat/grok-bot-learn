# FFmpeg

<ToolMeta id="ffmpeg" />

FFmpeg 是多媒体底层处理的核心工具，适合让 Bot 完成**音视频转码、压缩、截帧与音频提取**。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

<div class="tool-prompt">

````text
请你在云电脑中使用系统包管理器安装 FFmpeg。

1. 目标：在云电脑中完整部署 FFmpeg 工具链。
2. 参考命令：
- 更新软件源：sudo apt-get update
- 安装软件包：sudo apt-get install -y ffmpeg
3. 密钥与授权原则：遇到登录、授权、填密钥等只能我来做的步骤时，请先停下，把授权链接或验证码原样发给我，或请我把密钥填进本地私密文件，不要让我把密钥贴进聊天，不要打印密钥。
4. 常见坑及处理办法：
- 云电脑重置系统后通过 apt 安装的软件可能会丢失，建议将安装命令写入工作目录下的恢复脚本中。
- 后续若需烧录中文字幕，必须提前安装中文字体，否则字幕会显示为方块乱码。
- 大文件转码耗时长且占用较多资源，建议放后台运行并记录输出日志。
5. 安装完成标准：执行验证命令 ffmpeg -version，预期结果为正常输出 FFmpeg 版本号及构建配置信息。
6. 执行完成后，用几句话向我汇报安装与验证结果。
````

</div>

- 若有中文字幕烧录需求提前准备中文字体包
