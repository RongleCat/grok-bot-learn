# muse2api

<ToolMeta id="muse2api" />

社区开源的 muse.ai 逆向封装项目，适合在 **云电脑** 上通过 OpenAI 兼容接口直接调用网页端免费额度进行对话、生图和生视频。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上部署 muse2api（https://github.com/czg86389-hub/muse2api），以后调用多模态接口进行对话、生图和生视频用它。需要填密钥时请提醒我自己填。
````

</div>

## 需要你自己做的事

- 准备 muse.ai 账号并在云电脑浏览器中完成登录。
- 根据提示自行填入通信密钥与登录状态数据。
