# yt-dlp

<ToolMeta id="yt-dlp" />

yt-dlp 是支持上千个站点的命令行音视频下载工具，适合让 Bot **批量下载视频或抽取音频** 以供后续转写处理。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 yt-dlp（https://github.com/yt-dlp/yt-dlp），以后批量下载音视频和提取音频用它。
````

</div>

## 需要你自己做的事

- 准备需要下载的目标媒体链接。
- 遇到需登录的站点时导出对应 Cookie 文件备用。
