# Pi Coding Agent

<ToolMeta id="pi" />

极简且高度可扩展的终端编码 Agent，适合 **通过扩展、技能与提示模板深度定制** 专属开发工作流。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Pi Coding Agent（https://pi.dev），以后定制开发工作流和写代码用它。需要填密钥时请提醒我自己填。
````

</div>

## 需要你自己做的事

- 准备对应模型服务商的 API Key。
- 收到提示后自行将密钥写入私密配置文件。
