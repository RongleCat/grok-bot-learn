# MCP 连接器

<ToolMeta id="mcp-connectors" />

MCP 连接器打通了外部服务与模型的交互通道，适合让 Bot **直接调用外部工具与云端数据**完成复杂协同。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

<div class="tool-prompt">

````text
请你指导我完成 Grok MCP 连接器的接入与配置。

1. 目标：接入官方内置连接器、第三方 OAuth 连接器或自定义 MCP 服务器。
2. 参考命令：本功能由平台原生提供，无需在云电脑终端执行命令行安装。
3. 密钥与授权原则：遇到登录、授权、填密钥等只能我来做的步骤时，请先停下，指导我前往 grok.com/connectors 页面点击 New Connector 完成 OAuth 授权或填写 Custom MCP 服务器 URL 及认证信息，不要让我把密钥贴进聊天，不要打印密钥。
4. 常见坑及处理办法：
- MCP 服务器必须能从公网访问，直接运行在本机或云电脑 localhost 上的服务无法被 Grok 接入，必须使用隧道服务暴露公网地址。
- 自定义 MCP 服务器必须做好鉴权机制，切勿将未受保护的内部接口裸露在公网。
- 遵循最小权限原则，只勾选和授权必要的权限范围。
- 若使用商业版或企业版账号，需先联系团队管理员在控制台开通连接器权限。
5. 完成标准：在 grok.com/connectors 添加成功后，Grok 能够自动发现该服务器暴露的工具，并在对话中成功调用。
6. 梳理完毕后，用几句话向我汇报配置流程与检查要点。
````

</div>

## 需要你自己做的事

- 在浏览器中访问 grok.com/connectors 页面
- 准备待授权的第三方账号或公网可访问的自定义 MCP 服务器地址
- 商业版或企业版需确认管理员已在控制台开启连接器功能
