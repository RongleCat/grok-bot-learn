# 제3장 설치, 로그인 및 첫 번째 Bot

**구독에 Bot 혜택이 포함되어 있는지 확인하세요.** 그렇지 않으면 진입 메뉴가 없습니다. 로그인이 무한 반복된다면 개인정보 설정을 확인하세요. 제약 조건 없는 "만능 어시스턴트"를 만들어 주간 크레딧을 낭비하지 마세요.

1. 데스크톱 및 모바일 앱을 설치하고 로그인 오류를 해결합니다.
2. **전용 Bot을 생성하고 6줄 계약서를 작성합니다.**
3. 파일 저장을 포함한 첫 번째 작업을 지시하고, 체크리스트를 통해 검수합니다.

## 구독 플랜 확인 및 활성화 조건

다운로드 전에 먼저 계정 자격을 확인하세요. **Grok Bot은 반드시 유효한 구독과 연동되어 있어야만 사용할 수 있습니다**.

| 플랜명 | 가격 | Grok Bot 포함 여부 | 한도 설명 |
| :--- | :--- | :--- | :--- |
| The X Plus | $8 / 월 | 아니요 | 일반 모델 대화만 가능, Bot 권한 없음 |
| The X Premium | $30 / 월(연간 결제 시 $300) | 예 | 4배 한도, 개인 입문 최소 요건 |
| The X Super | $100 / 월(연간 결제 시 $1000) | 예 | 15배 한도 |
| The X Ultra | $200 / 월(연간 결제 시 $2000) | 예 | 50배 한도 |
| Cursor Pro / Pro+ / Ultra | 공식 홈페이지 가격 참조 | 예 | 등급에 따라 주간 한도 제공 |
| Cursor Teams (셀프 서비스 시트) | 공식 홈페이지 가격 참조 | 예 | 멤버 간 팀 할당량 공유 |

- **월 $8인 Plus 등급은 Bot 혜택을 포함하지 않으므로**, 결제해도 사용할 수 없습니다.
- **X 연동 한도와 Cursor 구독 한도는 중복 합산되지 않으며**, 시스템 정산 시 매주 사용량이 더 높은 쪽을 자동으로 적용합니다.

플랜 및 인프라 메커니즘은 커뮤니티 글 [《1.1 Grok Bot이란 무엇인가: 한 페이지로 이해하기》](https://jcng5q8n0f3z.feishu.cn/wiki/I04Gw3wEaisftUkBikxcg43rnpc) 및 [《만자 가이드｜Grok Bot 기초 입문 첫걸음》](https://jcng5q8n0f3z.feishu.cn/wiki/Zs1JwANRgiOvJ4klrADcMxJ9nzg)을 참고하세요.

## 데스크톱 앱 다운로드 및 설치

![데스크톱 앱 다운로드 및 설치](/info/03-install-s2.png)

macOS는 Apple silicon(M 시리즈) 및 Intel을 지원하며, Windows와 Linux는 x64 및 Arm64를 지원합니다(Windows에서는 하드웨어 가속 활성화를 권장합니다).

1. `cursor.com/dashboard/bot`에 로그인하거나 `x.ai/bot`으로 직접 이동하여 설치 프로그램을 다운로드합니다. **회사 기기에서 권한이 없는 경우 관리자에게 요청하세요**.
2. macOS는 다운로드한 앱을 `Applications` 폴더로 드래그하고, Windows와 Linux는 설치 마법사를 실행합니다.
3. **클라이언트를 실행하여 로그인 화면이 나타나면 완료된 것입니다**. 자세한 조작 방법은 [Grok Bot 빠른 시작](https://cursor.com/cn/docs/grok-bot/get-started) 문서를 참고하세요.

## 계정 로그인 및 프라이버시 모드 설정

1. 클라이언트를 실행하고 **로그인**을 클릭한 뒤 브라우저에서 Cursor 계정으로 직접 인증하면 기업 SSO가 자동으로 적용됩니다. Grok Business 시트인 경우 **Sign in with Grok**을 선택하여 로그인하세요.
2. 인증이 완료된 후 클라이언트 "설정"으로 들어가 계정 이메일과 플랜 상태가 보이면 성공입니다.

**구버전 프라이버시 모드(Privacy Mode (Legacy))는 현재의 Privacy Mode로 전환해야 계속 진행할 수 있습니다**. 개인 사용자는 팝업 창에서 확인을 클릭하면 되며, 팀 멤버는 관리자에게 Team Settings에서 업데이트하도록 요청해야 합니다.

자세한 내용은 공식 문서 [온보딩](https://cursor.com/cn/help/grok-bot/onboarding) 및 [Grok Bot 로그인](https://cursor.com/cn/help/grok-bot/sign-in)을 참고하세요.

## 자주 묻는 로그인 문제 및 문제 해결

무작정 재설치하는 것은 도움이 되지 않으며, 대부분 캐시나 세션 갱신 문제입니다.

1. 클라이언트를 최신 버전으로 업데이트하고 다시 로그인합니다.
2. `cursor.com`과 `x.ai`의 쿠키를 삭제하거나 시크릿 창을 사용합니다.
3. `x.ai/bot`에 로그인하여 웹에서 세션이 정상적으로 생성되는지 확인합니다.
4. 구독을 방금 변경했다면 **30~60분 정도 기다린 후**, 새로고침하면 오류가 사라집니다.

휴대폰 인증에 연속으로 실패하면 보안 위험 제어에 걸려 계정이 잠기며 자동 복구되지 않습니다. 문제 해결이 되지 않거나 OAuth 오류가 발생하면 **지원 페이지에서 티켓을 제출**하고, 이메일과 스크린샷을 첨부하여 버전 및 재현 단계를 명시하세요.

자세한 내용은 [Grok Bot 로그인](https://cursor.com/cn/help/grok-bot/sign-in)을 참조하세요.

## iOS 모바일 앱 설치 및 멀티 디바이스 협업

### 설치 및 로그인
1. 시스템은 **iOS 18 이상 버전**이 필요합니다.
2. App Store에서 Grok Bot을 검색하여 설치하고, 동일한 Cursor 계정으로 로그인하면 자동으로 동기화되며 **중복 결제할 필요가 없습니다**.

### 기기별 역할 분담
- 모바일 앱은 일상적인 모니터링에 적합하며, 실시간 화면 확인, 제어 권한 인계(Take over)를 통한 인증번호 입력, 승인(Allow / Deny) 또는 Routine 시작/중지가 가능합니다.
- **심층 작업은 반드시 데스크톱 앱으로 돌아와야 합니다**: 최대 10분 화면 녹화 티칭(Teach a task), Routine 테스트(Test run), 클라우드 PC 유지보수(Update / Recover).

### 알림 관리
- **특정 Bot 음소거**: 채팅 페이지 상단의 이름을 클릭하여 **Notifications**를 끄거나, 데스크톱 앱에서 메시지를 보낼 때 끌 수도 있습니다.
- **전체 알림 끄기**: 시스템 "설정"에서 Grok Bot의 알림 권한을 끕니다.

자세한 내용은 [모바일 Grok Bot](https://cursor.com/cn/help/grok-bot/mobile)을 참조하세요.

## 공유 인프라의 이해 및 첫 번째 Bot 생성

![공유 인프라의 이해 및 첫 번째 Bot 생성](/info/03-install-s6.png)

모든 유료 사용자는 상시 가동되는 클라우드 가상 머신(VM)을 1대씩 보유하며, 독립된 Linux, 브라우저, 터미널 및 영구 디스크가 제공됩니다(초기 테스트 기준 약 8코어 16GB 메모리였으나 공식 미검증 상태이며 공식 사양 기준).

이 머신에는 작업에 직접적인 영향을 미치는 세 가지 물리적 경계가 있습니다:
- **모든 Bot은 동일한 머신을 공유합니다**: `/workspace` 및 단일 브라우저 로그인 세션을 공유하며, 여러 Bot을 두는 것은 업무 역할을 나누는 것일 뿐 보안 격리가 적용되지 않습니다.
- **Bot 간 협업 시 반드시 파일을 디스크에 저장해야 합니다**: 채팅 기록은 서로 공유되지 않으므로, Bot A가 작업 결과물을 `/workspace` 파일에 기록해야만 Bot B가 이를 읽고 이어서 작업할 수 있습니다.
- **언제든 확인 및 실시간 직접 제어 가능**: 우측에서 클라우드 PC 화면을 펼칠 수 있으며, 비밀번호, 캡차(사람 확인) 또는 결제 인증이 발생하면 언제든 직접 제어(Take over)할 수 있으므로 입력창에 자격 증명을 직접 입력하지 마세요.

최초 로그인 시 기본 **Grok Bot**이 자동 생성되며, 수동으로 새로 생성하고 설정하는 절차는 다음과 같습니다:

1. **새로 만들기**: 사이드바 상단의 **+**(또는 Cmd+N)를 클릭하고 **새 Bot 생성**(Create new Bot)을 선택합니다. 입력창에 먼저 이름을 입력한 후 바로 클릭하여 생성할 수도 있습니다.
2. **이름 변경 및 레이블**: 마우스 우클릭 후 **봇 이름 바꾸기**를 선택하거나 상단 이름을 클릭하여 패널을 열어 수정합니다. 하단에서 직무 레이블(Label, 모바일 앱에서는 Title (optional))을 설정할 수 있습니다.
3. **프로필 사진 변경**: 상단 이름을 클릭하여 상세 정보로 들어간 뒤 프로필 사진을 클릭하면 내장 지오메트리 모양 선택, 프롬프트 입력 생성 또는 25MB 이하의 로컬 이미지 업로드를 지원합니다(모바일 앱에서는 앨범 선택, 생성 또는 삭제 가능).
4. **역할 설정**: **개인 Bot은 별도의 설정 페이지가 폐지되었으므로, 장기 규칙은 첫 번째 메시지에 직접 설명하고 기억하도록 요구해야 합니다**. 팀 Bot은 상세 정보의 "정보" 탭에 고정 설명 영역이 유지됩니다.

- [Bot의 이름, 프로필 사진 및 역할 변경하기](https://cursor.com/cn/help/grok-bot/edit-bot)
- [《만자 장문｜Grok Bot 입문부터 마스터까지｜金尘马》](https://jcng5q8n0f3z.feishu.cn/wiki/MIKpwiUXpiE9mWkyG8ccFM6Znee)

## 역할 작성: 표준 6줄 계약서

### 계약서 구조 및 템플릿

초보자는 모호하고 거창한 직책을 부여하지 말고, **6가지 핵심 제약 조건을 첫 번째 메시지에 직접 작성**하여 장기 규칙으로 기억하도록 하세요.

1. Own(담당 성과): 범용 어시스턴트가 아닌, 장기적으로 책임질 구체적인 지표를 명시합니다.
2. Sources(권위 있는 출처): 공식 사이트나 지정된 링크만 참조하도록 제한하고, 불분명한 출처 사용을 금지합니다.
3. Output(산출물 형식): 저장 경로, 파일명 규칙 및 요약 글자 수를 규정합니다.
4. Approval(승인 기준선): 이메일 발송, 양식 제출, 파일 삭제 등 고위험 작업은 반드시 사람의 팝업 승인을 기다려야 합니다.
5. Failure(예외 처리 대책): 웹페이지 접근 불가나 데이터 누락 시 명확히 표기해야 하며, 임의 추측이나 날조는 엄격히 금지합니다.
6. Never(절대 금지 구역): 소스 파일 수정 금지, 훈련 기억에 의존한 주관적 요약 금지, 결제 버튼 클릭 금지.

Bot의 이름을 정한 후, 템플릿 항목을 알맞게 수정하여 바로 전송하세요.

::: details 合同结构与模板
```text
请牢记你的长期工作职责，在今后的工作中始终遵循以下要求：

Own: 负责监控目标清单的每周功能与定价变动，输出结构化对比材料。
Sources: 仅限使用目标官方网站的定价页、Changelog 页面以及我通过附件提供的官方说明文档。
Output: 提炼核心动态，附带核对日期与原始出处链接，长文本与数据表格必须保存至 /workspace/research/ 下的 Markdown 文件中，对话框中只发简要完成汇报。
Approval: 涉及发送任何邮件、对外发帖、提交表单、删除文件或进行任何费用支付前，必须停下来等待我的人工批准。
Failure: 若目标页面无法访问或内容缺失，在报告中明确标注为“未取得一手数据”，严禁推测或编造任何功能与价格。
Never: 严禁修改我上传的任何源文件，在源系统可访问时严禁依赖自身训练记忆进行主观概括。

今后的工作中请记住这些要求。
```

## 첫 번째 실제 작업 지시하기

![첫 번째 실제 작업 지시하기](/info/03-install-s8.png)

**작은 작업부터 시작하세요**. 작업을 작성할 때는 5가지 요소를 명심해야 합니다. 목표와 입력을 명확히 설명하고, 엄격한 읽기 전용(소스 파일 수정, 가입 및 결제 금지), 저장 규격 설정, 직접 제어 시점 명시.

첨부 파일 요약 시 전송 예시:
```text
用五个要点总结这份文档。
在单独的部分列出每个日期、决策和未解决的问题，并为每项注明对应章节出处。
不要更改源文件。
```

경쟁사 가격 조사 및 파일 저장 시 전송 예시:

```text

调研 3 款主流代码编辑器（Cursor、VS Code、Zed）在 2026 年的最新公开定价方案与核心 AI 功能，产出一份选型对比参考材料。

【材料】
1. 仅限使用上述三款产品官方网站的定价页、功能介绍页与官方文档；第三方博客仅作为辅助索引，必须找到官方页面核实。
2. 记录每一项数据的原始官方 URL 与数据核对日期。

【边界】
1. 纯只读检索，严禁注册任何账号，严禁开启任何试用，严禁输入任何支付信息。
2. 遇到需要登录才能查看的页面，直接跳过并记录在未核实清单中。
3. 严禁改动 /workspace 下已有的其他项目文件。
```

## 주의해야 할 함정

1. $8 Plus 등급에는 Bot이 없으므로, **반드시 월 $30인 Premium 등급을 선택해야 합니다**.
2. 모든 Bot은 클라우드 PC와 할당량을 공유하므로, 먼저 하나를 정상 작동시켜 본 뒤 사용해야 하며, 십여 개를 만들어 서로 충돌하게 두지 마세요.
3. 채팅창에 비밀번호나 API Key를 직접 입력하지 말고, Take over로 직접 제어하여 입력하거나 보안 카드를 작성하세요.
4. 긴 텍스트는 컨텍스트 오염을 방지하기 위해 **모두 `/workspace`의 Markdown 파일로 저장**하세요.
5. 로그인 오류 시 재설치하지 말고, `cursor.com` 및 `x.ai`의 쿠키를 정리하거나 30~60분 정도 기다려 보세요.
6. **서로 다른 Bot이라도 가상 머신과 브라우저 세션을 공유**하므로 권한이 격리되지 않습니다.
7. Teach a task, Test run 및 시스템 복구는 데스크톱 앱 전용 기능이며, iOS 모바일 앱에서는 지원되지 않습니다.

## 완료 후 검수 방법

1. Usage & Billing에 들어가 유료 플랜이 활성 상태이고 사용량이 정상적인지 확인합니다.
2. 데스크톱 앱 우측 화면이 정상 표시되고 Reconnecting 오류가 없는지 확인합니다.
3. iPhone(iOS 18+)에서 동일한 Cursor 계정으로 로그인했을 때 재구매 안내가 뜨지 않는지 확인합니다.
4. 6줄 계약서를 전송했을 때 Bot이 장기 규칙을 기억했음을 명확히 답변하는지 확인합니다.
5. 클라우드 PC의 `/workspace`에 지시대로 대상 파일이 생성되었는지 확인합니다.
6. 로그인 등의 작업이 발생했을 때 Bot이 자발적으로 일시 정지하고 **Action needed** 카드를 띄우는지 확인합니다.
7. 일부러 끊긴 링크를 입력했을 때, 보고서에 명확히 **미취득 1차 데이터**라고 표기하고 지어내지 않는지 확인합니다.
