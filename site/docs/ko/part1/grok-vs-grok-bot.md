# Grok과 Grok Bot의 차이점은 무엇인가요

**Grok은 대화형 어시스턴트이고, Grok Bot은 클라우드 컴퓨터에서 사용자를 대신해 일하는 상주형 AI 동료입니다.**
Grok은 질문에 답하는 역할을 담당하여 웹페이지나 앱을 닫으면 대화가 바로 종료되지만, Grok Bot은 독립된 클라우드 컴퓨터에 상주하므로 클라이언트를 닫아도 백그라운드 작업이 계속 실행됩니다.
둘 다 xAI(현재 SpaceXSI)에서 개발되었지만, 인터랙션 형태와 활용 목적은 완전히 다릅니다.

## Grok과 Grok Bot의 핵심 차이점은 무엇인가요?

**핵심 차이점은 Grok이 말로 제안만 하는 반면, Grok Bot은 클라우드 컴퓨터에서 실제로 직접 작업을 수행한다는 점입니다.**
Grok은 질문하면 대답하는 순수한 대화형 어시스턴트이며, Grok Bot은 2026년 8월 11일 xAI와 Cursor가 출시한 상주형 AI 동료(현재 베타 상태)입니다.
전체적인 개념을 파악하고 싶다면 먼저 [제1장 Grok Bot이란 무엇인가](/part1/01-what-is)를 읽어보세요.

| 구분 | Grok | Grok Bot |
| --- | --- | --- |
| 정의 | xAI의 AI 대화형 어시스턴트 | 상주형 AI 동료(AI teammates) 그룹, 현재 Beta 진행 중 |
| 사용 환경 | grok.com 웹, iOS 및 Android 앱, X의 Grok 탭 | macOS, Windows, Linux 데스크톱, iPhone, iPad, Android 모바일 |
| 작동 방식 | 질문하면 답변하는 방식, 텍스트·음성·파일 업로드 분석·이미지 및 비디오 생성 등 지원 | 텍스트나 음성 메시지로 작업을 지시하며, 브라우저·파일 시스템·터미널을 갖춘 상주형 클라우드 컴퓨터에서 여러 애플리케이션을 넘나들며 작업 수행, 승인이 필요할 때만 호출 |
| 종료 후 실행 여부 | 실행 안 됨, 사용 후 웹페이지나 앱을 닫으면 대화 종료 | 계속 실행됨, 노트북을 덮거나 앱을 닫아도 백그라운드 작업과 루틴이 계속 실행됨 |
| 웹사이트 및 소프트웨어 조작 가능 여부 | 불가능, 다른 웹사이트나 소프트웨어에서 직접 작업해주지 않음 | 가능, 자주 쓰는 웹사이트와 애플리케이션에 로그인하여 작업을 완료하며, 민감한 단계는 사용자가 Take over를 클릭하여 직접 제어 |
| 필요한 구독 등급 | 무료 체험 가능, 구독 시 한도 상향; The X Subscription 무료 플랜, Plus 플랜 이상에 포함 | The X Subscription의 Premium, Super, Ultra에 포함; Plus에는 미포함 |
| 적합한 작업 | 즉각적인 Q&A, 오류 검색, 글 작성, 이미지/비디오 생성, X 최신 동향 확인 | 프로세스가 고정되어 있고 반복 빈도가 높으며 여러 웹사이트나 소프트웨어를 넘나드는 작업(예: 공식 웹사이트 모니터링, 주간 정산, 일일 모닝 브리핑 취합, Issue 재현 등) |

**동일한 계정의 모든 Bot은 하나의 클라우드 컴퓨터를 함께 사용하며 파일, 브라우저 로그인 세션 및 애플리케이션 로그인을 공유합니다.**
각 Bot은 고유한 화면을 가지고 있지만, 공식적으로 서로 다른 Bot 간에 완전한 보안 격리가 이루어지는 것은 아니라고 안내하고 있습니다. 구체적인 동작 방식은 [제5장 공유 클라우드 컴퓨터](/part1/05-computer)를 참고하세요.
환경 설정이 필요한 경우 [제3장 설치, 로그인 및 첫 번째 Bot](/part1/03-install)을 참고할 수 있습니다.

## 언제 Grok을 쓰고, 언제 Grok Bot을 써야 할까요?

**몇 초 만에 결과를 얻을 수 있는 즉각적인 Q&A에는 Grok을, 여러 소프트웨어를 넘나들거나 정기적으로 실행하거나 여러 단계를 거쳐야 하는 반복 작업에는 Grok Bot을 사용하세요.**

**Grok에 적합한 시나리오는 즉각적인 Q&A 및 일회성 콘텐츠 생성에 집중되어 있습니다.**
예를 들어 에러 코드 확인, 짧은 글 작성, 이미지 및 비디오 생성(비디오 최대 15초), 또는 실시간 웹 검색 및 X의 최신 트렌드 탐색 등이 있습니다.
이러한 작업은 몇 초 안에 끝나므로 클라우드 컴퓨터를 동원할 필요가 없습니다.

**Grok Bot에 적합한 시나리오는 주로 정형화된 프로세스, 잦은 반복, 여러 웹사이트나 소프트웨어를 아우르는 복잡한 작업입니다.**
대표적인 작업으로는 정기적으로 공식 웹사이트를 점검하고 요약본 작성, 주간 정산, 일일 아침 브리핑 취합, Issue를 읽고 버그 재현하기 등이 있습니다.
이러한 작업은 사람이 결과를 검증할 수 있어야 하며, 고위험 작업(이메일 발송, 결제, 삭제 등)은 승인을 기다리기 위해 자동으로 멈춥니다. 비밀번호 입력, 2단계 인증, 캡차(CAPTCHA) 또는 결제 단계가 나타나면 Take over를 클릭하여 수동으로 제어할 수 있습니다.

한 번 성공적으로 실행된 프로세스는 스킬로 저장하고 루틴으로 설정해 정해진 시간에 자동으로 실행되도록 할 수 있으며, 여러 Bot이 그룹 채팅에서 협업하고 업무를 인수인계할 수도 있습니다.
**주의할 점은 고빈도 폴링이나 비디오 처리 등의 작업은 주간 사용 한도를 빠르게 소진한다는 것입니다.**
한도 계획 및 소진에 대한 세부 사항은 [제10장 한도 및 비용](/part1/10-usage)을 미리 확인하는 것을 권장합니다.

## Grok Bot을 사용하려면 어떤 구독 요금제를 구매해야 하나요?

**Grok Bot을 사용하려면 최소 월 30달러의 Premium 플랜이 필요하며, 월 8달러인 Plus 등급에는 Grok Bot이 포함되지 않습니다.**

2026년 10월부터 공식적으로 Grok, Grok Bot, Cursor, X Premium을 통합한 The X Subscription 단일 구독 플랜이 출시되었습니다.
이 구독은 Free($0), Plus(월 $8), Premium(월 $30), Super(월 $100), Ultra(월 $200)의 다섯 가지 등급으로 나뉩니다.

**Grok은 무료 등급과 Plus 등급에서도 사용할 수 있지만, Grok Bot은 Premium, Super, Ultra 등급에만 제공됩니다.**
유료 등급은 매주 Grok, Grok Bot 및 Cursor 내의 Grok 모델이 함께 공유하는 통합 사용량 풀을 제공합니다.

**기존 사용자도 Grok Bot을 바로 사용할 수 있습니다.**
기존 Cursor 유료 개인 플랜, Cursor 팀 플랜을 보유하고 있거나 SuperGrok, SuperGrok Plus, SuperGrok Heavy와 연동된 계정은 모두 Grok Bot을 즉시 사용할 수 있습니다.
자세한 구독 혜택은 [제2장 플랜 및 구독](/part1/02-plans)을 확인하세요.
