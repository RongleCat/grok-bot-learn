# 铁柱AGI 소개

**저는 Grok Bot 헤비 유저이자 꾸준히 활용 팁을 공유하고 있으며, 오픈소스 Grok App과 Grok Bot 브라우저 확장 프로그램의 제작자인 铁柱AGI입니다.**

## 제가 하고 있는 일

- 대규모 프로젝트 FDE를 진행 중이며, 정기적으로 경험을 회고하고 있습니다.
- 커뮤니티 비공식 튜토리얼인 「Grok Bot 초보자 가이드」를 정리 및 관리하고 있으며, 소스 코드는 [GitHub](https://github.com/RongleCat/grok-bot-learn)에 오픈소스로 공개되어 있습니다.
- Grok Bot 활용 팁을 지속적으로 공유하고 있습니다.
- 유료 AI Agent Q&A 그룹을 개설하여 운영하고 있으며, Grok Bot은 그룹 내에서 가장 많이 다루어지는 주제입니다. 참여 방법은 [유료 Q&A 그룹](/group)을 참고하세요.

## 오픈소스 프로젝트

- [Grok Bot Clipper](https://github.com/RongleCat/grok-bot-clipper): 비공식 Grok Bot 브라우저 확장 프로그램으로, 웹 페이지 스크랩, 스크린샷, 소셜 미디어 콘텐츠 수집 후 봇으로 전송하는 기능을 지원합니다. 자세한 내용은 [소개 페이지](/ecosystem/grok-bot-clipper)를 참고하세요.
- [awesome-grok-bot](https://github.com/RongleCat/awesome-grok-bot): 중·영 이중 언어 Grok Bot 리소스 모음집.
- [Grok App](https://grok-app.com): 로컬 Grok Build 명령줄을 위한 오픈소스 데스크톱 워크벤치.
