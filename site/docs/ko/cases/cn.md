# 중국어 장문 엄선

Grok Bot으로 비즈니스 워크플로를 실행할 때 자주 겪는 문제는 주로 **계정 연동, 로컬과 클라우드 혼동, 권한 침범 및 루틴 공회전**이며, CAPTCHA(인증코드), API 만료, 크레딧 소진도 주의해야 합니다. 다중 역할의 책임을 명확히 분리하지 않으면 Bot끼리 컨텍스트를 서로 침범하게 됩니다.

여기 커뮤니티에서 실측 검증된 **15편의 장문 실전 사례**를 정리했습니다. 입문 기초, 1인 미디어 운영, 엔지니어링 R&D, 이커머스 및 일상, 조직 오케스트레이션의 5대 모듈을 아우르며 바로 참조하여 확인할 수 있습니다.

구축하기 전에 먼저 아래 프롬프트를 메인 Bot에 전송하여 **직무 경계와 실행 디렉터리를 정리하도록 요청**하세요.

```text
我打算参考以下业务场景搭建一套 Grok Bot 工作流：【填入具体业务目标】。
请按以下步骤帮我拆解：
1. 列出该流程所需的 Bot 岗位清单，明确每个角色的输入文件、交付成果和绝对禁止动作。
2. 在 /workspace 下为我规划一套清晰的目录结构，规定上下游交接的文件格式。
3. 标出涉及外部发信、数据修改、敏感登录或支付的环节，单独列出必须等待人工审批的节点清单。
4. 给出该流程第一步的测试提示词，明确要求未确认信息标注为待确认，严禁编造数据。
```

### 만 자 장문｜Grok Bot 제로부터 시작하는 첫 입문

> 출처: [万文长｜Grok Bot 从零入门第一次上](https://x.com/TodayKan/status/2104789484277473522)  
> 작성자: [Today🦘 @TodayKan](https://x.com/TodayKan)
데스크톱 앱 연동 진입로는 초기 화면에서만 나타나며, **연동 후에는 마이그레이션할 수 없습니다**. 웹 페이지 로그인 시에는 **Take over로 비밀번호를 직접 입력**하여 제어권을 가져옵니다.

장기 규칙은 설명(Description)에 작성하고, 임시 요구사항은 대화에 넣으세요. 제공되지 않은 정보는 확인 필요로 표시하여 임의로 추측하는 습관을 차단합니다.

첫 번째 작업을 작성할 때는 다음 5가지를 명확히 정리해야 합니다.
- 목표 및 자료
- 경계 및 산출물
- 사람의 수동 확인 노드

점검 작업은 보고서를 `/workspace/site-check/`에 통일하여 저장합니다. 보고서에는 링크와 점검 시간을 반드시 기록하고 스크린샷 증거를 저장해야 하며, 페이지의 사실과 추측을 명확히 분리해야 합니다.

일상 업무 스킬을 정형화하는 2단계:

일상 점검에서는 **새로운 이상이 없으면 기록만 저장하고 알림을 띄우지 않는 원칙**을 유지하여, 크레딧을 절약하고 알림 피로를 방지합니다.

2. 아이템 기획자

### 1인 미디어에서 Grok bot 제대로 쓰는 법｜Kin

> 출처: [做自媒体怎么用好 Grok bot](https://x.com/KinGao476942/status/2099736121781764594)

### Grok Bot을 WeChat에 연동하는 방법은? 초보자를 위한 완벽 가이드(상세 프롬프트 포함)｜Kin

> 출처: [如何把 Grok Bot 接入你的微信？保姆级新手指南来了（附详细提示词）](https://x.com/KinGao476942/status/2108132811635032316)  
> 작성자: [Kin @KinGao476942](https://x.com/KinGao476942)

![Grok Bot을 WeChat에 연동하는 방법은? 초보자를 위한 완벽 가이드(상세 프롬프트 포함)](/cases-img/fs29-0.jpg)

![Grok Bot을 WeChat에 연동하는 방법은? 초보자를 위한 완벽 가이드(상세 프롬프트 포함)](/cases-img/fs29-1.jpg)

스마트폰에서 언제든지 클라우드 PC의 Agent를 지휘하고 싶다면 WeChat ClawBot 플러그인을 통해 연결할 수 있으며, **배포는 단 3단계면 충분합니다**:
1. 정리된 프롬프트를 메인 Bot에 전송합니다.
2. Bot이 클라우드 PC에서 iLink 프로토콜을 통해 스크립트를 작성하고 'WeChat 명령 접수 창구' Webhook을 생성합니다.
3. 암호화 팝업에 키를 입력하고 QR 코드를 스캔하여 연동합니다.

통신 및 장애 대응은 다음 3가지 기준으로 검수합니다:
- 아웃바운드 롱 폴링 방식을 채택하여 **공인 IP 및 인트라넷 침투 불필요**.
- Bot이 **순수 텍스트로만 응답**하도록 엄격히 제한.
- 프롬프트에 **오류 코드 -14 자동 재연결** 사전 설정.

### 내 게시물을 개인 프로필 웹사이트로 만들기: Grok Bot으로 특징 분석부터 배포 공유까지 완벽 튜토리얼

> 출처: [把自己的推文做成个人画像网站,  用 Grok Bot 从分析特点到上线分享保姆级教程](https://x.com/0xlangeai/status/2109115005069341175)

![내 게시물을 개인 프로필 웹사이트로 만들기: Grok Bot으로 특징 분석부터 배포 공유까지 완벽 튜토리얼](/cases-img/fs32-1.jpg)
프로젝트 단체 채팅방에 4개의 Bot을 참여시키고, **공유 클라우드 PC 내의 Markdown 파일을 통해 릴레이 방식으로 작업을 전달합니다**:

1. 트윗 정리 담당자가 최근 90일간의 콘텐츠를 스크랩하여 `tweets.md`로 저장합니다.
2. 프로필 분석가가 3~5가지 특징을 도출하여 `profile.md`에 작성합니다.
