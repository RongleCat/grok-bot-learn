# Pi Coding Agent

<ToolMeta id="pi" />

미니멀하면서도 확장성이 뛰어난 터미널 코딩 Agent로, **확장 프로그램, 스킬 및 프롬프트 템플릿을 통한 심층 커스터마이징**으로 전용 개발 워크플로를 구축하기에 적합합니다.
확장 프로그램, 스킬 및 프롬프트 템플릿으로 전용 개발 워크플로를 맞춤 설정하기를 좋아하는 긱(Geek) 개발자에게 적합합니다.

결론적으로, 이 도구는 확장 프로그램, 스킬 및 프롬프트 템플릿을 통해 미니멀하고 확장성이 뛰어난 전용 터미널 코딩 Agent 워크플로를 심층 커스터마이징하는 데 주로 사용됩니다.

## Bot에 보낼 프롬프트

아래 내용을 전체 복사하여 Grok Bot에게 전송하면, 클라우드 컴퓨터에 자동으로 설치 및 검증을 진행하며, 로그인이나 키 구성이 필요한 경우 일시 중지하고 사용자의 입력을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Pi Coding Agent（https://pi.dev），以后定制开发工作流和写代码用它。需要填密钥时请提醒我自己填。
````

</div>

## 직접 해야 할 작업

- 해당 모델 제공업체의 API Key 준비.
