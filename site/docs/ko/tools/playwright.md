# Playwright

<ToolMeta id="playwright" />

Playwright는 마이크로소프트가 오픈소스로 공개한 자동화 라이브러리로, Bot이 **대량 웹페이지 스크린샷 및 렌더링 크롤링**을 수행하기에 적합하며 수동으로 브라우저 상호작용 할당량을 소모할 필요가 없습니다.

## Bot에 보낼 프롬프트

아래 전체 내용을 복사하여 Grok Bot에 보내면, 클라우드 PC에 자동으로 설치 및 검증을 진행하며 로그인이나 키 설정이 필요할 경우 일시 중지하고 사용자의 조작을 기다립니다.

````text
帮我在你的云电脑上安装 Playwright（https://playwright.dev/python/docs/intro），以后网页渲染、截图和抓取任务用它。
````

- 클라우드 PC에 Python 실행 환경이 갖추어져 있는지 확인합니다.
