# MCP 커넥터

<ToolMeta id="mcp-connectors" />

MCP 커넥터는 외부 서비스와 모델 간의 상호작용 통로를 열어주며, Bot이 **외부 도구와 클라우드 데이터를 직접 호출하여** 복잡한 협업을 수행하기에 적합합니다.

결론은 다음과 같습니다. 해당 도구는 Bot이 외부 도구와 클라우드 데이터를 직접 호출하여 복잡한 협업을 수행하는 데에만 사용됩니다.

## Bot에게 보낼 프롬프트

아래 내용을 전체 복사하여 Grok Bot에게 전송하면, 클라우드 PC에서 자동으로 설치 및 검증을 진행하며 로그인이나 키 설정이 필요할 때 일시 중지하고 사용자의 작업을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上接入 MCP 连接器（https://docs.x.ai/grok/connectors），以后调用外部工具和同步云端数据用它。需要第三方授权时把链接发给我，需要填密钥时请提醒我自己填。
````

</div>

## 직접 해야 할 일

- 브라우저에서 커넥터 제어 페이지에 접속하고 연동할 계정을 준비합니다.
- 안내에 따라 대상 서비스의 주소 또는 인증 키를 직접 입력합니다.
