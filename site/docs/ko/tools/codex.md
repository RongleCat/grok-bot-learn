# Codex CLI

<ToolMeta id="codex" />

OpenAI 공식 터미널 코딩 Agent로, **코드 수정, 스크립트 실행 및 이미지 생성/검토**에 적합하며, ChatGPT 구독 크레딧을 직접 사용할 수 있습니다.
코드 수정, 스크립트 실행 및 이미지 생성/검토가 필요한 ChatGPT 구독자에게 적합합니다.


## Bot에 보낼 프롬프트

아래 내용 전체를 복사하여 Grok Bot에 보내면 클라우드 PC에 자동으로 설치하고 검증하며, 로그인이나 키 설정이 필요할 때는 작업을 일시 중지하고 사용자의 입력을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Codex CLI（https://developers.openai.com/codex/cli），用我的 ChatGPT 账号登录，以后写代码、跑脚本和生图用它。需要我授权时把链接发给我。
````

</div>

## 직접 해야 할 일

- ChatGPT 계정을 준비하고 디바이스 코드 로그인 권한이 활성화되어 있는지 확인합니다.
- 브라우저에서 Bot이 보낸 디바이스 코드 링크를 열어 확인을 완료합니다.
