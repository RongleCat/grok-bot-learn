# muse2api

<ToolMeta id="muse2api" />

커뮤니티 오픈 소스 muse.ai 리버스 엔지니어링 래핑 프로젝트로, **클라우드 PC**에서 OpenAI 호환 인터페이스를 통해 웹 무료 크레딧을 직접 호출하여 대화, 이미지 생성 및 비디오 생성을 진행하기에 적합합니다.

결론적으로, 이 도구는 클라우드 PC에서 호환 인터페이스를 통해 대화, 이미지 생성 및 비디오 생성을 구현하는 용도로만 사용됩니다.

## Bot에 전송할 프롬프트

아래 내용 전체를 복사하여 Grok Bot에 전송하면, 클라우드 PC에서 자동으로 설치 및 검증을 진행하며, 로그인이나 키 설정이 필요할 때 일시 중지되어 사용자의 입력을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上部署 muse2api（https://github.com/czg86389-hub/muse2api），以后调用多模态接口进行对话、生图和生视频用它。需要填密钥时请提醒我自己填。
````

</div>

## 직접 해야 할 일

- muse.ai 계정을 준비하고 클라우드 PC 브라우저에서 로그인을 완료합니다.
- 안내에 따라 통신 키와 로그인 상태 데이터를 직접 입력합니다.
