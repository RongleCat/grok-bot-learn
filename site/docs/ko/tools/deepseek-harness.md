# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

DeepSeek 공식 오픈소스인 **"모든 것이 플러그인" 아키텍처 Agent**로, 데스크톱과 Web UI를 지원합니다. 현재 개발자 프리뷰 단계에 있으며 **코드 작성**, **조사 분석**, **일상 업무** 및 **예약 작업 확장**에 적합합니다.

## Bot에 보낼 프롬프트

아래 전체 내용을 복사하여 Grok Bot에 보내면, 클라우드 컴퓨터에 자동으로 설치 및 검증을 진행하며, 로그인이나 키 설정이 필요할 경우 일시 정지하고 사용자의 입력을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以后日常办公、调研、写代码和跑定时任务用它。需要配置 DeepSeek API Key 时请停下来提醒我自己填。
````

</div>

## 직접 해야 할 일

- DeepSeek API Key 준비
- Bot 설치 완료 후, 설정에서 직접 API Key 입력
