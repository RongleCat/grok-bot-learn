# Cursor CLI

<ToolMeta id="cursor-cli" />

Cursor 공식 명령줄 Agent로, **클라우드 컴퓨터에서 소규모 코드 수정을 실행**하고 Bot 할당량을 전체적인 의사 결정에 아껴두는 데 적합합니다.

## Bot에 보낼 프롬프트

아래 내용을 모두 복사하여 Grok Bot에게 전송하세요. 클라우드 컴퓨터에서 자동으로 설치 및 확인을 진행하며, 로그인이나 키 설정이 필요할 때 일시 중지하고 사용자의 작업을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 직접 해야 할 일

- Cursor 계정 또는 관련 인증 정보를 준비합니다.
- 브라우저에서 Bot이 전송한 인증 링크를 열어 로그인을 완료합니다.
