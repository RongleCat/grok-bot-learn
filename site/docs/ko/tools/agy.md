# Antigravity CLI（agy）

<ToolMeta id="agy" />

Google 공식 터미널 Agent로, **동영상 이해, 장문 작성 및 코드 수정**에 적합하며 동영상 파일을 직접 읽는 기능을 지원합니다.

결론: agy는 동영상 이해, 장문 작성 및 코드 수정에 적합하며, 동영상 파일을 직접 읽는 기능을 지원합니다.

## Bot에 보낼 프롬프트

아래 내용을 전체 복사하여 Grok Bot에 보내면, 클라우드 PC에서 자동으로 설치 및 검증을 진행하며 로그인이나 키 설정이 필요한 경우 일시 중지하고 사용자의 작업을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 Antigravity CLI（https://antigravity.google/docs/getting-started/），以后视频理解、长文写作与代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 직접 해야 할 일

- Google 계정을 준비합니다.
- 브라우저에서 Bot이 보낸 인증 링크를 열어 인증을 완료합니다.
