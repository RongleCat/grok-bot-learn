# yt-dlp

<ToolMeta id="yt-dlp" />

yt-dlp는 수천 개의 사이트를 지원하는 명령줄 오디오/비디오 다운로드 도구로, Bot이 후속 전사 처리를 위해 **동영상을 일괄 다운로드하거나 오디오를 추출**하는 데 적합합니다.

## Bot에 보낼 프롬프트

아래 전체 내용을 복사하여 Grok Bot에 전송하면, 클라우드 컴퓨터에 자동으로 설치 및 확인을 진행하며 로그인이나 키 설정이 필요한 경우 일시 중지하고 사용자의 작업을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 yt-dlp（https://github.com/yt-dlp/yt-dlp），以后批量下载音视频和提取音频用它。
````

</div>

## 직접 해야 할 일

- 다운로드할 대상 미디어 링크를 준비합니다.
- 로그인이 필요한 사이트의 경우 해당 Cookie 파일을 내보내어 준비해 둡니다.
