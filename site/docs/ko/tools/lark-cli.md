# 페이슈 CLI(lark-cli)

<ToolMeta id="lark-cli" />

페이슈 공식 명령줄 도구로, Bot이 개인 자격으로 **클라우드 컴퓨터**에서 페이슈 클라우드 문서, 다차원 표, 클라우드 드라이브 및 지식베이스를 다루기에 적합합니다.
Bot이 개인 자격으로 클라우드 컴퓨터에서 페이슈 클라우드 문서, 다차원 표, 클라우드 드라이브 및 지식베이스를 조작합니다.
Bot이 개인 자격으로 클라우드 컴퓨터에서 페이슈 문서, 표 및 클라우드 드라이브 자산을 관리해야 하는 사용자에게 적합합니다.


## Bot에 보낼 프롬프트

아래 내용 전체를 복사하여 Grok Bot에 보내면, 클라우드 컴퓨터에서 자동으로 설치 및 확인을 진행하며 로그인이나 키 설정 시 일시 중지하고 사용자의 작업을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置飞书 CLI（https://github.com/larksuite/cli），以后操作飞书云文档、多维表格和云盘用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 직접 해야 할 일

- 페이슈 개인 계정 준비.
- 인증 링크를 열고 터미널에 표시된 기기 코드를 입력하여 인증 확인.
