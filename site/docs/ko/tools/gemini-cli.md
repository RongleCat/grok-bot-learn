# Gemini CLI

<ToolMeta id="gemini-cli" />

Google이 오픈소스로 공개한 터미널 AI Agent로, **유료 사용자 및 Google Cloud 프로젝트 사용자**의 터미널 상호작용 및 개발 협업에 적합합니다.

결론은 다음과 같습니다: 이 도구는 유료 사용자 및 Google Cloud 프로젝트 사용자가 터미널 상호작용 및 개발 협업을 진행하는 용도로만 사용됩니다.

## Bot에 보낼 프롬프트

아래 전체 내용을 복사하여 Grok Bot에 보내면, 클라우드 컴퓨터에 자동으로 설치하고 검증합니다. 로그인이나 API 키 설정이 필요한 경우 일시 중지하고 사용자의 작업을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以后终端交互和开发协作用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 직접 해야 할 일

- 유료 Google 계정 또는 Google Cloud 프로젝트 계정을 준비합니다.
- 브라우저에서 Bot이 보낸 인증 링크를 열어 인증을 완료합니다.
