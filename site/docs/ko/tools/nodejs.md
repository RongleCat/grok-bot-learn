# Node.js 및 npm

<ToolMeta id="nodejs" />

Node.js 및 npm은 프론트엔드 및 각종 AI CLI의 실행 기반으로, Bot에 **최신 커맨드라인 도구의 실행 환경**을 제공하기에 적합합니다.

## Bot에게 보낼 프롬프트

아래 전체 내용을 복사하여 Grok Bot에게 전송하면, 클라우드 PC에 자동으로 설치하고 검증합니다. 로그인이나 키 설정이 필요할 경우 일시 정지하고 사용자의 입력을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装好 Node.js 与 npm（https://github.com/nvm-sh/nvm），以后运行前端项目和各类命令行工具用它。
````

</div>

## 직접 해야 할 일

- 클라우드 PC의 네트워크 연결을 확인합니다. 별도의 외부 계정은 준비하지 않아도 됩니다.
