# 고정 아웃바운드 프록시(SSH 터널)

<ToolMeta id="egress-proxy" />

고정 아웃바운드 프록시는 SSH 동적 포트 포워딩을 활용하여 로컬 SOCKS5 프록시를 구축하며, Bot이 **지역 제한이 있는 서비스에 접근**할 때 안정적인 아웃바운드 IP를 유지하는 데 적합합니다.

## Bot에 보낼 프롬프트

아래의 전체 내용을 복사하여 Grok Bot에게 전송하면, 클라우드 PC에서 자동으로 설치 및 검증을 진행하며, 로그인이나 키 설정 시 일시 중지되어 사용자의 입력을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上配置基于 SSH 隧道的固定出口代理（https://man.openbsd.org/ssh），以后访问受地域限制的服务用它。需要填服务器地址和私钥时请提醒我自己填。
````

</div>

## 직접 해야 할 일

- SSH 키 로그인을 지원하는 해외 서버를 준비합니다.
- 안내에 따라 로그인 개인키와 접속 정보를 보안 파일에 직접 작성합니다.

## 출처

- [OpenSSH ssh 매뉴얼(-D 동적 포워딩)](https://man.openbsd.org/ssh)
