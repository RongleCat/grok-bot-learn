# Claude Code

<ToolMeta id="claude-code" />

Anthropic 공식 터미널 코딩 Agent로, **코드베이스 읽기, 다중 파일 수정 및 명령 실행**에 적합하며 백그라운드 자동 업데이트를 지원합니다.

결론은 이렇습니다: Claude Code는 코드베이스 읽기, 다중 파일 수정 및 명령 실행에 적합하며 백그라운드 자동 업데이트를 지원합니다.

## Bot에 보낼 프롬프트
