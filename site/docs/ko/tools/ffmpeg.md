# FFmpeg

<ToolMeta id="ffmpeg" />

FFmpeg는 멀티미디어 로우레벨 처리의 핵심 도구로, Bot에게 **오디오/비디오 트랜스코딩, 압축, 프레임 추출 및 오디오 추출** 작업을 맡기기에 적합합니다.

## Bot에게 보낼 프롬프트

아래 내용 전체를 복사하여 Grok Bot에게 전송하면 클라우드 PC에 자동으로 설치하고 검증하며, 로그인이나 키 설정이 필요할 경우 일시 중지하고 사용자의 조작을 기다립니다.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 FFmpeg（https://ffmpeg.org/download.html），以后处理音视频转码、剪辑、压缩和截帧用它。
````

</div>
