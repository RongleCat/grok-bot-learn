# 제 16 장 사례: 지식 자동 수집 및 WeChat 연동

스마트폰 즐겨찾기는 뒤섞이기 쉽고, 단체 대화방 파일은 수시로 만료되며, 외출 중에는 클라우드에서 **7×24시간** 상시 가동 중인 Grok Bot을 활용하기 어렵습니다.

1. 웹페이지 및 숏폼 영상: Webhook과 iOS 단축어를 연동하여, **원클릭으로 구조화하여 자동 수집**합니다.
2. 스크린샷 및 음성 녹음: WeChat 전달 시 첨부파일이 함께 전송되지 않으므로, **공용 네트워크 임시 중계를 거쳐** 내보냅니다.
3. 대화 제어 및 호출: 공식 「微信ClawBot」 플러그인과 롱 폴링을 활용하여, **WeChat 대화창에서 Grok Bot을 직접 제어**합니다.

## 사례 1: Webhook과 단축어로 지식 자동 수집 파이프라인 구축하기

![사례 1: Webhook과 단축어로 지식 자동 수집 파이프라인 구축하기](/info/16-knowledge-s2.png)

**이 방안은 크롤링, 음성/영상 텍스트 변환 및 요약을 모두 Grok Bot 클라우드에서 처리하며, 스마트폰은 URL만 전송하여 트리거합니다.

** 铁柱AGI(@cgnot996)는 [루틴](https://cursor.com/cn/help/grok-bot/routines)의 Webhook을 활용하여 요청 전송 즉시 실행되도록 구현했습니다.

### 구축 단계
1. 데스크톱 앱의 Details에서 Routines를 찾습니다. Bot에게 파싱 작업을 생성하도록 요청하고, **생성된 Webhook URL과 key를 안전하게 보관**합니다.
2. 새 단축어 "지식베이스 Bot으로 보내기"를 생성하고, "URL 내용 가져오기" 동작을 추가한 후 표에 따라 매개변수를 구성합니다.

| 매개변수 | 설정값 |
|---|---|
| URL | Webhook 주소 |
| 방법 | POST |
| 헤더 | 키 이름 `Authorization`, 값 `Bearer <key>` |
| 요청 본문 | JSON 선택 후 "단축어 입력" 추가 |

3. **폐쇄형 앱을 위한 보조 입력창 추가**. WeChat은 공유 패널을 비활성화하는 경우가 많으므로, 두 번째 단축어("메뉴에서 선택" 및 "텍스트 요청" 추가)를 만들어 중계하고, iPhone 동작 버튼에 매핑하여 버튼 클릭으로 붙여넣고 전송할 수 있게 합니다.

## 사례 2: WeChat 대화 기록 및 멀티모달 자료 수집 연동

### 사례 개요
- WeChat 통합 전달 내용을 패키징하여 Grok Bot으로 전송하면 자동으로 압축 해제 후 접수증을 출력합니다.
- **filebin.net을 징검다리로 활용**하여 로컬 경로 의존성을 배제합니다.
- Mac 및 iPhone에 **5가지 수집 모드** 단축어를 배포합니다.

### 원리: 임시 웹하드 중계가 필요한 이유

서로 다른 기기 간에는 로컬 디스크를 직접 읽을 수 없으며, WeChat의 대용량 ZIP 파일을 요청 본문에 직접 담으면 시간 초과가 발생하기 쉽습니다.

1. 텍스트는 JSON을 통해 직접 전송합니다.
2. 이미지, 음성 녹음, ZIP 파일은 먼저 filebin.net에 업로드한 후 링크를 Bot에 전달하여 다운로드하도록 합니다.
3. 파일 저장소 ID는 이름 중복으로 인한 유출을 방지하기 위해 반드시 **최소 8자리의 무작위 영문 및 숫자**를 사용해야 합니다.
4. 파일은 기본적으로 7일간 보관되며 암호화되지 않으므로, **개인정보나 영업비밀을 절대 전송해서는 안 됩니다**.

### 진행 방법: 단계별 구축 방법

#### 1. Webhook 설정
데스크톱 앱 메인 대화창에 다음 프롬프트를 전송합니다:

```text
帮我创建一个 Webhook 触发的例行任务。快捷指令会用 POST 请求发来一个 JSON，里面只有一个字段 info。info 可能是我输入的文字，也可能是一个文件下载链接，比如微信聊天记录压缩包、截图、录音。收到后：如果是链接就先下载文件再读取，压缩包先解压；然后整理出要点，收录进知识库，最后给我一份回执，写清楚收录了什么、存在哪里。
```

**전송 후 Bot "루틴"에서 Webhook URL과 key를 기록해 둡니다.**

#### 2. 단축어 설정
가져오기 링크: `https://www.icloud.com/shortcuts/2b77155d7c744110a0f0f9ef1bdc42bf`
"【分享版】发送给知识库 Bot" 단축어를 편집하여 URL, key 및 **최소 8자리의 복잡한 스토리지 ID**(예: kb7x9m2q)를 입력합니다. 헤더는 기본 내장되어 있으므로 수정할 필요가 없습니다.

#### 3. WeChat 기록 수집
- **Mac**: 다른 앱으로 통합 전달 시 해당 단축어를 선택하고 전달받기를 클릭합니다. ZIP 파일이 웹하드로 업로드되어 링크가 전달되면 Bot이 즉시 처리합니다.
- **스마트폰**: 통합 전달에서 해당 단축어를 선택하고 전달받기를 탭합니다. "동작 편집"에서 자주 사용하는 영역에 고정해 둘 수 있습니다.

#### 4. 개별 실행 및 수집
Mac에서는 Raycast 또는 메뉴 막대를 사용하고, 스마트폰에서는 동작 버튼에 지정합니다.
- 스크린샷/음성 녹음: 확인 또는 녹음 완료 후 웹하드로 업로드하고 링크를 전달합니다.
- 텍스트 입력: 웹하드를 거치지 않고 **JSON에 직접 담아 전송**합니다.
- 이미지 선택 및 추가: 이미지를 선택한 후 설명을 입력하여 일괄 업로드합니다.
- 전달 내용 수신: 수신된 내용이 없을 경우 클립보드를 읽어와 전송합니다.

## 사례 3: Grok Bot을 WeChat에 직접 연동하여 양방향 제어하기

![사례 3: Grok Bot을 WeChat에 직접 연동하여 양방향 제어하기](/info/16-knowledge-s4.png)

### 사례 개요
Kin은 Grok Bot을 WeChat에 연동하여 **스마트폰으로 메시지를 보내 클라우드 Bot을 원격 제어**할 수 있게 했습니다.

1. Grok에게 iLink를 호출하는 롱 폴링 스크립트를 작성하도록 요청
2. 명령어를 수신할 Webhook 생성
3. WeChat에서 「微信ClawBot」을 활성화하고 QR 코드 스캔으로 연동

순수 아웃바운드 롱 폴링 방식을 사용하여 **퍼블릭 포트를 개방할 필요가 없습니다**.

### 원리: 微信ClawBot과 iLink 롱 폴링 메커니즘

이 방안은 공식 「微信ClawBot」 플러그인과 iLink 인터페이스(`ilinkai.weixin.qq.com`)를 사용하며, 클라이언트 메모리를 변조하지 않으므로 **계정 정지 위험이 없습니다**.

통신은 모두 아웃바운드 요청으로 이루어지므로 **퍼블릭 포트를 개방할 필요가 없습니다**:
1. Grok Bot 백그라운드에서 `getupdates`를 호출하여 폴링 방식으로 메시지를 가져오고, 처리가 완료되면 `sendmessage`를 호출하여 회신합니다.
2. Webhook이 텍스트를 수신한 후 각 전담 Bot에 전달하여 협업 실행하며, 자세한 내용은 [使用 Grok Bot](https://cursor.com/cn/docs/grok-bot/work) 문서를 참고하세요.

### 진행 방법: 단계별 실습 가이드 및 전체 프롬프트

1. PC 데스크톱 메인 대화창에 프롬프트를 전송하고, 「微信下旨入口」 루틴이 생성될 때까지 기다립니다.
::: details 怎么做：手把手操作步骤与完整提示词
```text
我想把你接到我的微信上，让我能在微信里直接给你发消息、收到你的回复。请按下面的思路做，每做完一步告诉我结果，需要我操作的地方停下来等我。

1、先调研方案：腾讯「微信ClawBot」插件用的是 iLink 接口（ilinkai.weixin.qq.com）。请确认怎么用 getupdates 长轮询收消息、怎么用 sendmessage 回消息。整个程序只走出站请求，不要开公网端口。

2、在 Grok Bot 里建一个由 webhook 触发的 routine，名字可以叫「微信下旨入口」。建好后告诉我去 routine 面板复制 Webhook URL 和 key，然后弹出加密弹框让我填进去，不要让我在聊天里发明文。

3、在你的云端电脑上写一个小转发程序：收到微信消息后 POST 给这个 routine；你处理完以后，用一个 reply 脚本把回复发回微信，同时在我们的主聊天里同步一份。

4、等我在手机微信里启用 ClawBot 插件以后，生成二维码让我用手机扫码确认，同时给我一个可以在微信里直接打开的备用链接。二维码大约 5 分钟有效。

5、绑定成功后，提醒我先在 ClawBot 对话里发一句话，因为回复要用到这条消息带的 context_token。

6、规则：只认绑定的这一个人，别人的消息不处理；回复一律用纯文本，不要用 Markdown，因为微信不渲染 Markdown。

7、最后告诉我：云端电脑重启以后，怎么把转发程序重新拉起来；如果遇到错误码 -14（凭证过期），提醒我重新扫码。
```
:::
2. 루틴의 URL과 key를 복사합니다. **대화창에 평문으로 전송하는 것은 절대 금지**이며, 시크릿 카드에 입력하여 "안전하게 저장되었으며 비공개 상태로 유지됨"이라고 표시되면 됩니다. 자세한 내용은 [安全存储机密信息](https://cursor.com/cn/help/grok-bot/secrets)을 참고하세요.
3. WeChat 버전은 **iOS 8.0.70 / Android 8.0.69 이상**이어야 합니다. "나" -> "설정" -> "플러그인"에서 붉은 바닷가재 아이콘의 「微信ClawBot」을 활성화합니다.
4. "插件开好了"라고 전송한 뒤, WeChat으로 QR 코드를 스캔하여 권한을 부여합니다(QR 코드는 **5분간 유효**하며, 시간 초과 시 대체 링크 사용).
5. **반드시 WeChat에서 먼저 첫 메시지를 보내야 합니다**(예: "你好"). 인터페이스가 이를 통해 `context_token`을 가로채 연결을 설정해야 하며, 전송이 완료되면 통로가 공식적으로 준비됩니다.

3. 동영상 링크를 보내 다운로드 전문가 Bot을 호출하고, 정제된 텍스트가 회신되는지 확인.
4. 데스크톱 앱에서 모든 명령어와 기록이 동기화되는지 대조 확인.

실제 실습 및 스크린샷은 [《如何把 Grok Bot 接入你的微信？保姆级新手指南来了（附详细提示词）｜Kin》](https://jcng5q8n0f3z.feishu.cn/wiki/LehUwOhxAijkigkkVlDclVVunQg)을 참고하세요.

## 자주 발생하는 문제 및 주의사항

1. 전달하기 전에 **반드시 로컬에서 첨부파일을 클릭하여 다운로드**해야 합니다. 그렇지 않으면 내보낸 ZIP 파일에 자리표시자 텍스트만 포함됩니다.
2. filebin.net에는 비밀번호가 없으므로 `test`나 `123456`을 사용하지 말고, **반드시 8자리 이상의 무작위 문자열을 설정**해야 합니다. 신분증, 은행 카드, 기밀 계약서 등은 절대 전송하지 마세요.
3. Webhook을 설정할 때 대화창에 key를 붙여넣지 말고, **시크릿 카드를 사용하여 저장**하세요. 단축어를 공유하기 전에는 개인 key와 URL을 반드시 비워야 합니다.
4. ClawBot QR 코드는 5분 후 만료됩니다. 응답이 없거나 `-14` 에러가 발생하면 **자격 증명이 만료된 것이므로 다시 생성하여 스캔**해야 합니다.
5. 클라우드 PC가 Reset되거나 재부팅되면 Python 폴링이 중단되므로, WeChat에서 응답이 없으면 데스크톱 앱에서 **Bot에게 스크립트를 다시 실행하도록 요청**하세요.
6. WeChat은 Markdown을 렌더링하지 않으므로, `**`나 `#` 등이 출력되지 않도록 **Instruction에서 일반 텍스트 회신을 강제**하세요.
7. iLink 대기열에서 메시지를 가로채 명령어가 누락되는 것을 방지하기 위해, **동시에 여러 개의 OpenClaw 리스너를 실행하지 마세요**.
8. The X Subscription은 주간 할당량에서 차감되므로, **고빈도 트리거에는 반드시 필터링을 추가**해야 합니다. 소모가 너무 빠르면 불필요한 루틴을 일시 중단하거나 실행 조건을 완화하세요.

## 완료 후 검증 방법

1. **Webhook 테스트**: `Authorization: Bearer <key>` 헤더를 포함한 POST 요청을 전송합니다. **200이 반환되면 성공**이며, 401은 키 오류, 404는 URL 오류입니다. PC의 "루틴" 상태가 Running…으로 변경되고 로그가 찍히면 정상입니다.
2. **단축어 테스트**: 텍스트를 전송하여 수십 초 내에 접수증이 나오는지 테스트하고, 이미지 2장을 전달하여 아카이빙을 테스트합니다. 스크린샷은 반드시 권한 승인 미리보기가 떠야 하며, 허용을 눌러야 전송됩니다.
3. **WeChat 및 동기화 테스트**: 「微信ClawBot」에 메시지를 보내 **5초 이내에 회신이 오면** 정상 통신된 것입니다. 이후 PC 화면을 확인하여 대화 기록이 동기화되었다면 모든 연동이 완벽하게 완료된 것입니다.
