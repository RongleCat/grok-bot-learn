# Começando do Zero com o Grok Bot

O Grok Bot é um **colega de IA com computador em nuvem integrado**: passe a tarefa, feche o computador e ele continuará rodando.

Reuni nesta página os passos iniciais para iniciantes e os casos reais testados e aprovados pela comunidade.
