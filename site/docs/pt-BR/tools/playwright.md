# Playwright

<ToolMeta id="playwright" />

O Playwright é uma biblioteca de automação de código aberto da Microsoft, ideal para permitir que o Bot execute **capturas de tela em lote e raspagem de páginas web com renderização**, sem consumir manualmente a sua cota de interação do navegador.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot; ele instalará e verificará tudo automaticamente no computador na nuvem, pausando para aguardar sua ação caso encontre etapas de login ou configuração de chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Playwright（https://playwright.dev/python/docs/intro），以后网页渲染、截图和抓取任务用它。
````

</div>

## O que você precisa fazer

- Confirme se o computador na nuvem possui um ambiente de execução Python.
