# FFmpeg

<ToolMeta id="ffmpeg" />

O FFmpeg é a ferramenta essencial para o processamento multimídia de baixo nível, ideal para permitir que o Bot realize **transcodificação de áudio e vídeo, compactação, captura de quadros e extração de áudio**.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele fará a instalação e a verificação automáticas no computador em nuvem, pausando para aguardar sua ação caso encontre etapas de login ou configuração de chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 FFmpeg（https://ffmpeg.org/download.html），以后处理音视频转码、剪辑、压缩和截帧用它。
````

</div>
