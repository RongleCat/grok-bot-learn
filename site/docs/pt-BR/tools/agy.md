# Antigravity CLI (agy)

<ToolMeta id="agy" />

Agent de terminal oficial do Google, ideal para **compreensão de vídeo, redação de textos longos e modificação de código**, com suporte à leitura direta de arquivos de vídeo.

A conclusão é: agy é ideal para compreensão de vídeo, redação de textos longos e modificação de código, com suporte à leitura direta de arquivos de vídeo.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele fará a instalação e verificação automaticamente no computador na nuvem, pausando para aguardar sua ação caso seja necessário fazer login ou configurar chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 Antigravity CLI（https://antigravity.google/docs/getting-started/），以后视频理解、长文写作与代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## O que você precisa fazer

- Preparar uma conta do Google.
- Abrir o link de autorização enviado pelo Bot no navegador para concluir a autenticação.
