# agently-cli (CLI de E-mail de Agente)

<ToolMeta id="agently-cli" />

Ferramenta oficial de linha de comando lançada pelo Tencent QQ Mail, ideal para permitir que o Bot envie e receba e-mails, pesquise o histórico de e-mails e baixe anexos no **computador em nuvem**.
O Bot envia e recebe e-mails, pesquisa o histórico e baixa anexos no computador em nuvem.
A conclusão é: o Bot pode gerenciar de forma independente o envio e recebimento diário de e-mails, pesquisar o histórico e baixar anexos automaticamente no computador em nuvem.


## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele irá instalar e verificar tudo automaticamente no computador em nuvem, pausando para aguardar sua ação caso seja necessário fazer login ou configurar chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 agently-cli（https://agent.qq.com），以后收发邮件、检索历史邮件和下载附件用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## O que você precisa fazer

- Preparar uma conta do QQ Mail ou do Agent Mail.
- Abrir o link de autorização enviado pelo Bot no navegador para concluir a verificação.
