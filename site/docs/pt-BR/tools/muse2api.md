# muse2api

<ToolMeta id="muse2api" />

Projeto de código aberto da comunidade de engenharia reversa do muse.ai, adequado para usar diretamente a cota gratuita da versão web no **computador em nuvem** por meio de uma interface compatível com OpenAI para conversação, geração de imagens e vídeos.

A conclusão é: esta ferramenta serve apenas para realizar conversação, geração de imagens e vídeos no computador em nuvem por meio de uma interface compatível.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot; ele instalará e validará automaticamente no computador em nuvem, pausando para aguardar sua ação caso precise fazer login ou configurar chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上部署 muse2api（https://github.com/czg86389-hub/muse2api），以后调用多模态接口进行对话、生图和生视频用它。需要填密钥时请提醒我自己填。
````

</div>

## O que você precisa fazer

- Preparar uma conta muse.ai e realizar o login no navegador do computador em nuvem.
- Preencher a chave de comunicação e os dados de status de login por conta própria de acordo com as instruções.
