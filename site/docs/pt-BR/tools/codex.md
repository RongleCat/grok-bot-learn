# Codex CLI

<ToolMeta id="codex" />

Agent oficial de codificação em terminal da OpenAI, ideal para **modificação de código, execução de scripts e geração e revisão de imagens**, podendo utilizar diretamente a cota de assinatura do ChatGPT.
Indicado para assinantes do ChatGPT que precisam modificar código, executar scripts e gerar e revisar imagens.


## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot; ele instalará e verificará tudo automaticamente no computador em nuvem, pausando e aguardando sua ação caso encontre etapas de login ou configuração de chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Codex CLI（https://developers.openai.com/codex/cli），用我的 ChatGPT 账号登录，以后写代码、跑脚本和生图用它。需要我授权时把链接发给我。
````

</div>

## O que você precisa fazer

- Preparar uma conta do ChatGPT e confirmar que a permissão de login por código do dispositivo está ativada.
- Abrir no navegador o link do código do dispositivo enviado pelo Bot para concluir a confirmação.
