# Node.js e npm

<ToolMeta id="nodejs" />

O Node.js e o npm são a base de execução para o front-end e vários CLIs de IA, sendo ideais para fornecer ao Bot um **ambiente de execução de ferramentas de linha de comando modernas**.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie-o para o seu Grok Bot. Ele fará a instalação e a verificação automáticas no computador em nuvem, pausando e aguardando suas ações caso encontre etapas de login ou configuração de chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装好 Node.js 与 npm（https://github.com/nvm-sh/nvm），以后运行前端项目和各类命令行工具用它。
````

</div>

## O que você precisa fazer

- Verifique se o computador em nuvem tem conexão com a internet; não é necessário preparar contas externas.
