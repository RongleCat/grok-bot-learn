# Claude Code

<ToolMeta id="claude-code" />

Agent oficial de codificação no terminal da Anthropic, ideal para **leitura de bases de código, modificação de múltiplos arquivos e execução de comandos**, com suporte a atualizações automáticas em segundo plano.

Conclusão: o Claude Code é ideal para leitura de bases de código, modificação de múltiplos arquivos e execução de comandos, com suporte a atualizações automáticas em segundo plano.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele irá instalar e validar automaticamente no computador em nuvem, pausando e aguardando a sua ação caso encontre etapas de login ou configuração de chave.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Claude Code（https://code.claude.com/docs/en/setup），以后阅读代码库和多文件修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## O que você precisa fazer

- Preparar uma assinatura do Claude ou uma conta no Anthropic Console.
- Abrir no navegador o link de autorização enviado pelo Bot para concluir a autenticação.
