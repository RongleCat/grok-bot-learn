# Cursor CLI

<ToolMeta id="cursor-cli" />

Agent oficial de linha de comando do Cursor, ideal para **executar pequenas modificações de código no computador na nuvem**, reservando a cota do Bot para decisões globais.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele fará a instalação e a verificação automáticas no computador na nuvem, pausando para aguardar sua ação caso precise de login ou configuração de chave.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## O que você precisa fazer

- Preparar uma conta do Cursor ou credenciais de autorização correspondentes.
- Abrir no navegador o link de autorização enviado pelo Bot para concluir o login.
