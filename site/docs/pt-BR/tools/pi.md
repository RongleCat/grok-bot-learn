# Pi Coding Agent

<ToolMeta id="pi" />

Agent de codificação de terminal minimalista e altamente extensível, ideal para **personalizar profundamente** fluxos de trabalho de desenvolvimento exclusivos por meio de extensões, habilidades e templates de prompt.
Perfeito para desenvolvedores geeks que gostam de personalizar seu fluxo de desenvolvimento por meio de extensões, habilidades e templates de prompt.

A conclusão é: esta ferramenta serve exclusivamente para personalizar profundamente, por meio de extensões, habilidades e templates de prompt, fluxos de trabalho exclusivos de Agent de codificação em terminal minimalistas e altamente extensíveis.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot; ele instalará e validará automaticamente no computador em nuvem, pausando para aguardar sua ação caso encontre etapas de login ou configuração de chaves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Pi Coding Agent（https://pi.dev），以后定制开发工作流和写代码用它。需要填密钥时请提醒我自己填。
````

</div>

## O que você precisa fazer

- Prepare a API Key do provedor de modelos correspondente.
- Insira você mesmo a chave no arquivo de configuração confidencial após receber o aviso.
