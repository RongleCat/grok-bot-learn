# 第 2 章 方案與訂閱：先選對檔位

新手選購常遇到三處坑點。
- 買最便宜的入門套餐，開啟客戶端找不到智慧體入口。
- **Cursor 訂閱與 SuperGrok 每週額度不累加，系統只認更高一側。**
- 手機 App 內點選升級無法切換，還會丟失原有的第三方模型用量。

Grok Bot 執行依託額度。**周用量耗盡且未配置按需保護，雲端自動化任務立刻停擺。**

官方自 2026 年 10 月 12 日起推行 The X Subscription 統一訂閱，分免費檔與四個付費檔。


![方案與訂閱：先選對檔位](/info/02-plans.png)

## 想用 Grok Bot 需要買哪個訂閱套餐？ {#統一訂閱全貌-the-x-subscription-的四檔與免費檔}

**統一訂閱分為 Plus、Premium、Super 與 Ultra 四檔，因 Plus 檔完全不含 Grok Bot，跑自動化任務起步必須選擇每月 30 美元的 Premium 檔。**

![統一訂閱全貌：The X Subscription 的四檔與免費檔](/info/02-plans-s1.png)

### 是什麼

2026 年 10 月 12 日起整合為 The X Subscription，年付為月付 10 倍。

按每美元用量折算（Plus 為基準 1，Premium 約 1.07，Super 約 1.2，Ultra 約 2.0，作者自述，未核），檔位越高自家模型越划算。

| 方案 | 網頁端月付 / 年付 | Grok Bot |
| :--- | :--- | :--- |
| **免費檔** | $0 | 7 天額度試用 |
| **Plus** | $8/月（摺合約$7）/ $80/年 | 不包含 |
| **Premium** | $30/月 / $300/年 | 包含（准入門檻） |
| **Super** | $100/月 / $1000/年 | 包含 |
| **Ultra** | $200/月 / $2000/年 | 包含（最高配額） |

**Plus 檔完全不包含 Grok Bot 與 Cloud agents**，跑自動化任務起步必須選每月 30 美元的 Premium 檔。免費試用限制 7 天有效期，額度按任務規模、步驟和 token 扣除，重度任務可能一次耗盡，用完不恢復。

### 怎麼做

**開通建議走網頁端，避免在移動端付款。**

1. 瀏覽器訪問統一訂閱頁面 [grok.com/com/overlay/subscribe](https://grok.com/com/overlay/subscribe?from=/)。
2. 登入工作用的 X 或 Grok 賬戶。
3. 選 Premium 檔（$30/月；社群曾見首月 5 折 $15 活動，以結賬頁為準）。
4. **選月付不要直接勾年付**，方便隨時換檔或換工具。
5. 用支援的國際信用卡、簽帳金融卡或網頁端 Apple Pay、Google Pay 付款。
6. 開啟 Grok Bot 客戶端登入，確認主介面已解鎖智慧體建立與執行許可權。

詳細解讀見 [《大一統 X 訂閱解讀：新使用者怎麼選，老訂閱要不要切換？一文講清楚》](https://jcng5q8n0f3z.feishu.cn/wiki/Myw6wFW8EicOiRkoEAXcVJqinee) 與 [《鐵柱推文合集①：開通、套餐與額度》](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)。

### 做到什麼程度算好

開啟 Grok Bot 桌面客戶端，**新建任務能分配雲端環境執行，且賬單顯示為按月扣費的 Premium 狀態**即合格。

## Grok Bot 每週用量池是如何結算的？ {#每週共享用量池-額度結算與多端共用機制}

**訂閱每週提供固定額度池並在多端實時同步，官方模型在網頁端、Bot 與 Cursor 補全中按任務量和步數共用扣除，第三方模型則按標價單獨扣費。**

![每週共享用量池：額度結算與多端共用機制](/info/02-plans-s2.png)

### 是什麼

The X Subscription 每週給一個固定額度池，到期自動重新整理。**Grok 網頁端、Bot 與 Cursor 補全問答共用這個池子**。Mac 與 iPhone 登入同賬號額度實時同步，換裝置不重複扣額。

| 模型類別 | 結算規則 |
| :--- | :--- |
| 官方模型 | 計入共享池，網頁端與 Bot 都在此扣額，消耗快慢只看任務量與步數。 |
| 第三方模型 | **不計入共享池**，在 Cursor 中按 API 標價單獨扣費。 |

系統自動指派 Bot 底層模型，統一標為“Grok Bot 用量”，無法自選或遮蔽。詳情見 [Grok Bot 模型](https://cursor.com/cn/help/grok-bot/models.md)。

### 怎麼做

想避免前三天耗光額度，日常分三步規劃。

1. **周初先跑核心重任務**。優先處理核心程式碼編寫、架構搭建與複雜邏輯除錯。
2. **避開高消耗操作**。批次做影片、高頻輪詢與多 Bot 聯動消耗最快（作者自述，未核）；影片建議去網頁端做，別放進 Bot 工作流。
3. 關注重置週期。記清面板上的每週重置日，臨近重置還有富餘時，再集中做資料整理或深度審查。

### 做到什麼程度算好

**常規自動化把日均消耗穩在 10% 到 15%**。每週重置前一天留約 20% 緩衝，且沒收到額度告急彈窗，節奏就算剛好。

## Cursor 怎麼關聯 Grok 共享額度？ {#授權互通-cursor-套餐與-supergrok-關聯規則}

**Cursor 可直接關聯 Grok 賬號對映額度，繫結不改原套餐且無額外扣費，額度按兩邊最高檔生效不累加，且配對後終身鎖定無法解綁或轉移。**

![授權互通：Cursor 套餐與 SuperGrok 關聯規則](/info/02-plans-s3.png)

### 是什麼

Cursor 賬號可以直接關聯 Grok 賬號共享用量。**繫結前先認準三條硬規則。**

- 只同步額度，不改套餐：用量直接對映，不改動現行 Cursor 方案，無額外扣費。
- 額度不累加，只認最高檔：取兩邊每週額度更高者生效，例如 Cursor Pro 繫結 SuperGrok Plus 可升至 Plus 額度。
- 繫結後終身鎖定，無法解綁：配對成功後，**無論自行操作還是聯絡客服，都無法解綁或轉移授權。**

| Cursor 訂閱層級 | 等效關聯層級 | Grok Bot 每週用量 |
| :--- | :--- | :--- |
| Cursor Pro | SuperGrok / X Premium+ | 基礎每週用量 |
| Cursor Pro+ | SuperGrok Plus | 充足每週用量 |
| Cursor Ultra | SuperGrok Heavy | 最高每週用量 |
| 無 Cursor 套餐 | SuperGrok Lite | 不提供 Grok Bot（Lite 檔無許可權，需升級後關聯） |

若分配了 Grok Business 企業席位，賬號自帶 Bot 許可權，**無需在頁面進行任何關聯操作。**

### 怎麼做

個人賬號繫結在網頁端完成。

1. 瀏覽器用接收額度的 Cursor 賬號登入 Grok Bot 網頁端，先確認主賬號無誤。
2. 開啟快速入門入口 [cursor.com/bot/onboarding](https://cursor.com/bot/onboarding)。
3. 點選關聯 Grok 賬戶（Link Grok Account），手機端在訂閱頁點同名按鈕。
4. 跳轉後登入持有 SuperGrok、SuperGrok Plus、SuperGrok Heavy 或 X Premium+ 的賬號授權。
5. 返回客戶端設定頁確認狀態。**新額度最多需要等 24 小時同步，期間切勿重複點選關聯或嘗試解綁。**

完整規則見官方文件 [為 Grok Bot 關聯 SuperGrok](https://cursor.com/cn/help/grok-bot/supergrok.md)。

**分配了企業席位的使用者直接登入即可，無需額外繫結。**

1. 桌面端開啟 Settings > General，點 Sign Out 退出當前賬號，手機端同理。
2. 回到登入頁，點選 Sign in with Grok。
3. 輸入分配了 Business 席位的 Grok 憑據登入，系統會自動掛載該席位額度。

### 做到什麼程度算好

開啟桌面端 Settings > Usage & Billing。

**管理方案下方顯示對應關聯層級標籤、每週額度條顯示重置週期且賬戶無重複扣款，即繫結成功。**

## 團隊版席位與按需付費（On-demand）配置

### 是什麼

團隊成員直接用自己的 Cursor 賬號登入 Grok Bot，用量走團隊配額。**管理員不用單獨分配席位，成員也免審批**。

每週額度用完後會自動走按需用量（賬單顯示 Billed through Cursor）。系統有保護機制，**跑超月度限額的任務不會中途掐斷**，當前任務能完整跑完。

### 怎麼做

1. 在客戶端開啟 **設定**（Settings）> **Usage & Billing**。
2. 找到“按需用量月度限額”，顯示 Disabled 就點右側 **Enable** 開啟。
3. 首次配置需繫結信用卡，在 [cursor.com/dashboard](https://cursor.com/dashboard) 點選 **支出**（Spending）。
4. 在 **Monthly Limit** 填入每月透支上限（比如設 20 或 50 美元防超支）並儲存。

**iOS 和 Android 移動端 App 沒法直接配限額**，必須登網頁控制檯。具體計費詳見官方文件 [方案和計費](https://cursor.com/cn/help/grok-bot/plans.md)。

### 做到什麼程度算好

在 Usage & Billing 中能看到按需用量處於開啟狀態，且顯示設定的限額數值。**每週額度耗盡時任務不報錯中斷**，能順暢切到按需通道繼續跑完。

## 老訂閱切換決策與操作指南

![老訂閱切換決策與操作指南](/info/02-plans-s5.png)

### 是什麼

The X Subscription 統一大訂閱在 2026 年 10 月 12 日上線。不主動切換的使用者，原有方案、價格與功能維持現狀不變。年付週期完整保留至自然到期，後續若有變動只在續訂時生效。

**操作在網頁端一旦確認完成便永久生效，聯絡客服也無法撤回或恢復老套餐**。舊訂閱結算時自動終止並按天折算退款，退款不能抵扣需全額支付的新套餐，賬單週期從當天重新計算。手機客戶端目前不支援切換，必須在網頁端進行。

| 支付渠道與訂閱產品 | 退款途徑與使用者操作 |
| :--- | :--- |
| 網頁端直接購買的舊方案 | 官方自動按比例退款到原支付卡，無需額外人工操作。 |
| Apple 渠道訂閱的 Grok / X Premium | 官方協助提交申請，由 Apple 最終決定退還金額。 |
| Apple 渠道訂閱的 Cursor | **使用者必須親自前往 iOS 系統的「Apple ID → 訂閱」手動取消，並向 Apple 客服申訴退款**。 |
| Google Play 渠道訂閱的服務 | **使用者必須在 Google Play 的「支付和訂閱」中手動取消自動續訂**。 |

### 實戰案例：社群作者面對大一統訂閱的決策實錄

社群開發者持有有效期至 2027 年的年費方案（作者自述，未核），排查用量後決定**暫時不把手裡的老訂閱切換為新版大一統訂閱**，同時關閉原方案自動續費繼續觀望。

老方案帶有長期優惠，強行切換後原優惠直接作廢。新方案每週共享池只覆蓋自家模型，所有第三方模型呼叫都需按 API 標價另行付費。新方案每週用量池為各產品共享，Bot 執行過多會擠佔網頁端與程式碼補全的正常額度。

| 人群分類 | 典型特徵與核心訴求 |
| :--- | :--- |
| 建議換的人群 | 單獨購買多個零散訂閱且每月開銷遠超 30 美元，主要用官方模型，對 Grok Bot 自動化與 X 賬號運營有強捆綁需求。 |
| 不建議換的人群 | 持有含額外第三方模型額度的舊方案，或只在 Cursor 重度寫程式碼、對 X 社交權益與影片生成無需求。 |

切換前先開啟用量面板檢視真實呼叫分佈，摸清自家模型與第三方模型比例。AI 工具儘量按月訂閱，套餐政策兩三個月就會重組，鎖定長週期年費容易陷入被動（作者自述，未核）。

**透過 Apple 訂閱過 Cursor 的使用者，決定遷移後必須在手機後臺手動取消自動續訂**，網頁端升級不會代為處理。

決策分析細節可參閱 [《大一統 X 訂閱解讀：新使用者怎麼選，老訂閱要不要切換？一文講清楚》](https://jcng5q8n0f3z.feishu.cn/wiki/Myw6wFW8EicOiRkoEAXcVJqinee) 與 [《鐵柱推文合集①：開通、套餐與額度》](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)。

### 做到什麼程度算好

保留老方案的使用者，需確認自動續訂狀態符合預期，核心模型額度完好。

**決定切換新方案的使用者，需確認舊訂閱已徹底解除且原渠道收到退款，新方案按 Premium 正常計費，兩端沒有出現重複計費或通道衝突。**

## 用量檢視與防損提示詞配置

### 是什麼

**先搞清兩端術語對應，避免額度不知不覺跑空**。

- 每週使用限額（桌面）/ 每週用量（手機）：本週固定池，每週重置。走 SuperGrok 關聯代表已關聯授權，不包含獨立 Cursor 套餐。
- 按需用量（Billed through Cursor）：固定池耗盡後的額外計費。網頁端月度限額在支出下方的 Monthly Limit。
- 檢視路徑：桌面端進設定（Settings）> 用量與計費（Usage & Billing），移動端點每週用量，網頁端登入 [cursor.com/dashboard](https://cursor.com/dashboard)。

### 怎麼做

**把防損指令直接寫入 Bot 系統提示詞或首條對話**。

常規單 Bot 填第一段，鎖定低消耗推理並拉長輪詢週期，避免後臺空轉。

```text
你是一个自动化执行助手。在后续所有任务执行中，必须严格遵守以下资源控制规则：
1. 任务规划阶段必须输出极简执行步骤，禁止发起非必要的递归搜索与多轮冗余工具自检。
2. 在处理代码与文本分析任务时，保持适度推理强度，优先给出核心结果，不要输出冗长无关的修饰性文字。
3. 如果任务涉及定时轮询或周期监控，单次轮询时间间隔不得低于 30 分钟，严禁设置分钟级高频循环。
4. 严禁自行尝试调用外部视频生成或音频转换能力；如遇复杂多步骤任务，分步向我汇报进度并等待确认。
```

多 Bot 協同填第二段。**多 Bot 在同任務中頻繁廣播是吃額度最快的坑（作者自述，未核），必須強制走點對點鏈式通訊**。

```text
你在多智能体协同流水线中担任协同节点。必须严格执行以下通信约束：
1. 全面采用点对点（Agent-to-Agent）单向派活与回传，禁止向群聊或未指名的公共上下文广播全量数据。
2. 传递工作流结果时，只提取关键字段与结构化结果摘要，严禁将完整的历史对话日志重复打包转发。
3. 协助任务交付完毕后，立即输出任务终止状态，主动退出协作监听，切断后续消息的被动接收与重复解析。
```

策略參考自 [《鐵柱推文合集①：開通、套餐與額度》](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)。

### 做到什麼程度算好

注入提示詞後，**Bot 需明確回覆並確認遵守資源約束**。連續跑自動化指令碼三天，客戶端 Usage & Billing 用量曲線平緩，定時任務按整點間隔跑且無冗餘自檢日誌，就算達標。

## 容易踩的坑

### 選購與訂閱

- **用 Bot 別買 8 美元的 Plus 檔**。它不含 Grok Bot 和 Cloud agents，想用 Bot 必須選 30 美元的 Premium 檔。
- **Cursor Pro 和 SuperGrok 額度不疊加**。兩邊同時開不會給雙倍額度，系統只按一方算，純屬浪費錢。
- 第三方模型單獨按 API 標價計費。The X Subscription 周共享池只包自家模型。
- **選月付，別買年費**。工具和規則變動頻繁，年費會鎖死後續調整的自由度。

### 繫結與退訂

- **賬號關聯終身不可逆**。Cursor 繫結 SuperGrok 或 X Premium+ 以後客服無法解綁，千萬別拿測試小號授權。
- 老訂閱遷移只能在電腦網頁端操作，手機 App 沒開放切換入口。
- **必須去 iPhone 手動取消 Cursor 續費**。網頁端換了統一訂閱不會自動停掉 App Store 扣費，不手動退訂會被兩邊重複扣。

### 額度與使用

- **開啟按需用量並設月度限額**。每週共享池耗盡且沒開按需時，Bot 會立刻停止響應。
- **多 Bot 協作走點對點通訊**。群聊每條訊息都會向所有 Bot 廣播計算，拉進常駐群聊幾輪就會耗盡周額度。

## 做完怎麼驗收

1. **賬號許可權**：開啟桌面端點左下角頭像，確認套餐是 **Premium、Super 或 Ultra**。點選新建 Bot，確認能開啟配置面板且 Cloud agents 顯示就緒。
2. **多端額度**：在桌面端 **Settings > Usage & Billing** 記下每週用量百分比，再開啟手機端核對，兩邊數值必須完全一致。
3. **支出保護**：瀏覽器訪問 [cursor.com/dashboard](https://cursor.com/dashboard) 的 Spending 頁面，確認 **Monthly Limit** 填了美元上限，客戶端按需通道處於 Enable 狀態。
4. **實際呼叫**：發提示詞讓 Bot 跑一次簡短任務，**檢查日誌確認沒有廢話、沒有多餘工具呼叫**，用量微動就合格。
