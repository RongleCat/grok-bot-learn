# FFmpeg

<ToolMeta id="ffmpeg" />

FFmpeg 是多媒體底層處理的核心工具，適合讓 Bot 完成 **音影片轉碼、壓縮、截幀與音訊提取**。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 FFmpeg（https://ffmpeg.org/download.html），以后处理音视频转码、剪辑、压缩和截帧用它。
````

</div>
