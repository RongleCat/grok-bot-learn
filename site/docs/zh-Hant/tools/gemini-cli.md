# Gemini CLI

<ToolMeta id="gemini-cli" />

Google 開源的終端 AI Agent，適合 **付費使用者與 Google Cloud 專案使用者** 進行終端互動與開發協作。

結論是：該工具僅用於供付費使用者與 Google Cloud 專案使用者進行終端互動與開發協作。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以后终端交互和开发协作用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 需要你自己做的事

- 準備付費 Google 賬號或 Google Cloud 專案賬號。
- 在瀏覽器開啟 Bot 傳送的授權連結完成認證。
