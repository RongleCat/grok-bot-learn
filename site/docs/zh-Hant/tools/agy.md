# Antigravity CLI（agy）

<ToolMeta id="agy" />

Google 官方終端 Agent，適合 **影片理解、長文寫作與程式碼修改**，支援直接讀取影片檔案。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 Antigravity CLI（https://antigravity.google/docs/getting-started/），以后视频理解、长文写作与代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 需要你自己做的事

- 準備 Google 賬號。
- 在瀏覽器開啟 Bot 傳送的授權連結完成認證。
