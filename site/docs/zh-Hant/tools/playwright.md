# Playwright

<ToolMeta id="playwright" />

Playwright 是微軟開源的自動化庫，適合讓 Bot 執行 **批次網頁截圖與渲染抓取**，無需手動耗費瀏覽器互動額度。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Playwright（https://playwright.dev/python/docs/intro），以后网页渲染、截图和抓取任务用它。
````

</div>

## 需要你自己做的事

- 確認雲電腦具備 Python 執行環境。
