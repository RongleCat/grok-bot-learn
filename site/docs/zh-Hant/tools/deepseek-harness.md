# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

DeepSeek 官方開源的 **「一切皆外掛」架構 Agent**，支援桌面端與 Web UI。目前處於開發者預覽階段，適合用於 **程式碼編寫**、**調研分析**、**日常辦公** 與 **定時任務擴充套件**。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以后日常办公、调研、写代码和跑定时任务用它。需要配置 DeepSeek API Key 时请停下来提醒我自己填。
````

</div>

## 需要你自己做的事

- 準備好 DeepSeek API Key
- 待 Bot 安裝完畢後，在設定中自行填入 API Key
