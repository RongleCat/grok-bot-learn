# Node.js 與 npm

<ToolMeta id="nodejs" />

Node.js 與 npm 是前端及各類 AI CLI 的執行基礎，適合為 Bot 提供 **現代命令列工具的執行環境**。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装好 Node.js 与 npm（https://github.com/nvm-sh/nvm），以后运行前端项目和各类命令行工具用它。
````

</div>

## 需要你自己做的事

- 確認雲電腦網路連通，無需準備外部賬號。
