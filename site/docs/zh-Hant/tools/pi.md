# Pi Coding Agent

<ToolMeta id="pi" />

極簡且高度可擴充套件的終端編碼 Agent，適合 **透過擴充套件、技能與提示模板深度定製** 專屬開發工作流。
適合喜歡透過擴充套件、技能與提示模板定製專屬開發流的極客開發者。

結論是：該工具僅用於透過擴充套件、技能與提示模板，深度定製極簡、高擴充套件的專屬終端編碼 Agent 工作流。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Pi Coding Agent（https://pi.dev），以后定制开发工作流和写代码用它。需要填密钥时请提醒我自己填。
````

</div>

## 需要你自己做的事

- 準備對應模型服務商的 API Key。
- 收到提示後自行將金鑰寫入私密配置檔案。
