# MCP 聯結器

<ToolMeta id="mcp-connectors" />

MCP 聯結器打通了外部服務與模型的互動通道，適合讓 Bot **直接呼叫外部工具與雲端資料** 完成複雜協同。

結論是：該工具僅用於讓 Bot 直接呼叫外部工具與雲端資料完成複雜協同。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上接入 MCP 连接器（https://docs.x.ai/grok/connectors），以后调用外部工具和同步云端数据用它。需要第三方授权时把链接发给我，需要填密钥时请提醒我自己填。
````

</div>

## 需要你自己做的事

- 在瀏覽器訪問聯結器控制頁面並準備待連線賬號。
- 根據提示自行填入目標服務的地址或授權金鑰。
