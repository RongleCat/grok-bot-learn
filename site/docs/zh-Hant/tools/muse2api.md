# muse2api

<ToolMeta id="muse2api" />

社群開源的 muse.ai 逆向封裝專案，適合在 **雲電腦** 上透過 OpenAI 相容介面直接呼叫網頁端免費額度進行對話、生圖和生影片。

結論是：該工具僅用於在雲電腦上透過相容介面實現對話、生圖與生影片。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上部署 muse2api（https://github.com/czg86389-hub/muse2api），以后调用多模态接口进行对话、生图和生视频用它。需要填密钥时请提醒我自己填。
````

</div>

## 需要你自己做的事

- 準備 muse.ai 賬號並在雲電腦瀏覽器中完成登入。
- 根據提示自行填入通訊金鑰與登入狀態資料。
