# 飛書 CLI（lark-cli）

<ToolMeta id="lark-cli" />

飛書官方命令列工具，適合讓 Bot 以個人身份在 **雲電腦** 上操作飛書雲文件、多維表格、雲盤和知識庫。
Bot 以個人身份在雲電腦中操作飛書雲文件、多維表格、雲盤與知識庫。
適合需要 Bot 以個人身份在雲電腦管理飛書文件、表格與雲盤資產的使用者。


## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置飞书 CLI（https://github.com/larksuite/cli），以后操作飞书云文档、多维表格和云盘用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 需要你自己做的事

- 準備飛書個人賬號。
- 開啟驗證連結輸入終端給出的裝置碼確認授權。
