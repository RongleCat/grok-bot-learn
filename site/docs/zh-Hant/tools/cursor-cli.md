# Cursor CLI

<ToolMeta id="cursor-cli" />

Cursor 官方命令列 Agent，適合 **在雲電腦執行小範圍程式碼修改**，將 Bot 額度留給全域性決策。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 需要你自己做的事

- 準備 Cursor 賬號或相關授權憑證。
- 在瀏覽器開啟 Bot 傳送的授權連結完成登入。
