# Claude Code

<ToolMeta id="claude-code" />

Anthropic 官方終端編碼 Agent，適合 **程式碼庫閱讀、多檔案修改與命令執行**，支援後臺自動更新。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲電腦上自動安裝並驗證，遇到登入或配置金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Claude Code（https://code.claude.com/docs/en/setup），以后阅读代码库和多文件修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## 需要你自己做的事

- 準備 Claude 訂閱或 Anthropic Console 賬號。
- 在瀏覽器開啟 Bot 傳送的授權連結完成認證。
