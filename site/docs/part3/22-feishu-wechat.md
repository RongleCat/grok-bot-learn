# 第 22 章 接入飞书与微信

不用公网 IP 和自建服务器，就能把 Grok Bot 安全接入飞书与微信。

The X Subscription（2026年10月12日生效）按周扣额度，**群聊必须配消息过滤**，否则闲聊会耗光整周额度。

- **飞书多 Bot 协同**：走官方 Python SDK 长连接与「飞书应用管家」模板。
- **微信 ClawBot 直连**：靠官方「微信ClawBot」插件和 iLink 接口。
- **微信快捷指令收录**：借苹果快捷指令与 Webhook 归档记录。

## 接入通道对比与技术选型

![接入通道对比与技术选型](/info/22-feishu-wechat-s1.png)

**三种接入方式全都不需要公网 IP**。

- 飞书多 Bot 通道：用于团队办公与群聊派工。走官方 WebSocket 长连接出站，支持富文本与卡片，群内仅响应 @ 保护额度。
- 微信 ClawBot 通道：用于个人日常随身助理与调度。走 iLink 长轮询，仅支持纯文本，靠白名单单聊避免无效唤醒。
- 微信快捷指令通道：用于图文与音频资产入库。走 Webhook 单向推送并返回回执，按需触发，无消息不产生额外消耗。

## 团队接入飞书：多 Bot 协同与飞书应用管家

![团队接入飞书：多 Bot 协同与飞书应用管家](/info/22-feishu-wechat-s2.png)

### 飞书长连接与门铃触发器机制

走长连接出站，**免去公网 IP、证书和开放端口**。

1. 飞书自建应用：负责群聊与单聊收发。
2. 云端转发程序：后台监听长连接并转交。
3. 门铃触发器：唤醒 Bot 并调 SDK 回复。

怕重复配置，用「飞书应用管家」**扫码自动建应用**。

### 怎么做：从单 Bot 跑通到多 Bot 协同

#### 扫码建首个 Bot（文章主编）
1. 私聊让 Bot 调飞书 SDK 扫码建应用。**该链接为一次性凭证且仅限管理员使用，切勿点他人链接或转发。**
2. 浏览器打开链接点「创建」并确认权限，凭证自动回传。
3. 收到飞书测试消息后回复一条，**Bot 自动将你的 Open ID 写入白名单**。

#### 创建门铃例程
1. 点击 Bot 名称进 [help_grok-bot_routines.md](file:///workspace/grok-bot-learn/v3/src/help_grok-bot_routines.md) 的 **Details** 面板。
2. 在例程建 Webhook 门铃，获取 POST to 地址与 key。
3. **必须在 Bot 弹出的加密输入框提交凭证**，避免明文泄露。单聊发测试文本，Bot 正常回复即跑通。

#### 批量建应用与群聊协同
1. 导入模板 `https://x.ai/bot/AJpUlCwa8tyMX7L5UHnuY`。登记表与恢复脚本存 Git 私有仓库，不存明文密钥。
2. 向管家下令批量生成扫码链接（**每链接 1 小时有效**），扫码并在加密窗填 key，管家自动拉起转发。
3. 建群拉入各 Bot，**发 `@所有人` 确认汇报管辖范围**；`@文章主编` 调 `虚拟机服务管家`，服务管家发登记表进群即完成协同。

#### 交互安全
- **指令来源校验**：仅响应群内白名单管理员的直接指令。
- **飞书卡片确认**：改配置、写库或重启等高危操作推送带「同意」与「驳回」按钮的卡片，**在飞书内点击即可二次授权**。

### 做到什么程度算好

- **端到端耗时低于 1 秒**：发消息基本秒回。
- **群聊消息精准分流**：闲聊静默，单独 @ 谁谁回，@所有人按职责汇报不抢答。
- **高可用自愈**：退出 5 秒内拉起，每 5 分钟巡检假死，强杀进程约 9 秒恢复。

## 个人接入微信：微信 ClawBot 插件直连

![个人接入微信：微信 ClawBot 插件直连](/info/22-feishu-wechat-s3.png)

走官方 iLink 接口（`ilinkai.weixin.qq.com`），纯出站长轮询，**不开放公网端口，合规且无封号风险**。

### 三步完成接入

1. **发送提示词**：电脑端向主 Bot 发送下方指令，等待自动生成通信组件。
::: details 三步完成接入
```text
我想把你接到我的微信上，让我能在微信里直接给你发消息、收到你的回复。请按下面的思路做，每做完一步告诉我结果，需要我操作的地方停下来等我。

1、先调研方案：腾讯「微信ClawBot」插件用的是 iLink 接口（ilinkai.weixin.qq.com）。请确认怎么用 getupdates 长轮询收消息、怎么用 sendmessage 回消息。整个程序只走出站请求，不要开公网端口。

2、在 Grok Bot 里建一个由 webhook 触发的 routine，名字可以叫「微信下旨入口」。建好后告诉我去 routine 面板复制 Webhook URL 和 key，然后弹出加密弹框让我填进去，不要让我在聊天里发明文。

3、在你的云端电脑上写一个小转发程序：收到微信消息后 POST 给这个 routine；你处理完以后，用一个 reply 脚本把回复发回微信，同时在我们的主聊天里同步一份。

4、等我在手机微信里启用 ClawBot 插件以后，生成二维码让我用手机扫码确认，同时给我一个可以在微信里直接打开的备用链接。二维码大约 5 分钟有效。

5、绑定成功后，提醒我先在 ClawBot 对话里发一句话，因为回复要用到这条消息带的 context_token。

6、规则：只认绑定的这一个人，别人的消息不处理；回复一律用纯文本，不要用 Markdown，因为微信不渲染 Markdown。

7、最后告诉我：云端电脑重启以后，怎么把转发程序重新拉起来；如果遇到错误码 -14（凭证过期），提醒我重新扫码。
```
:::
2. **配置密钥**：打开主 Bot 的「微信下旨入口」例程，复制 Webhook 的 **POST to** 和 **key** 提交到加密框。
3. **绑定与激活**：
   - 微信版本须满足 **iOS ≥ 8.0.70，Android ≥ 8.0.69**，在「设置-插件」启用「微信ClawBot」。
   - 对电脑 Bot 发「插件开好了」，微信扫码授权（二维码 5 分钟内有效）。
   - **必须主动向微信 ClawBot 发首条消息**（如“你好”），获取 `context_token` 激活回包。

### 验收标准

- **双向同步**：微信端秒级回复，电脑端实时存档。
- **子 Agent 调度**：在微信直接派发推特检索、视频转录任务。
- **安全隔离**：未绑定的微信号无法唤醒。

细节见[《如何把 Grok Bot 接入你的微信？保姆级新手指南来了（附详细提示词）｜Kin》](https://jcng5q8n0f3z.feishu.cn/wiki/LehUwOhxAijkigkkVlDclVVunQg)。

## 微信内容入库：快捷指令打通聊天记录与多媒体

通过快捷指令把合并转发的 ZIP 包传给临时网盘，**再推给 Grok Bot 的 Webhook 自动归档**。

### 配置与操作

1. 在 Grok Bot 对话窗口发提示词创建例程：
```text
帮我创建一个 Webhook 触发的例行任务。快捷指令会用 POST 请求发来一个 JSON，里面只有一个字段 info。info 可能是我输入的文字，也可能是一个文件下载链接，比如微信聊天记录压缩包、截图、录音。收到后：如果是链接就先下载文件再读取，压缩包先解压；然后整理出要点，收录进知识库，最后给我一份回执，写清楚收录了什么、存在哪里。
```
在详情页 Routine 列表里，**复制 Webhook 的 POST to 地址与 key 密钥**。

2. 导入快捷指令：`https://www.icloud.com/shortcuts/2b77155d7c744110a0f0f9ef1bdc42bf`。

3. 填入 POST to、key 和图床 ID。`filebin.net` 文件存 7 天，**ID 须设 8 位以上随机字符**（如 `kb7x9q2m`）防覆盖泄露；**分享前务必清空这三项**。

4. 微信多选聊天记录，合并转发到其他应用，选快捷指令「发送给知识库 Bot」中的「接收转发」。未接收转发时会读剪贴板，也能选「截图」或「录音」直传。

### 验收标准

- **多媒体解析完整**：解压并分类图片、文档与语音（如 13 个设计灵感网站按整站、App、组件建索引）。
- **回执规范**：标清主题要点、笔记存储路径与原始 ZIP 归档路径。

参考：[《微信聊天记录打通 Grok Bot：快捷指令进阶版》](https://jcng5q8n0f3z.feishu.cn/wiki/IwrfwYt1ti0aDWk3YEdcGyQRnUb)。

## 容易踩的坑与排查方案

### 1. 飞书权限配置不足导致群消息无法接收

- **坑点**：单聊正常但群内 `@` 没反应也没日志，因初选 7 项权限，漏了「获取群组中所有 @机器人的消息」。
- **解法**：走 SDK 扫码生成补权链接，管理员确认扩到 14 项，**无需重新发版**。

### 2. 飞书群聊过滤规则误判与长连接断线重推

1. 漏消息与抢答：飞书 `@所有人` 不在 mention 数组，不验 ID 又会全员抢答。**脚本必须卡准目标 ID，只响应「`@自己`」或「`@所有人`」**。
2. 重复回复：网络恢复后官方会自动补推，**千万别手动二次补发**。

### 3. 跨 Bot 调用的信任链与授权卡片缺失

1. 群里 Bot 互调没反应，是**跨 Bot 消息默认不可信**，全卡在私聊等确认。
2. 转发层配白名单认管理员 Open ID；高危操作推**带同意/驳回的飞书卡片**确认。

### 4. 虚拟机 Python 运行环境路径错误

- 脚本报错提示找不到 `lark-oapi`，通常是配置守护任务时**误用了系统默认的 `/usr/bin/python3`**。
- 在启动脚本、Supervisor 和定时任务里，**必须写死虚拟环境的绝对路径**（如 `/home/user/venv/bin/python3`），别直接调系统全局环境。

### 5. 微信 ClawBot 二维码失效与错误码 -14

- 二维码**只有 5 分钟有效期**，超时会失效，出来后赶紧用手机扫。
- 后台报错误码 **`-14`** 是凭证过期了，重新生成二维码让管理员再扫一次就行。

### 6. 微信消息格式混乱与 Markdown 渲染失败

- 微信**不解析 Markdown**，星号、反引号和标题符号都会直接露出来。
- 在接入提示词或转发脚本里加过滤，**统一转成带换行的纯文本**再发给微信。

### 7. 微信合并转发 ZIP 缺少未加载的多媒体附件

微信不存原文件，没点开加载的不会打进压缩包，解压就会丢图片。

1. 转发前，**逐个点开需要保存的图片和文件**。
2. 等本地完全加载好，再去打包转发。

### 8. 临时网盘的命名冲突与隐私泄露风险

`filebin.net` 没账号体系，ID 太简单会撞车，导致报错或下到别人的文件。用的时候注意：

- 图床 ID **必须设为 8 位以上随机字符串**。
- 别传密码、身份证等隐私内容。
- 分享快捷指令前，**删掉自己的专属 ID 与 Webhook 密钥**。

### 9. The X Subscription 统一订阅下的额度防耗控制

群员闲聊会触发例程空转，**一到两天就会耗尽周额度导致 Bot 停止响应**。

2026 年 10 月 12 日起 The X Subscription 按周从共享池扣额度。

Plus 档（$8/月）没有 Grok Bot，只有 Premium（$30/月，4x 额度）、Super（$100/月，15x 额度）与 Ultra（$200/月，50x 额度）包含。

防耗抓两点：
1. **仅在精准提及（`@自己`）或特定管理员指令时触发 Webhook**。
2. 严禁全群无差别监听，避免配置高频短周期轮询。

详细规则参考 [help_grok-bot_plans.md](file:///workspace/grok-bot-learn/v3/src/help_grok-bot_plans.md) 与 [help_grok-bot_routines.md](file:///workspace/grok-bot-learn/v3/src/help_grok-bot_routines.md)。

## 实战案例复盘

### 飞书多 Bot 协同（铁柱AGI）
没公网 IP 也能跑协同，**核心是用出站长连接免打洞**。
1. **批量注册**：飞书 Python SDK 扫码授权，管家 Bot 读 Git 备份表，托管主编、记账与虚拟机 3 个 Bot 的密钥和 Webhook。
2. **安全确认**：群内仅响应 `@自己` 或 `@所有人`。**高敏感操作由 Bot 推卡片按钮人工授权**。

### 微信 ClawBot 随身台（Kin）
微信内调度推特运营与文案提取 Bot，**走官方插件长轮询能防封号**。
1. 给 7×24 小时云电脑发提示词，调腾讯 iLink（`ilinkai.weixin.qq.com`）跑通 `getupdates` 轮询与 `sendmessage` 脚本。
2. 弹窗交接 Webhook 和密钥，扫码发首条消息拿到初始 `context_token`。
3. **踩坑点**：**微信回复必须强制转纯文本**，剥除 Markdown 符号。

### 微信图文归库流水线
微信沙盒禁了整包直传，**用临时网盘当中转可绕过限制**。
1. **中转上传**：Mac 或 iPhone 用「合并转发」导出聊天 ZIP 包，快捷指令自动传到 `filebin.net`。
2. **自动归档**：快捷指令拼 JSON 发给 Grok Bot 的 Webhook，解压归档「13 个设计灵感网站」等图文。
3. **验收标准**：**必须输出带路径与摘要的结构化回执**。

## 做完怎么验收

### 飞书
1. **消息响应**：私聊 1 秒内回复；群聊发普通文字静默，单独 `@文章主编` 响应，`@所有人` 各 Bot 依次汇报。
2. **权限与自愈**：后台开齐 14 项事件权限并支持卡片授权；手动杀掉进程，5 至 10 秒内自动拉起。

### 微信
1. **环境与握手**：微信高于 iOS 8.0.70 或 Android 8.0.69 并启用插件；扫码首条用 `context_token` 回复且无 Markdown 乱码。
2. **拦截与报错**：未绑定账号直接忽略；重启后自动拉起，**遇到错误码 `-14` 提示重新扫码**。

### 快捷指令
1. **入库操作**：填好 Webhook、Bearer 密钥及 8 位以上图床 ID；微信先点开加载附件再合并转发，也能独立唤醒。
2. **输出与对账**：**回执须包含提要、笔记路径与留存路径**；在方案页核查用量，避免持续空转扣费。
