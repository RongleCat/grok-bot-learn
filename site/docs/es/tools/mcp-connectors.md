# Conectores MCP

<ToolMeta id="mcp-connectors" />

Los conectores MCP abren un canal de interacción entre los servicios externos y el modelo, ideal para permitir que el Bot **invoque directamente herramientas externas y datos en la nube** para llevar a cabo colaboraciones complejas.

En conclusión: esta herramienta se utiliza únicamente para que el Bot invoque directamente herramientas externas y datos en la nube con el fin de completar colaboraciones complejas.

## Prompt para enviar al Bot

Copia todo el contenido a continuación y envíalo a tu Grok Bot; se instalará y verificará automáticamente en la computadora en la nube, y se pausará para esperar tu intervención si requiere inicio de sesión o configuración de claves.

<div class="tool-prompt">

````text
帮我在你的云电脑上接入 MCP 连接器（https://docs.x.ai/grok/connectors），以后调用外部工具和同步云端数据用它。需要第三方授权时把链接发给我，需要填密钥时请提醒我自己填。
````

</div>

## Lo que debes hacer tú mismo

- Accede a la página de control de conectores en el navegador y prepara la cuenta que se va a conectar.
- Introduce la dirección del servicio de destino o las claves de autorización según las indicaciones.
