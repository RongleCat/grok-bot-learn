# GitHub CLI (gh)

<ToolMeta id="gh" />

La herramienta oficial de línea de comandos de GitHub, ideal para permitir que el Bot clone repositorios privados, envíe código, cree PR y gestione Actions en la **computadora en la nube**.

La conclusión es: esta herramienta solo se utiliza para permitir que el Bot clone repositorios privados de GitHub, envíe código, cree PR y gestione Actions en la computadora en la nube.

## Prompt para enviar al Bot

Copia el texto completo que aparece a continuación y envíalo a tu Grok Bot. Lo instalará y verificará automáticamente en la computadora en la nube, y se pausará para esperar tu intervención cuando requiera iniciar sesión o configurar claves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 GitHub CLI（https://github.com/cli/cli/blob/trunk/docs/install_linux.md），以后管理代码仓库、推送分支和提交 PR 用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## Lo que necesitas hacer tú

- Preparar una cuenta de GitHub.
- Abrir el enlace de autorización en el navegador e ingresar el código de verificación de un solo uso correspondiente.
