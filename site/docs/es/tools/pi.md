# Pi Coding Agent

<ToolMeta id="pi" />

Un agente de codificación de terminal minimalista y altamente extensible, ideal para **personalizar a fondo** flujos de trabajo de desarrollo propios **mediante extensiones, habilidades y plantillas de prompts**.
Ideal para desarrolladores geek a quienes les gusta personalizar sus propios flujos de desarrollo a través de extensiones, habilidades y plantillas de prompts.

En conclusión: esta herramienta se utiliza exclusivamente para personalizar a fondo flujos de trabajo de agentes de codificación de terminal minimalistas y altamente extensibles a través de extensiones, habilidades y plantillas de prompts.

## Prompt para enviar al Bot

Copia todo el contenido siguiente y envíalo a tu Grok Bot; este lo instalará y verificará automáticamente en la computadora en la nube, y se detendrá a esperar tus instrucciones si se requiere iniciar sesión o configurar claves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Pi Coding Agent（https://pi.dev），以后定制开发工作流和写代码用它。需要填密钥时请提醒我自己填。
````

</div>

## Lo que debes hacer tú mismo

- Preparar la API Key del proveedor de modelos correspondiente.
- Escribir la clave en el archivo de configuración privado por tu cuenta tras recibir el aviso.
