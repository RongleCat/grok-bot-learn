# Claude Code

<ToolMeta id="claude-code" />

Agent oficial de codificación en terminal de Anthropic, ideal para **lectura de bases de código, modificación de múltiples archivos y ejecución de comandos**, con soporte para actualizaciones automáticas en segundo plano.

La conclusión es: Claude Code es ideal para la lectura de bases de código, modificación de múltiples archivos y ejecución de comandos, y admite actualizaciones automáticas en segundo plano.

## Prompt para enviar al Bot

Copia el contenido completo que aparece a continuación y envíalo a tu Grok Bot. Este se instalará y verificará automáticamente en la computadora en la nube, y se pausará para esperar tu intervención si es necesario iniciar sesión o configurar una clave.


## Lo que debes hacer tú mismo

- Preparar una suscripción a Claude o una cuenta de Anthropic Console.
- Abrir en el navegador el enlace de autorización enviado por el Bot para completar la autenticación.
