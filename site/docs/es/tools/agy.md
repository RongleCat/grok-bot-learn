# Antigravity CLI (agy)

<ToolMeta id="agy" />

Agent de terminal oficial de Google, ideal para la **comprensión de video, redacción de textos largos y modificación de código**, con soporte para leer archivos de video directamente.

En conclusión: agy es ideal para la comprensión de video, redacción de textos largos y modificación de código, con soporte para leer archivos de video directamente.

## Prompt para enviar al Bot

Copia el siguiente texto completo y envíalo a tu Grok Bot. Se instalará y verificará automáticamente en la computadora en la nube, y se detendrá a esperar tus instrucciones si requiere inicio de sesión o configuración de claves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 Antigravity CLI（https://antigravity.google/docs/getting-started/），以后视频理解、长文写作与代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## Lo que necesitas hacer tú

- Preparar una cuenta de Google.
- Abrir el enlace de autorización enviado por el Bot en el navegador para completar la autenticación.
