# Gemini CLI

<ToolMeta id="gemini-cli" />

Agente de IA para terminal de código abierto de Google, adecuado para que **usuarios de pago y usuarios de proyectos de Google Cloud** interactúen en la terminal y colaboren en el desarrollo.

La conclusión es: esta herramienta está destinada únicamente a que usuarios de pago y usuarios de proyectos de Google Cloud realicen interacción en terminal y colaboración en el desarrollo.

## Prompt para enviar al Bot

Copia todo el texto a continuación y envíalo a tu Grok Bot; este lo instalará y verificará automáticamente en la computadora en la nube, y se pausará para esperar tu acción cuando requiera inicio de sesión o configuración de claves.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以后终端交互和开发协作用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## Lo que debes hacer tú mismo

- Preparar una cuenta de Google de pago o una cuenta de proyecto de Google Cloud.
- Abrir en el navegador el enlace de autorización enviado por el Bot para completar la autenticación.
