# Conexión persistente del bot de Feishu

<ToolMeta id="feishu-bot" />

Solución de mensajería con conexión persistente basada en el SDK oficial de Python para Feishu, adecuada para implementar la escucha de eventos y la colaboración mediante bots en chats grupales en una **computadora en la nube** sin necesidad de una IP pública.

## Prompt para enviar al bot

Copia todo el contenido siguiente y envíalo a tu Grok Bot. Se instalará y verificará automáticamente en la computadora en la nube, y se pausará a la espera de tus instrucciones si se requiere iniciar sesión o configurar claves secretas.

<div class="tool-prompt">

````text
帮我在你的云电脑上配置基于飞书 Python SDK（https://github.com/larksuite/oapi-sdk-python）的长连接机器人，以后接收群聊事件和派发任务用它。需要填密钥时请提醒我自己填。
````

</div>

## Lo que debes hacer tú mismo

- Crear una aplicación personalizada de empresa en la plataforma abierta de Feishu y habilitar las funciones de conexión persistente y de bot.
- Ingresar el App ID y el App Secret de la aplicación por tu cuenta según las instrucciones.
