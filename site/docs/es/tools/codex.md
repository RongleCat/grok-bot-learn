# Codex CLI

<ToolMeta id="codex" />

Agente de codificación en terminal oficial de OpenAI, ideal para la **modificación de código, ejecución de scripts y generación y revisión de imágenes**, con acceso directo a la cuota de suscripción de ChatGPT.
Adecuado para suscriptores de ChatGPT que necesiten modificar código, ejecutar scripts y generar o revisar imágenes.


## Prompt para enviar al Bot

Copia el contenido completo que aparece a continuación y envíalo a tu Grok Bot; este lo instalará y verificará automáticamente en la computadora en la nube, y se pausará a la espera de tus instrucciones si se requiere iniciar sesión o configurar claves.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Codex CLI（https://developers.openai.com/codex/cli），用我的 ChatGPT 账号登录，以后写代码、跑脚本和生图用它。需要我授权时把链接发给我。
````

</div>

## Lo que debes hacer tú

- Preparar una cuenta de ChatGPT y confirmar que el inicio de sesión mediante código de dispositivo esté habilitado.
- Abrir en el navegador el enlace con el código de dispositivo enviado por el Bot para completar la confirmación.
