# Cursor CLI

<ToolMeta id="cursor-cli" />

Agente oficial de línea de comandos de Cursor, ideal para **realizar modificaciones de código a pequeña escala en la computadora en la nube**, reservando la cuota del Bot para decisiones globales.

## Prompt para enviar al Bot

Copia todo el texto a continuación y envíalo a tu Grok Bot. Se instalará y verificará automáticamente en la computadora en la nube, y se detendrá a esperar tu intervención si requiere iniciar sesión o configurar claves.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## Lo que necesitas hacer tú

- Preparar una cuenta de Cursor o credenciales de autorización correspondientes.
- Abrir en el navegador el enlace de autorización enviado por el Bot para completar el inicio de sesión.
