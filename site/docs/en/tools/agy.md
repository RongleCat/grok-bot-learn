# Antigravity CLI (agy)

<ToolMeta id="agy" />

Google's official terminal agent, ideal for **video understanding, long-form writing, and code modifications**, with support for directly reading video files.

## Prompt to Send to the Bot

Copy the entire text below and send it to your Grok Bot. It will automatically install and verify it on the cloud computer, pausing to wait for your action if login or key configuration is required.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 Antigravity CLI（https://antigravity.google/docs/getting-started/），以后视频理解、长文写作与代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## What You Need to Do Yourself

- Prepare a Google account.
- Open the authorization link sent by the Bot in your browser to complete authentication.
