# Node.js and npm

<ToolMeta id="nodejs" />

Node.js and npm are foundational for front-end development and various AI CLIs, suitable for providing the Bot with a **modern command-line tool runtime environment**.

## Prompt to Send to the Bot

Copy the entire content below and send it to your Grok Bot. It will automatically install and verify it on the cloud computer, pausing to wait for your action if login or key configuration is required.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装好 Node.js 与 npm（https://github.com/nvm-sh/nvm），以后运行前端项目和各类命令行工具用它。
````

</div>

## What You Need to Do Yourself

- Confirm network connectivity on the cloud computer; no external account is required.
