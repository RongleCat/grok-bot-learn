# yt-dlp

<ToolMeta id="yt-dlp" />

yt-dlp is a command-line audio and video download tool that supports thousands of sites, suitable for letting the Bot **batch download videos or extract audio** for subsequent transcription processing.

## Prompt to Send to the Bot

Copy the entire content below and send it to your Grok Bot. It will automatically install and verify it on the cloud computer, pausing to wait for your action if it encounters login or key configuration.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 yt-dlp（https://github.com/yt-dlp/yt-dlp），以后批量下载音视频和提取音频用它。
````

</div>

## What You Need to Do

- Prepare the target media links you need to download.
- Export the corresponding cookie file as a backup when encountering sites that require login.
