# Claude Code

<ToolMeta id="claude-code" />

Anthropic's official terminal coding agent, ideal for **codebase reading, multi-file editing, and command execution**, supporting background auto-updates.

The bottom line: Claude Code is ideal for codebase reading, multi-file editing, and command execution, supporting background auto-updates.

## Prompt to Send to the Bot

Copy the entire text below and send it to your Grok Bot. It will automatically install and verify it on the cloud computer, pausing to wait for your action if login or key configuration is required.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Claude Code（https://code.claude.com/docs/en/setup），以后阅读代码库和多文件修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## What You Need to Do Yourself

- Prepare a Claude subscription or Anthropic Console account.
- Open the authorization link sent by the Bot in your browser to complete authentication.
