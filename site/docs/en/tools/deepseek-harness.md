# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

DeepSeek's official open-source **"everything-is-a-plugin" architecture Agent**, supporting desktop and Web UI. Currently in developer preview, it is suitable for **coding**, **research & analysis**, **daily office tasks**, and **scheduled task extensions**.

## Prompt to Send to Bot

Copy the entire text below and send it to your Grok Bot. It will automatically install and verify it on the cloud computer, pausing to wait for your action if login or key configuration is needed.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装配置 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以后日常办公、调研、写代码和跑定时任务用它。需要配置 DeepSeek API Key 时请停下来提醒我自己填。
````

</div>

## What You Need to Do Yourself

- Have your DeepSeek API Key ready
- After the Bot finishes installation, enter the API Key yourself in settings
