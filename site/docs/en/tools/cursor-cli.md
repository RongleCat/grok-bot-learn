# Cursor CLI

<ToolMeta id="cursor-cli" />

The official command-line Agent from Cursor, ideal for **executing small-scoped code modifications on the Cloud Computer**, saving Bot quota for global decision-making.

## Prompt to Send to the Bot

Copy the entire content below and send it to your Grok Bot. It will automatically install and verify it on the Cloud Computer, pausing to wait for your action if login or key configuration is required.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## What You Need to Do

- Prepare a Cursor account or relevant authorization credentials.
- Open the authorization link sent by the Bot in your browser to complete login.
