# muse2api

<ToolMeta id="muse2api" />

A community open-source reverse-engineered wrapper project for muse.ai, suitable for directly calling web-tier free quotas on a **Cloud PC** via an OpenAI-compatible interface for chat, image generation, and video generation.

The takeaway is: this tool is solely used to enable chat, image generation, and video generation via compatible interfaces on a Cloud PC.

## Prompt to Send to the Bot

Copy the entire content below and send it to your Grok Bot. It will automatically install and verify it on the Cloud PC, pausing to wait for your action when login or key configuration is needed.

<div class="tool-prompt">

````text
帮我在你的云电脑上部署 muse2api（https://github.com/czg86389-hub/muse2api），以后调用多模态接口进行对话、生图和生视频用它。需要填密钥时请提醒我自己填。
````

</div>

## What You Need to Do Yourself

- Prepare a muse.ai account and complete login in the Cloud PC browser.
- Enter the communication key and login session data yourself according to the prompts.
