# Playwright

<ToolMeta id="playwright" />

Playwright is an open-source automation library by Microsoft, ideal for having the Bot perform **batch webpage screenshots and rendered scraping** without manually consuming browser interaction quotas.

## Prompt to Send to the Bot

Copy the entire text below and send it to your Grok Bot. It will automatically install and verify it on the cloud computer, pausing to wait for your action if it encounters login or key configuration steps.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Playwright（https://playwright.dev/python/docs/intro），以后网页渲染、截图和抓取任务用它。
````

</div>

## What You Need to Do Yourself

- Confirm that the cloud computer has a Python runtime environment.
