## Prompt to Send to the Bot

Copy the entire text below and send it to your Grok Bot. It will automatically install and verify it on the Cloud PC, pausing to await your action if a login or key configuration is required.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Pi Coding Agent（https://pi.dev），以后定制开发工作流和写代码用它。需要填密钥时请提醒我自己填。
````
