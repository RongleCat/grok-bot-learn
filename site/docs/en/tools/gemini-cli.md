# Gemini CLI

<ToolMeta id="gemini-cli" />

Google's open-source terminal AI Agent, suitable for **paid users and Google Cloud project users** for terminal interaction and development collaboration.

Conclusion: this tool is only intended for paid users and Google Cloud project users for terminal interaction and development collaboration.

## Prompt to Send to the Bot

Copy the entire snippet below and send it to your Grok Bot. It will automatically install and verify it on the cloud computer, pausing to wait for your action when login or key configuration is needed.

<div class="tool-prompt">

````text
帮我在你的云电脑上安装 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以后终端交互和开发协作用它。需要登录或授权时停下来把链接发给我由我完成。
````

</div>

## What You Need to Do Yourself

- Prepare a paid Google account or Google Cloud project account.
- Open the authorization link sent by the Bot in your browser to complete authentication.
