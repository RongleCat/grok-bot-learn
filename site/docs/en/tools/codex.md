# Codex CLI

<ToolMeta id="codex" />

OpenAI's official terminal coding agent, suitable for **code modification, script execution, and image generation/review**, and can directly use ChatGPT subscription quota.
Suitable for ChatGPT subscribers who need to modify code, execute scripts, and generate/review images.

## Prompt to Send to the Bot

Copy the entire text below and send it to your Grok Bot. It will automatically install and verify it on your cloud computer, pausing to wait for your action if login or key configuration is required.

<div class="tool-prompt">

````text
帮我在你的云电脑上装好 Codex CLI（https://developers.openai.com/codex/cli），用我的 ChatGPT 账号登录，以后写代码、跑脚本和生图用它。需要我授权时把链接发给我。
````

</div>

## What You Need to Do

- Prepare a ChatGPT account and confirm that device code login permission is enabled.
- Open the device code link sent by the bot in your browser to complete confirmation.
