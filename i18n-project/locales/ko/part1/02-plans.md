# 제2장 플랜 및 구독: 먼저 올바른 등급 선택하기

초보자가 구독을 구매할 때 흔히 겪는 세 가지 함정이 있습니다.
- 가장 저렴한 입문용 요금제를 구매했다가 클라이언트를 열었을 때 에이전트 진입 메뉴를 찾지 못합니다.
- **Cursor 구독과 SuperGrok 주간 크레딧은 중복 합산되지 않으며, 시스템은 더 높은 쪽만 인정합니다.**
- 모바일 앱 내에서 업그레이드를 클릭해도 전환할 수 없으며, 기존 서드파티 모델 사용량까지 잃게 됩니다.

Grok Bot 실행은 크레딧에 의존합니다. **주간 사용량이 모두 소진되고 온디맨드 보호가 구성되어 있지 않으면, 클라우드 자동화 작업이 즉시 중단됩니다.**

공식적으로 2026년 10월 12일부터 The X Subscription 통합 구독을 시행하며, 무료 등급과 4개의 유료 등급으로 나뉩니다.


![플랜 및 구독: 먼저 올바른 등급 선택하기](/info/02-plans.png)

## Grok Bot을 사용하려면 어떤 구독 요금제를 구매해야 할까? {#统一订阅全貌-the-x-subscription-的四档与免费档}

**통합 구독은 Plus, Premium, Super, Ultra 4개 등급으로 나뉘며, Plus 등급에는 Grok Bot이 전혀 포함되지 않으므로 자동화 작업을 실행하려면 최소 월 30달러의 Premium 등급을 선택해야 합니다.**

![통합 구독 전모: The X Subscription의 4개 등급 및 무료 등급](/info/02-plans-s1.png)

### 무엇인가요

2026년 10월 12일부터 The X Subscription으로 통합되었으며, 연간 결제는 월간 결제의 10배입니다.

달러당 사용량으로 환산하면(Plus를 기준 1로 볼 때, Premium 약 1.07, Super 약 1.2, Ultra 약 2.0, 작성자 서술, 미검증), 등급이 높을수록 자사 모델이 더 유리합니다.

| 플랜 | 웹 월간 / 연간 결제 | Grok Bot |
| :--- | :--- | :--- |
| **무료 플랜** | $0 | 7일 크레딧 체험 |
| **Plus** | 월 $8(실제 월 약 $7 상당) / 연 $80 | 미포함 |
| **Premium** | 월 $30 / 연 $300 | 포함(진입 기준) |
| **Super** | 월 $100 / 연 $1000 | 포함 |
| **Ultra** | 월 $200 / 연 $2000 | 포함(최고 한도) |

**Plus 등급에는 Grok Bot 및 Cloud agents가 전혀 포함되지 않으므로**, 자동화 작업을 실행하려면 최소 월 30달러의 Premium 등급을 선택해야 합니다. 무료 체험은 유효기간이 7일로 제한되며, 크레딧은 작업 규모, 단계 및 토큰 수에 따라 차감됩니다. 무거운 작업은 한 번에 소진될 수 있으며 소진 후 복구되지 않습니다.

### 진행 방법

**구독 신청은 모바일 결제를 피하고 웹사이트를 통해 진행하는 것을 권장합니다.**

1. 브라우저에서 통합 구독 페이지 [grok.com/com/overlay/subscribe](https://grok.com/com/overlay/subscribe?from=/)에 접속합니다.
2. 업무용으로 사용할 X 또는 Grok 계정으로 로그인합니다.
3. Premium 등급을 선택합니다(월 $30, 커뮤니티에서 첫 달 50% 할인인 $15 프로모션이 확인되기도 했으나 결제 페이지 기준).
4. 언제든 등급을 변경하거나 도구를 바꿀 수 있도록 **연간 결제를 바로 선택하지 말고 월간 결제를 선택하세요**.
5. 지원되는 해외 결제 신용카드, 체크카드 또는 웹 브라우저의 Apple Pay, Google Pay로 결제합니다.
6. Grok Bot 클라이언트를 열어 로그인하고, 메인 인터페이스에서 에이전트 생성 및 실행 권한이 활성화되었는지 확인합니다.

자세한 해설은 [《통합 X 구독 분석: 신규 사용자는 어떻게 선택해야 하며 기존 구독자는 전환해야 할까? 한 편으로 정리》](https://jcng5q8n0f3z.feishu.cn/wiki/Myw6wFW8EicOiRkoEAXcVJqinee) 및 [《铁柱 트윗 모음 ①: 개통, 요금제 및 크레딧》](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)을 참조하세요.

### 달성 기준

Grok Bot 데스크톱 클라이언트를 열었을 때, **새 작업을 클라우드 환경에 할당하여 실행할 수 있고 청구서에 월간 결제되는 Premium 상태로 표시되면** 정상입니다.

## Grok Bot 주간 사용량 풀은 어떻게 정산되나요? {#每周共享用量池-额度结算与多端共用机制}

**구독은 매주 고정 크레딧 풀을 제공하며 여러 기기 간 실시간으로 동기화됩니다. 공식 모델은 웹, Bot, Cursor 코드 완성에서 작업량과 단계 수에 따라 공유 풀에서 차감되고, 서드파티 모델은 표시 가격에 따라 별도로 청구됩니다.**

![주간 공유 사용량 풀: 크레딧 정산 및 멀티 디바이스 공유 메커니즘](/info/02-plans-s2.png)

### 무엇인가요

The X Subscription은 매주 고정 크레딧 풀을 제공하며, 만료 시 자동으로 갱신됩니다. **Grok 웹, Bot, Cursor 완성 및 Q&A가 이 풀을 공유합니다.** Mac과 iPhone에서 동일한 계정으로 로그인하면 크레딧이 실시간 동기화되며, 기기를 변경해도 중복 차감되지 않습니다.

| 모델 구분 | 정산 규칙 |
| :--- | :--- |
| 공식 모델 | 공유 풀에 포함되며, 웹과 Bot 모두 여기서 크레딧이 차감됩니다. 소진 속도는 오직 작업량과 단계 수에 따라 결정됩니다. |
| 서드파티 모델 | **공유 풀에 포함되지 않으며**, Cursor에서 API 표시 가격에 따라 별도로 청구됩니다. |

시스템이 Bot의 기본 모델을 자동으로 지정하며, 'Grok Bot 사용량'으로 일괄 표시되므로 직접 선택하거나 차단할 수 없습니다. 자세한 내용은 [Grok Bot 모델](https://cursor.com/cn/help/grok-bot/models.md)을 참조하세요.

### 진행 방법

처음 3일 만에 크레딧이 모두 소진되는 것을 방지하려면, 일상적으로 다음 3단계 계획을 따르세요.

1. **주 초반에 핵심 헤비 작업을 먼저 실행합니다.** 핵심 코드 작성, 아키텍처 구축, 복잡한 로직 디버깅을 우선적으로 처리하세요.
2. **소모량이 큰 작업은 피합니다.** 비디오 대량 생성, 고빈도 폴링(polling), 다중 Bot 연동 작업이 가장 빠르게 크레딧을 소진합니다(작성자 서술, 미검증). 비디오 제작은 웹 버전을 이용하고 Bot 워크플로에는 넣지 않는 것을 권장합니다.
3. **리셋 주기를 주시합니다.** 대시보드에 표시된 주간 리셋 날짜를 명확히 기억하고, 리셋 직전에 여유 크레딧이 남아있을 때 데이터 정리나 심층 검토 작업을 집중적으로 진행하세요.

### 달성 기준

**일반적인 자동화 환경에서는 일일 평균 소모량을 10%~15% 수준으로 안정적으로 유지합니다.** 매주 리셋 전날 약 20%의 버퍼를 남겨두고, 크레딧 부족 경고 팝업이 뜨지 않는다면 적절한 페이스로 관리되고 있는 것입니다.

## Cursor와 Grok을 연결하여 크레딧을 공유하려면 어떻게 해야 하나요? {#授权互通-cursor-套餐与-supergrok-关联规则}

**Cursor는 Grok 계정과 직접 연결하여 크레딧을 매핑할 수 있으며, 연동 시 기존 요금제가 변경되지 않고 추가 비용도 없습니다. 크레딧은 양쪽 중 더 높은 등급 기준으로 적용되며 합산되지 않고, 한 번 페어링되면 평생 고정되어 연동 해제나 이전이 불가능합니다.**

![권한 연동: Cursor 요금제와 SuperGrok 연결 규칙](/info/02-plans-s3.png)

### 무엇인가요

Cursor 계정은 Grok 계정과 직접 연동하여 사용량을 공유할 수 있습니다. **연동하기 전에 먼저 3가지 엄격한 규칙을 확인하세요.**

- 크레딧만 동기화되며 요금제는 변경되지 않음: 사용량이 직접 매핑될 뿐 기존 Cursor 요금제는 변경되지 않으며, 추가 요금도 청구되지 않습니다.
- 크레딧은 합산되지 않고 최고 등급만 적용됨: 양쪽의 주간 크레딧 중 더 높은 쪽이 적용됩니다. 예를 들어 Cursor Pro에 SuperGrok Plus를 연결하면 Plus 크레딧으로 상향 적용됩니다.
- 연동 후 평생 잠금, 해제 불가: 페어링이 완료된 후에는 **직접 조작하든 고객지원팀에 문의하든 연동을 해제하거나 라이선스를 이전할 수 없습니다.**

| Cursor 구독 등급 | 연동 동등 등급 | Grok Bot 주간 사용량 |
| :--- | :--- | :--- |
| Cursor Pro | SuperGrok / X Premium+ | 기본 주간 사용량 |
| Cursor Pro+ | SuperGrok Plus | 넉넉한 주간 사용량 |
| Cursor Ultra | SuperGrok Heavy | 최고 주간 사용량 |
| Cursor 요금제 없음 | SuperGrok Lite | Grok Bot 미제공(Lite 등급은 권한이 없으므로 업그레이드 후 연동 필요) |

Grok Business 기업용 시트가 할당된 경우 계정 자체에 Bot 권한이 포함되어 있으므로, **웹 페이지에서 별도의 연동 작업을 진행할 필요가 없습니다.**

### 진행 방법

개인 계정 연동은 웹에서 진행합니다.

1. 크레딧을 부여받을 Cursor 계정으로 브라우저에서 Grok Bot 웹사이트에 로그인하고, 기본 계정이 올바른지 먼저 확인합니다.
2. 온보딩 빠른 시작 링크 [cursor.com/bot/onboarding](https://cursor.com/bot/onboarding)에 접속합니다.
3. 'Grok 계정 연결(Link Grok Account)'을 클릭합니다. 모바일의 경우 구독 페이지에서 동일한 이름의 버튼을 누릅니다.
4. 페이지 이동 후 SuperGrok, SuperGrok Plus, SuperGrok Heavy 또는 X Premium+를 보유한 계정으로 로그인하여 인증을 진행합니다.
5. 클라이언트 설정 페이지로 돌아와 상태를 확인합니다. **새로운 크레딧이 동기화되기까지 최대 24시간이 걸릴 수 있으므로, 이 시간 동안 중복으로 연동을 클릭하거나 해제를 시도하지 마세요.**

전체 규칙은 공식 문서 [Grok Bot에 SuperGrok 연결](https://cursor.com/cn/help/grok-bot/supergrok.md)을 참조하세요.

**기업용 시트가 할당된 사용자는 추가 연동 없이 바로 로그인하기만 하면 됩니다.**

1. 데스크톱 앱에서 Settings > General로 이동한 후 Sign Out을 클릭하여 현재 계정에서 로그아웃합니다(모바일 앱도 동일).
2. 로그인 화면으로 돌아가 'Sign in with Grok'을 클릭합니다.
3. Business 시트가 할당된 Grok 인증 정보를 입력하여 로그인하면, 시스템이 해당 시트의 크레딧을 자동으로 연결합니다.

### 달성 기준

데스크톱 앱의 Settings > Usage & Billing을 엽니다.

**플랜 관리 하단에 해당하는 연동 등급 태그가 표시되고, 주간 크레딧 표시줄에 리셋 주기가 표시되며 계정에 중복 결제가 발생하지 않았다면 연동이 성공한 것입니다.**

## 팀 요금제 시트 및 온디맨드(On-demand) 결제 구성

### 무엇인가요

팀원은 각자의 Cursor 계정으로 Grok Bot에 바로 로그인할 수 있으며, 사용량은 팀 할당량에서 차감됩니다. **관리자가 별도로 시트를 할당할 필요가 없으며, 팀원 역시 별도의 승인이 필요하지 않습니다.**

주간 크레딧이 소진되면 자동으로 온디맨드 사용량(청구서에는 Billed through Cursor로 표기)으로 전환됩니다. 시스템에 보호 장치가 마련되어 있어 **월간 한도를 초과하여 실행 중인 작업도 중간에 강제 중단되지 않고** 현재 작업을 완전히 끝까지 실행할 수 있습니다.

### 진행 방법

1. 클라이언트에서 **Settings(설정)** > **Usage & Billing**을 엽니다.
2. '온디맨드 사용량 월간 한도'를 찾아 Disabled로 표시되어 있다면 오른쪽의 **Enable**을 클릭하여 활성화합니다.
3. 최초 구성 시 신용카드 등록이 필요하며, [cursor.com/dashboard](https://cursor.com/dashboard)에서 **Spending(지출)**을 클릭합니다.
4. **Monthly Limit**에 월간 초과 사용 한도액을 입력(예: 예산 초과 방지를 위해 20달러 또는 50달러로 설정)하고 저장합니다.

**iOS 및 Android 모바일 앱에서는 한도를 직접 설정할 수 없으므로**, 반드시 웹 대시보드에 접속해야 합니다. 자세한 요금 체계는 공식 문서 [플랜 및 요금 체계](https://cursor.com/cn/help/grok-bot/plans.md)를 참조하세요.

### 달성 기준

Usage & Billing에서 온디맨드 사용량이 활성화 상태로 표시되고 설정된 한도 금액이 보여야 합니다. **주간 크레딧이 모두 소진되었을 때도 작업이 오류로 중단되지 않고**, 원활하게 온디맨드 채널로 전환되어 끝까지 완료된다면 정상입니다.

### 무엇인가요

The X Subscription 통합 구독은 2026년 10월 12일에 출시되었습니다. 직접 전환하지 않는 사용자의 경우 기존 요금제, 가격 및 기능이 그대로 유지됩니다. 연간 결제 주기는 만료일까지 온전히 유지되며, 향후 변동 사항이 발생하더라도 갱신 시점에만 적용됩니다.

**웹에서 작업을 확정하면 즉시 영구 적용되며, 고객지원팀에 문의하더라도 취소하거나 이전 요금제로 되돌릴 수 없습니다.** 기존 구독은 정산 시 자동으로 종료되며 일할 계산되어 환불됩니다. 환불금은 전액 지불해야 하는 신규 요금제 결제에 바로 공제되지 않으며, 청구 주기는 당일부터 새로 시작됩니다. 모바일 클라이언트는 현재 전환을 지원하지 않으므로 반드시 웹에서 진행해야 합니다.

| 결제 채널 및 구독 상품 | 환불 경로 및 사용자 조치 |
| :--- | :--- |
| 웹에서 직접 구매한 기존 요금제 | 공식 시스템에서 원래 결제 카드로 일할 계산하여 자동 환불되므로 추가 조치가 필요 없습니다. |
| Apple을 통해 구독한 Grok / X Premium | 공식 고객지원에서 신청 제출을 지원하며, Apple이 환불 금액을 최종 결정합니다. |
| Apple을 통해 구독한 Cursor | **사용자가 직접 iOS의 'Apple ID → 구독'으로 이동하여 수동으로 취소하고, Apple 고객센터에 환불을 요청해야 합니다.** |
| Google Play를 통해 구독한 서비스 | **사용자가 Google Play의 '결제 및 정기 결제'에서 자동 갱신을 수동으로 취소해야 합니다.** |

### 실전 사례: 통합 구독에 직면한 커뮤니티 작성자의 결정 기록

2027년까지 유효한 연간 플랜을 보유한 한 커뮤니티 개발자(작성자 서술, 미검증)는 사용량을 검토한 후 **보유 중인 기존 구독을 신규 통합 구독으로 당장 전환하지 않기로 결정**했으며, 기존 요금제의 자동 갱신을 끄고 계속 상황을 지켜보기로 했습니다.

기존 요금제에는 장기 할인 혜택이 포함되어 있어 섣불리 전환하면 기존 할인이 즉시 소멸됩니다. 또한 신규 요금제의 주간 공유 풀은 자사 모델에만 적용되며, 모든 서드파티 모델 호출은 API 표시 가격에 따라 별도 요금이 청구됩니다. 신규 요금제의 주간 사용량 풀은 모든 제품 간에 공유되므로, Bot을 과도하게 실행하면 웹 및 코드 완성에 필요한 일반 크레딧을 잠식하게 됩니다.

| 대상 구분 | 대표적인 특징 및 핵심 요구사항 |
| :--- | :--- |
| 전환 권장 대상 | 여러 구독을 개별 구매하여 월 지출이 30달러를 훨씬 초과하고, 주로 공식 모델을 사용하며, Grok Bot 자동화 및 X 계정 운영 간의 결합도가 높은 경우. |
| 전환 비권장 대상 | 서드파티 모델 추가 크레딧이 포함된 기존 요금제를 보유하고 있거나, Cursor에서 주로 코딩만 집중적으로 작업하고 X 소셜 기능이나 비디오 생성에는 관심이 없는 경우. |

전환하기 전에 먼저 사용량 대시보드를 열어 실제 호출 통계를 확인하고, 자사 모델과 서드파티 모델의 사용 비율을 파악하세요. AI 도구는 가능한 한 월간 구독을 이용하는 것이 좋습니다. 요금제 정책이 2~3개월마다 개편되므로 장기 연간 결제에 묶이면 상황 변화에 대처하기 어렵습니다(작성자 서술, 미검증).

**Apple을 통해 Cursor를 구독했던 사용자는 이전을 결정한 후 반드시 스마트폰 설정에서 자동 갱신을 직접 취소해야 합니다.** 웹에서 업그레이드하더라도 자동으로 처리되지 않습니다.

결정 분석에 대한 세부 사항은 [《통합 X 구독 분석: 신규 사용자는 어떻게 선택해야 하며 기존 구독자는 전환해야 할까? 한 편으로 정리》](https://jcng5q8n0f3z.feishu.cn/wiki/Myw6wFW8EicOiRkoEAXcVJqinee) 및 [《铁柱 트윗 모음 ①: 개통, 요금제 및 크레딧》](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)을 참조하세요.

### 달성 기준

기존 요금제를 유지하는 사용자는 자동 갱신 상태가 의도한 대로 설정되어 있는지 확인하고 핵심 모델 크레딧이 온전한지 점검해야 합니다.

**신규 요금제로 전환하기로 결정한 사용자는 기존 구독이 완전히 해지되었는지, 기존 결제 채널에서 환불을 받았는지, 신규 요금제가 Premium으로 정상 결제되고 있는지, 양쪽에서 중복 결제나 채널 충돌이 발생하지 않았는지 확인해야 합니다.**

## 사용량 확인 및 크레딧 손실 방지 프롬프트 구성

### 무엇인가요

**크레딧이 부지불식간에 소진되는 것을 방지하기 위해 먼저 양쪽 플랫폼의 용어 대응 관계를 이해해야 합니다.**

- 주간 사용 한도(데스크톱) / 주간 사용량(모바일): 이번 주의 고정 풀이며 매주 리셋됩니다. SuperGrok 연결 표시는 라이선스가 연동되었음을 나타내며, 독립적인 Cursor 요금제는 포함하지 않습니다.
- 온디맨드 사용량(Billed through Cursor): 고정 풀이 소진된 후의 추가 과금입니다. 웹의 월간 한도는 Spending 하단의 Monthly Limit에서 확인할 수 있습니다.
- 확인 경로: 데스크톱 앱의 경우 Settings(설정) > Usage & Billing(사용량 및 청구)으로 이동하고, 모바일 앱은 주간 사용량을 탭하며, 웹은 [cursor.com/dashboard](https://cursor.com/dashboard)에 로그인합니다.

### 진행 방법

**손실 방지 지침을 Bot의 시스템 프롬프트나 첫 번째 대화에 직접 입력하세요.**

일반적인 단일 Bot의 경우 첫 번째 문단을 입력하여 저소모 추론으로 제한하고 폴링 주기를 늘려 백그라운드 공회전을 방지합니다.

```text
你是一个自动化执行助手。在后续所有任务执行中，必须严格遵守以下资源控制规则：
1. 任务规划阶段必须输出极简执行步骤，禁止发起非必要的递归搜索与多轮冗余工具自检。
2. 在处理代码与文本分析任务时，保持适度推理强度，优先给出核心结果，不要输出冗长无关的修饰性文字。
3. 如果任务涉及定时轮询或周期监控，单次轮询时间间隔不得低于 30 分钟，严禁设置分钟级高频循环。
4. 严禁自行尝试调用外部视频生成或音频转换能力；如遇复杂多步骤任务，分步向我汇报进度并等待确认。
```

다중 Bot 협업 시에는 두 번째 문단을 입력합니다. **동일한 작업에서 여러 Bot이 빈번하게 브로드캐스팅하는 것은 크레딧을 가장 빠르게 낭비하는 함정이며(작성자 서술, 미검증), 반드시 포인트 투 포인트(P2P) 체인 통신을 강제해야 합니다.**

```text
你在多智能体协同流水线中担任协同节点。必须严格执行以下通信约束：
1. 全面采用点对点（Agent-to-Agent）单向派活与回传，禁止向群聊或未指名的公共上下文广播全量数据。
2. 传递工作流结果时，只提取关键字段与结构化结果摘要，严禁将完整的历史对话日志重复打包转发。
3. 协助任务交付完毕后，立即输出任务终止状态，主动退出协作监听，切断后续消息的被动接收与重复解析。
```

해당 전략은 [《铁柱 트윗 모음 ①: 개통, 요금제 및 크레딧》](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)을 참고했습니다.

### 달성 기준

프롬프트를 주입한 후, **Bot이 리소스 제약 사항을 준수하겠다고 명확히 응답하고 확인해야 합니다.** 자동화 스크립트를 3일 연속 실행했을 때 클라이언트의 Usage & Billing 사용량 곡선이 완만하고, 예약 작업이 지정된 정시 간격으로 실행되며 불필요한 자체 점검 로그가 없다면 합격입니다.

## 흔히 겪는 함정

### 선택 및 구독

- **Bot을 사용할 거라면 8달러짜리 Plus 등급을 사지 마세요.** Grok Bot과 Cloud agents가 포함되어 있지 않으므로 Bot을 쓰려면 반드시 30달러짜리 Premium 등급을 선택해야 합니다.
- **Cursor Pro와 SuperGrok 크레딧은 중복 합산되지 않습니다.** 양쪽을 동시에 구독해도 2배의 크레딧이 제공되지 않으며 시스템은 한쪽만 인정하므로 순전히 돈 낭비입니다.
- 서드파티 모델은 API 표시 가격에 따라 별도로 청구됩니다. The X Subscription 주간 공유 풀은 자사 모델에만 적용됩니다.
- **월간 결제를 선택하고 연간 결제는 피하세요.** 도구와 정책이 자주 바뀌므로 연간 요금제는 향후 조정할 수 있는 유연성을 제한합니다.

### 연동 및 구독 취소

- **계정 연동은 평생 되돌릴 수 없습니다.** Cursor를 SuperGrok 또는 X Premium+에 연동한 후에는 고객센터를 통해서도 연동을 해제할 수 없으므로, 테스트용 부계정으로 절대 연동하지 마세요.
- 기존 구독 이전은 PC 웹 브라우저에서만 작업할 수 있으며, 모바일 앱에서는 전환 메뉴가 지원되지 않습니다.
- **iPhone에서 Cursor 정기 결제를 반드시 수동으로 취소해야 합니다.** 웹에서 통합 구독으로 변경해도 App Store 결제가 자동으로 중단되지 않으므로, 수동으로 구독을 취소하지 않으면 양쪽에서 중복 결제됩니다.

### 크레딧 및 사용

- **온디맨드 사용량을 활성화하고 월간 한도를 설정하세요.** 주간 공유 풀이 소진되었을 때 온디맨드가 켜져 있지 않으면 Bot이 즉시 응답을 중단합니다.
- **다중 Bot 협업 시 포인트 투 포인트 통신을 사용하세요.** 그룹 대화의 모든 메시지는 모든 Bot에 브로드캐스트되어 연산되므로, 상주 그룹 대화에 초대하면 몇 턴 만에 주간 크레딧이 바닥납니다.

## 완료 후 검증 방법

1. **계정 권한**: 데스크톱 앱을 열고 왼쪽 하단 프로필을 클릭하여 요금제가 **Premium, Super 또는 Ultra**인지 확인합니다. 새 Bot 만들기를 클릭하여 구성 패널이 열리고 Cloud agents가 준비 완료 상태로 표시되는지 확인합니다.
2. **멀티 디바이스 크레딧**: 데스크톱 앱의 **Settings > Usage & Billing**에서 주간 사용량 백분율을 기록한 뒤, 모바일 앱을 열어 확인했을 때 양쪽 수치가 완전히 일치해야 합니다.
3. **지출 보호**: 브라우저에서 [cursor.com/dashboard](https://cursor.com/dashboard)의 Spending 페이지에 접속하여 **Monthly Limit**에 달러 한도가 입력되어 있고, 클라이언트의 온디맨드 채널이 Enable 상태인지 확인합니다.
4. **실제 호출**: 프롬프트를 보내 Bot이 짧은 작업을 한 번 실행하도록 하고, **로그를 확인하여 불필요한 수식어나 쓸데없는 도구 호출이 없는지 확인**한 후 사용량이 소폭 변동했다면 합격입니다.
